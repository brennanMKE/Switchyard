## Test design

- **Locating the app**: reads `BUILT_PRODUCTS_DIR` from the test process
  environment, falls back to walking up from the test bundle; then requires
  `Switchyard.app/Contents/MacOS/Switchyard` to exist via `try #require`
  before launching. Both mutation runs confirmed the env-var path resolves to
  the real DerivedData products directory.
- **Fixture**: a real git repository with one empty commit, created under
  `<project>/build/launch-smoke/repo-<UUID>` (resolved from `#filePath`;
  `build/` is gitignored), via `/usr/bin/git init --initial-branch=main` +
  local config + `commit --allow-empty`. Its path is passed as the sole argv
  argument to the app. Removed on every exit path.
- **Bounded wait**: polls `process.isRunning` every 100 ms against a deadline
  of now + 5 s. The bound is 5 s; worst-case overshoot is one poll interval.
- **Always killed**: a `defer` registered immediately after `run()` succeeds
  calls `stop(_:)` — SIGTERM, 2 s grace, then SIGKILL, then
  `waitUntilExit()`. An early `Issue.record`+`return` in the `run()` catch
  happens before the process exists, so nothing can leak there either. stderr
  is drained only after the process is confirmed stopped, so the read cannot
  block.
- **Failure reporting**: on early exit the `#expect` comment carries the
  termination status, reason, and full stderr. Stderr is never asserted
  empty — the app legitimately logs XPC failures on this machine; a log line
  is not a crash. No accessibility queries, no screenshots, no UI driving.

## Honest note on the dyld regression

**#0123's dyld crash was not reproduced.** The planning refresh explains why:
`Package.swift` on `main` has no `Clibgit2` target or libgit2 dependency, and
the issue forbids hand-editing the manifest to fabricate the failure. So the
demonstrated coverage is the first mutation only: the harness fails fast, with
the launched process's stderr and termination status in the failure message,
and never hangs. A real dyld error would surface through the same stderr
channel; that specific message remains unverified.
