Add the CLIInstaller state machine

Created `YardKit/Sources/YardKit/CLIInstaller.swift` (public caseless enum)
and `YardKit/Tests/YardKitTests/CLIInstallerTests.swift`. No other files
changed.

Ported vs adapted
- Ported from `../../RemoteControl/BridgeKit/Sources/BridgeKit/CLIInstaller.swift`
  (MIT, same author) with the copyright notice retained in the header, in the
  style of `XPCProtocols.swift:1-7`. Adapted: `remotectl` -> `switchyard`
  (via `ServiceNames.cliName`), bundle CLI path derived from
  `ServiceNames.cliBundleRelativePath` through a new `bundledCLI(inBundle:)`
  (the Switchyard constant excludes `Contents/`, so `Contents/` is prepended),
  legacy sweep path `~/.local/bin/switchyard`.
- Shape change for the pure half: RemoteControl's @MainActor @Observable class
  became a caseless enum of static functions taking injected paths, since
  install()/uninstall() (which need instance state) are #0222's. The pieces:
  `State` (4 cases), `inspect(_:expecting:)` (verbatim port, incl. the
  attributesOfItem-vs-fileExists dangling-link subtlety), `isBundleDurable(_:)`,
  `buildDirectoryRefusalReport(bundle:destination:)` (the REFUSAL value the
  install action must return when not durable), `requiresAuthentication(forDestinationDirectory:)`,
  `shellQuoted(_:)` (`public nonisolated static`, exact port), `Report`/
  `Severity`, `pathShadowReport(environmentPath:destinationDirectory:)`
  (injected PATH defaulting to the process environment; scans entries in
  order and stops at the destination's own entry, so the destination itself is
  never reported; a non-executable or directory match is skipped), and
  `legacySweepReport(bundledCLI:legacyDestination:)` (the DECISION: reports
  links into any `/Switchyard.app/` bundle, silent for someone else's tool;
  removal stays with #0222).
