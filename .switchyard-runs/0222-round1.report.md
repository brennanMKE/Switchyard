Add the privileged install act and menu

#0222 round 1: the ACT half of the CLI installer, behind the File menu.

**Package (`YardKit/Sources/YardKit/CLIInstaller.swift`, +87 lines, pure additions):**
`installCommand(bundledCLI:destination:legacyDestination:)` and
`uninstallCommand(destination:legacyDestination:)` return the exact privileged
shell strings (`mkdir -p <dir> && rm -f <legacy> && ln -sfn <bundled> <dest>`;
`rm -f <legacy> <dest>`), every path through `shellQuoted`, legacy cleared
FIRST in the same privileged step. Design decision, documented on the
functions: `legacyDestination` is `URL?` — the caller passes it only when
#0051's `legacySweepReport` reported the legacy link as ours, so a link to
somebody else's tool is never removed ("without legacy → no `rm -f`" shape).
Also `AuthOutcome` (`.cancelled` / `.failed(String)`),
`authOutcome(fromAppleScriptError:message:)` (-128 is userCanceledErr, read
from RemoteControl's BridgeKit installer, not guessed), and
`installPreconditionReport(bundle:destination:)` composing the durability
refusal.

**AppleScript runner location (decision):** the runner lives in the APP
target, new `Switchyard/CLIInstallActions.swift`. NSAppleScript needs AppKit;
the YardKit target is deliberately Foundation-only, so the package returns
strings and classifies outcomes while the app executes them. The runner is
in-process `NSAppleScript` with `with prompt` + `with administrator
privileges`, never a child `osascript` (dialog branding); it blocks on the
main thread, so no spinner. `install()`/`uninstall()` compose precondition →
state check (blockedByFile never clobbered) → legacy decision → command →
runner → Report, and `present(_:)` renders a Report as an NSAlert; a
cancelled dialog yields `nil` and surfaces as NOTHING.

**Menu:** `Switchyard/Commands.swift` gains Install Command Line Tool…
(ellipsis, dialog convention) and Uninstall Command Line Tool, both always
present with the inapplicable one disabled, funnelled through
CLIInstallActions.

**Tests:** new `YardKit/Tests/YardKitTests/CLIInstallerCommandTests.swift`,
9 tests reusing the InstallerFixture (staged under build/ only): exact
command strings with hand-apostrophised expectations (independent of
shellQuoted), the '\'' quoting boundary (space + embedded quote), uninstall
both/one, classifier cancelled/failure cases, durability refusal equals
buildDirectoryRefusalReport. One iteration fixed: the ServiceNames
single-source guard test (`noOtherSwiftSourceHardcodesTheIdentifiers`) caught
a hardcoded `/usr/local/bin/switchyard`; the destination now comes from
`ServiceNames.cliInstallPath`.
