## Routing decision

`Sources/yard-engine/main.swift` composes
`runEngineCommand(arguments:workingDirectory:) ?? runYard(arguments:)`.
The three-way router is `route(_:)` in `CommandLineRunner.swift`: it
classifies by **first token only** — `isKnownRemoteCommand(arguments.first)`
matches against `CommandRegistry.all` names. For `["wt", "list"]` a spec
named "wt list" would classify `.unknown` and be answered "Unknown
subcommand 'wt'" despite being in the registry. So the spec is named **`wt`**
(`CommandRegistry.lookup(name: "wt")`), schemaName stays `wt-list`, and
`runEngineCommand`'s `case "wt":` dispatches on `arguments[1]` with a
`guard arguments.count >= 2` — unknown/missing subcommand returns nil so
`runYard`'s usage fallback handles it. `wt where` (#0228) slots in as one
more case.
