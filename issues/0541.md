## Description

Guide §11 decision 42 in the stash detail pane (`StashDetailView`, #0496), the same shape as #0540.

- `loadStashDiff(at:oid:options:)` passes `options` to the async `stashDiff` (default `.standard`;
  `ContentView.reloadSelectedStashDiff` is unchanged).
- `StashDetailView` gains a `repositoryPath:` init parameter (after `item:`) so it can load the
  filtered stash itself — `ContentView` loads the standard one and passes `files` as before, and
  its call site passes `repositoryPath: repositoryPath ?? ""` (the way `RerereDetailView`'s does).
- `@State options` (not persisted) and `@State shownFiles`, loaded by `.task(id: ShownLoad(oid:
  options:))` only when the options are not standard; each of `files` draws
  `DiffViewOptions.file(file, in: shownFiles)` or `WhitespaceOnlyFileView`.
- The bar sits beside the "N changed files" count. No staging note: Apply, Pop and Drop… act on the
  stash, not on the diff, and stay enabled whatever the options.

```swift
// StashDiffOptionsTests.swift — the stash detail pane's diff drawn with
// diff options (#0541, guide §11 decision 42)

import Testing
@testable import YardGit
@testable import YardUI

@Test(arguments: FixtureRepository.RefFormat.supported())
func loadStashDiffDrawsTheStashWithTheOptions(format: FixtureRepository.RefFormat) async throws {
    var repo = try FixtureRepository(refFormat: format)
    defer { repo.destroy() }
    try repo.build([.init("base", files: ["a.txt": "a\n", "ws.txt": "y\n"])])
    try repo.writeUntracked(["a.txt": "a\nmore\n", "ws.txt": "y  \n"])
    try await GitProcess().run(["stash", "push", "-q"], workingDirectory: repo.url.path)
    let oid = try repo.revParse("refs/stash")

    let full = try await loadStashDiff(at: repo.url.path, oid: oid)
    let shown = try await loadStashDiff(
        at: repo.url.path, oid: oid, options: DiffViewOptions(ignoresWhitespace: true).diffOptions)

    #expect(full.map(\.path) == ["a.txt", "ws.txt"])
    #expect(full.map { DiffViewOptions.file($0, in: shown)?.path } == ["a.txt", nil],
            "the pane draws a.txt and notes ws.txt")
}
```
