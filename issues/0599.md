## Description

Every in-app history operation names itself in the Edit menu — Undo Merge, Undo Fixup, Undo Move
Commit — from `JournalMenuTitles`'s operation map. Squash with Parent does not: its engine writes
the journal entry with operation `"squash"` (`YardKit/Sources/YardGit/Squash.swift`, line 120:
`JournalCheckpoint.around(operation: "squash", …)`), and the map in
`YardKit/Sources/YardUI/JournalMenu.swift` has no `"squash"` key, so `JournalMenuTitles.undo`
falls back to the plain verb.

**Measured in the VM** (planner's run `20261005-135415-15022`, `main` at 7ff8d880): after Commit ▸
Squash with Parent… ▸ Squash on the history fixture's `stack` tip, #0595's spike reported
`the Edit menu offers no “Undo Squash”; it offers ["Undo"]`. The squash itself was correct (parent,
tree and combined message all asserted by git).

## The change — `YardKit/Sources/YardUI/JournalMenu.swift`

In `JournalMenuTitles.titles`, after `"fixup": "Fixup",` add:

```swift
        "squash": "Squash",
```

## The test — `YardKit/Tests/YardUITests/JournalMenuTests.swift`

In `everyMeasuredAndNamedOperationHasItsTitle`, add `"squash": "Squash",` after
`"fixup": "Fixup",` in `pairs`, and change `#expect(pairs.count == 16)` to
`#expect(pairs.count == 17)`.

## Verification

- `cd YardKit && swift test` prints `Test run with N tests … passed`; N equals main's count (the
  edit extends an existing test, it adds none — the count is not greater than main's).
- `./scripts/run-ui-tests-vm.sh 0595` (after #0595 is merged) prints
  `Test Case '-[SwitchyardUITests.Spike0595SquashUITests testSquashFoldsTheTipIntoItsParentWithBothMessages]' passed`.
  Before this change it fails at `the Edit menu offers no “Undo Squash”`.

## Mutation the review runs

Delete the `"squash": "Squash",` map entry: the unit test fails on
`JournalMenuTitles.undo(operation: "squash") == "Undo Squash"` and the VM spike fails at its
Edit-menu step.

## Expected behavior

After Squash with Parent, the Edit menu reads **Undo Squash** (and Redo Squash after undoing).

## Noted, not in scope

Two more operation strings the engine writes are unmapped and would also read plain "Undo":
`"resolve"` (`ResolveApply`) and `"branch-upstream"` (`RefManage.swift` line 521). Neither is
reached by a Commit-menu action this suite covers; if the app exposes them, they want the same
one-line fix.
