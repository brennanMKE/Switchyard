## Description

The suite that must never be allowed to go red. For every mutating command: build a fixture repo,
capture the pre-state, run the command, undo it, and assert the repository is **byte-identical** to
the pre-state — refs, index, and worktree, not just `HEAD`.

Coverage has to include the states that actually break undo, not just a clean tree.

## Expected behavior

- [ ] Every mutating command has a round-trip test.
- [ ] Pre/post comparison covers refs, index (including conflict stages), tracked files, and untracked files.
- [ ] Cases: unmerged index, mid-rebase sequencer state, detached `HEAD`, untracked files present, staged-and-unstaged mix.
- [ ] Each case runs against both ref formats via #0024.
- [ ] Deliberately breaking a restore path makes the suite fail — verified, not assumed.

## Notes

mid-rebase must capture it or the rebase cannot be resumed after restore. That is a test case here.
