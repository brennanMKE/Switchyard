## Description

The macOS 27 upgrade replaced the system git: **2.50.1 → 2.54.0 (Apple Git-157)**, measured
2026-09-22 (`git --version`). The reference-transaction hook contract changed, and the tripwire
CLAUDE.md's gotcha section and `ReferenceTransactionTests` were built to catch it fired: four
tests fail on `main` with the current toolchain, byte-identically, in both ref formats:

- `hookReceivesTheMeasuredContract` ×2 — `states.isSubset(of: ["prepared", "committed", "aborted"])`
  fails at `ReferenceTransactionTests.swift:207`.
- `nonZeroExitInPreparedAbortsTheTransaction` ×2 — `standardError.contains("aborted by hook")`
  fails at `ReferenceTransactionTests.swift:270`.

### Measured on git 2.54.0 (Apple Git-157), 2026-09-22

Scratch repo under `build/hook-measure2/`, hook logging `$1` and stdin per invocation:

- **Create** (`git update-ref refs/heads/observed <commit>`): states `preparing` → `prepared` →
  `committed`.
- **Delete** (`git update-ref -d refs/heads/observed`): states `preparing` → `aborted` →
  `prepared` → `committed` — **`aborted` fires mid-transaction on a successful delete.**
- **stdin is delivered on every invocation**, not only on `prepared` (each state's invocation
  received the full update lines).
- **Abort path**: hook exiting 1 on `prepared` produces, on stderr,
  `fatal: in 'prepared' phase, update aborted by the reference-transaction hook`, exit **128**
  (was: `fatal: ref updates aborted by hook`). The old substring `aborted by hook` no longer
  appears, which is why the abort test fails.
- A failed update (non-commit object to a branch) also invokes the hook before failing.

### What must change

- **The hook layer's rule already survives this**: do real work only on `committed`, return 0 in
  every other state. `preparing` and the mid-transaction `aborted` are covered by that rule —
  verify `JournalHook`/the hook installer treats them as do-nothing (it should already; add a
  test if the state list is pinned anywhere in source).
- **Tests**: the tripwire's allowed set gains `preparing`; the abort test asserts the new stderr
  text; the stdin-per-invocation semantics get an assertion so the next change is caught the same
  way. Re-measure per scenario (create, delete, abort) in both formats and pin what 2.54.0
  actually emits — the first measurement above mixed a failed update into its log, so the fixing
  round re-measures cleanly before editing.
- **CLAUDE.md's gotcha text** ("The states git 2.50.1 actually emits are prepared, committed,
  aborted … There is no preparing state") is now wrong for 2.54 and must be rewritten with the
  measured 2.54 contract, keeping the do-nothing rule and the reason for it.

### Files and literal changes (planning update, 2026-09-22)

- **`YardKit/Sources/YardGit/ReferenceTransaction.swift`** — the `State` enum's parse switch
  (lines 42–44) gains `case "preparing": self = .preparing`, with the enum gaining the matching
  case. Measured: git 2.54.0 emits `preparing` before `prepared` on every transaction.
- **`YardKit/Sources/YardKit/HookArm.swift`** — no change expected: line 129's
  `guard state == "committed" else` already treats every other state as do-nothing, which covers
  `preparing` and the mid-transaction `aborted`. The round verifies this by test, not by trust.
- **`YardKit/Tests/YardGitTests/ReferenceTransactionTests.swift`**:
  - the tripwire at line 207 becomes
    `states.isSubset(of: ["preparing", "prepared", "committed", "aborted"])`;
  - the abort assertion at line 270 becomes
    `attempt.standardError.contains("update aborted by the reference-transaction hook")`
    (measured 2.54.0 text: `fatal: in 'prepared' phase, update aborted by the reference-transaction hook`,
    exit 128);
  - new assertions pin the measured per-transaction sequences — create:
    `preparing → prepared → committed`; delete: `preparing → aborted → prepared → committed`
    (the mid-transaction `aborted` on a *successful* delete is part of the contract) — and that
    stdin is delivered on every invocation, not only on `prepared`.
- **`CLAUDE.md`**, reference-transaction gotcha bullet: replace the 2.50.1 sentence with the
  measured 2.54.0 contract and the date, keeping "do real work only on `committed`; return 0
  immediately in every other state" and its reason.
