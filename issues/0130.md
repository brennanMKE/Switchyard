## Description

Apply #0129's settled wire pattern (its Decisions 1–8) to the worktree identity payloads:

| type | source file |
|---|---|
| `WorktreeEntry` | `YardKit/Sources/YardGit/WorktreeList.swift` |
| `WorktreeWhere` | `YardKit/Sources/YardGit/WorktreeWhere.swift` |
| `SiblingWorktree` | `YardKit/Sources/YardGit/SiblingWorktree.swift` |

All three are already `Sendable`, so each needs only a same-file `extension … : Encodable` with an
explicit no-raw-value `CodingKeys` enum (#0129 Decision 3) plus byte-pinned tests in
`YardKit/Tests/YardWireTests/` reusing that target's `wireJSON` helper.

Known trap: `WorktreeEntry` declares a custom `==`; that has no effect on `Encodable` synthesis,
but its 10 stored properties (`path`, `head`, `branch`, `locked`, `lockReason`, `bare`,
`detached`, `prunable`, `prunableReason`, `isMainWorktree`) must all appear in `CodingKeys` —
mutation-test a dropped case per #0129's row 2.

## Expected behavior (re-author to code level before dispatch, per CLAUDE.md)

- [ ] Each type gains `Encodable` with an explicit `CodingKeys` enum, keys = member names
      verbatim; nil optionals omitted, never `null` (#0129 Decisions 3–4).
- [ ] Literal-JSON tests (fully-populated value, nil-optional value, one envelope passthrough) in
      `YardKit/Tests/YardWireTests/WorktreeIdentityWireTests.swift`, literals pasted from a real
      run at planning time.
- [ ] `cd YardKit && swift test` prints a `Test run with N tests` line; N must exceed the
      pre-change baseline by exactly the number of new tests, both counts settled and stated at
      planning time.
