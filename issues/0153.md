## Description

The half of the original #0042 that needs the journal store: take the
`ReferenceTransaction.Decision.updates` a foreign `committed` transaction produced (#0042's
decision core) and persist them as **observed** journal entries — distinct from undoable ones —
in the metadata store #0027/#0028 build. This is what lets the guard say *what* moved a ref
between two `switchyard` commands instead of merely that something did.

## Expected behavior

- [ ] A committed foreign transaction's updates land as an observed entry (operation, refs with
      old/new values, timestamp, worktree), marked so `undo` never offers to revert it.
- [ ] The journal's own ref writes never produce an entry (the #0042 marker path, exercised end
      to end through the store).
- [ ] Failure to persist never surfaces as a non-zero hook exit — the #0042 totality invariant
      holds through this layer too.
- [ ] `swift test` prints a `Test run with N tests` line; N must exceed the pre-change baseline
      (re-measure at planning time; state the delta).
