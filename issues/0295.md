## Description

**Finding 3 of the M1 milestone review, eighth pass, 2026-08-18.** `graphRows` loses its trailing `--`
undetected, and then **fails outright** on a repository with a branch named like a directory.

`YardKit/Sources/YardGit/LaneAssignment.swift:204`, remove `arguments.append("--")`: full suite green,
`Test run with 1103 tests in 78 suites passed after 61.030 seconds`.

**Measured against the engine**, in a repository with both a `docs/` directory and a `docs` branch:

```
pristine:  PROBE-GRAPH: ok rows=2
mutant:    PROBE-GRAPH: THREW git rev-list --topo-order --parents --exclude=refs/switchyard/* docs
                        exited 128: fatal: ambiguous argument 'docs': both revision and filename
```

**A hard failure, not a degraded result.** The flag's own doc comment states the reason — *"a trailing
`--` keeps git from reading a revision name as a path"* — and that comment is the only thing enforcing
it.

**It is on the path M3 takes.** The same comment notes the graph view will pass ref names rather than
the default `["HEAD"]`, which is precisely when this becomes reachable. `docs`, `test` and `build` as
both a branch and a directory is ordinary.
