## Description

**Split out of #0209 on 2026-08-17**, which introduced `JournalCheckpoint.around` and applied it to
`commitHunks` — the one composed command that existed. This issue applies it to the rest, so M2's exit
criterion *"undo round-trips every mutating command"* is true of every command rather than one.

The remaining mutating entry points in `YardGit`:

- `stageHunks` (`Staging.swift`)
- `unstageHunks` (`Unstaging.swift`)
- `fixup` — **does not exist yet; it is #0039.** Do not wait for it; #0039 should call
  `JournalCheckpoint.around` when it is written, and this issue's job is the two that exist.

## The trap this issue has to avoid, and it is the reason #0209 was scoped to one command

**`commitHunks` calls `stageHunks`.** If `stageHunks` checkpoints on its own, `commitHunks` produces
**two** entries for one user action — exactly the littering guide §11 decision 15 rejects, and `undo`
would then step through half of a commit.

So the primitives cannot simply be wrapped. Each needs a public entry point that checkpoints and an
internal one that does not, with `commitHunks` calling the internal one. Name them so the distinction
is impossible to miss at a call site; #0209's helper is the composing seam and this issue extends the
pattern rather than inventing a second.

## Expected behavior

- [ ] `YardKit/Sources/YardGit/Staging.swift` and `YardKit/Sources/YardGit/Unstaging.swift`:
      `stageHunks` and `unstageHunks` each write exactly one journal entry per call when called
      directly, via `JournalCheckpoint.around`. Tests go in
      `YardKit/Tests/YardGitTests/StagingTests.swift` and
      `YardKit/Tests/YardGitTests/UnstagingTests.swift` — check those file names against the tree
      before writing, and say if they differ.
- [ ] **`commitHunks` still writes exactly one entry**, not two. `#0209`'s
      `commitHunksWritesExactlyOneJournalEntry` must still pass unchanged — if it needs changing, the
      split above is wrong.
- [ ] `undo` after each restores the pre-operation state, using `UndoRoundTripSuiteTests`' helpers.
- [ ] A mutation, observed: have `commitHunks` call the checkpointing variant of `stageHunks` and
      confirm the one-entry test goes red. This is the row that proves the split is real.
- [ ] `cd YardKit && swift test` prints a `Test run with N tests` line greater than the count in
      `docs/test-baseline.txt`; state the delta before running.

## Notes

**Blocked by #0209**, which introduces the helper.

Guide §9's M2 criterion is the reason this exists: `stage` and `unstage` are named in it alongside
`commit` and `fixup`, and an `undo` with nothing to restore to is not a working `undo`.
