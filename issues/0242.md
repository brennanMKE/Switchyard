## Description

**Finding 2 of #0160's third umbrella review, 2026-08-17.** #0236 made `JournalObserved.Metadata`
`Decodable` and gave `JournalAnchor.metadata` a `namespace:` — but **there is still no production read
path**, so bullet 5 ("#0064 can read the stored mapping") is not met.

The decode requires a matching `dateDecodingStrategy`, and the only decoder that has one lives in a
**test**: `private static func decodeMetadata` in `JournalObservedTests.swift:74`, whose own doc comment
says *"decode must match or `timestamp` fails to parse"*.

```
$ grep -rn "dateDecodingStrategy" YardKit/Sources/     # three hits, none for observed metadata
```

`JournalEntryMetadata` has `init(serialized:)` (`:470`) and so does `RefSnapshot`;
`JournalObserved.Metadata` does not. A consumer in `Sources/` must therefore re-derive the strategy
from scratch and throws at runtime if it gets it wrong — **the same "the knowledge lives only in a
test" shape #0236 was filed to remove**, one step further in.

## The files

- `YardKit/Sources/YardGit/JournalObserved.swift` — the initialiser and the shared strategy.
- `YardKit/Sources/YardGit/JournalEntryMetadata.swift` — read `init(serialized:)` here first.
- `YardKit/Tests/YardGitTests/JournalObservedTests.swift` — delete `decodeMetadata`, add the round trip.
