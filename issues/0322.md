## Description

**Finding of #0160's thirteenth umbrella review, 2026-08-18 — the third instance of a comment describing
a property its assertion cannot check.** The own path's stored `source` is pinned to a **literal**, not
derived from the `Decision`.

`YardKit/Sources/YardGit/JournalCheckpoint.swift:447-448`, mutated:

```diff
  let mapping = JournalEntryMetadata.RewriteMapping(
-     source: decision.source.gitArgument, rewrites: decision.rewrites)
+     source: PostRewrite.Source.rebase.gitArgument, rewrites: decision.rewrites)
```

`✔ Test run with 1133 tests in 80 suites passed after 92.110 seconds.` — **full suite.**

The complementary mutation (`.amend`) *is* killed, so the field is pinned in exactly one direction:
**the stored value must be the string `"rebase"`** — which every own-path fixture happens to produce.

**The two assertions sit on adjacent lines** (`PostRewriteAttachTests.swift:305-306`):

```swift
#expect(mapping.source == "rebase")
#expect(mapping.rewrites == decision.rewrites)
```

The second compares against the decision; **the first compares against a literal.** And
`attachingAnExistingCommitFixupMappingKeepsThePreCheckpointHeadReachable:981` repeats the literal with
the comment *"the final, authoritative invocation is the rebase; **its source must survive composing**"* —
a claim the assertion **cannot test**, because it cannot distinguish *surviving* from *being hardcoded*.

**The asymmetry is the sharpest evidence.** The same mutation on the **foreign** half
(`JournalObserved.swift:108`) is killed **three ways** — two wire tests that use `amend` and
`filter-repo`, plus the production-accessor round trip. Bullet 1's `source` is pinned three ways;
bullet 2's identical field is pinned by a literal.

## Reachability — two routes, stated honestly

Today every own operation reaching `attachRewrite` ends on a `rebase`, so the final composed value is
`"rebase"` either way. **Two reachable routes make the constant wrong:**

1. **`Fixup.run(source:target:)` → `performFixupExisting`** runs `git commit --amend --fixup=… --no-edit`
   (`Fixup.swift:424`) inside `around`. That fires an own `amend` invocation, attached on its own, so the
   entry reads `{source: "amend", headBefore→mid}` until the rebase composes over it. **If
   `autosquashRebase` fails and aborts** — the `signingSucceedsForTheFixupCommitThenFailsDuringTheRebase`
   arm — that `amend`-labelled mapping is the entry's **final, persisted state**, and under the constant
   it claims a rebase that never ran.
2. Any M3 `switchyard` command whose only rewrite is an amend.
