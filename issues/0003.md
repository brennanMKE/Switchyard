## Description

The app's premise is a live, interactive commit graph. If lane assignment for the visible window
cannot be computed fast enough to feel instant on a large repository, the app is not worth building
in this shape and we need to know in week one.

Measure with and without a `commit-graph` file present. `git commit-graph write --reachable` is
cheap and Switchyard can keep it fresh in the background, so measuring only the cold case measures
something we would never ship.

## Expected behavior

- [ ] Actual numbers recorded — not "fast enough". Load time, lane assignment time, memory.
- [ ] Both cases measured: with and without `commit-graph`.
- [ ] A real repository with 50k+ commits used, named in the findings.
- [ ] Windowed traversal measured, not full-history traversal, since that is what the UI does.
- [ ] Finding recorded in `docs/engine-findings.md`.

## Notes

Guide §5 "Milestone 0 spike" question 2. **If this fails, stop and escalate.**

GitUp's lane assignment is well tested and worth understanding conceptually — but it is GPLv3, so
read it, close it, and write your own. Do not copy its fixtures either (#0025).

## Fix

Measured both candidate paths — libgit2 revwalk and `git rev-list --topo-order --parents` — over
five window sizes against `git/git` (81,873 commits), with and without a commit-graph, in a release
build.

## Verification

`spike/libgit2-eval` `perf` binary. Without a commit-graph, a 100-commit window costs 451 ms
(libgit2) / 391 ms (plumbing). With one — written in 0.39 s, 5.1 MB — plumbing drops to **79 ms**
while libgit2 stays at 456 ms. Full tables in `docs/engine-findings.md`.

## Gotchas

**Topological order costs a full history traversal regardless of window size** — a 100-commit window
costs the same as a 20,000-commit one. "Windowed loading" does not bound the load cost, and #0015
must not assume it does; the commit-graph is what makes it affordable.

The 2.1 s lane assignment at 20,000 commits is the spike's naive O(n × lanes) algorithm leaking
lanes (4,145 open lanes), not a prediction about the shipping one. Upper bound to beat.
