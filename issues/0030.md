## Description

The repository is always authoritative; the state directory is an index and a convenience. If it is
deleted, `yard journal` must rebuild from `refs/switchyard/journal/*` alone, with reduced metadata.

Write this early and test it by actually deleting the directory. It is what keeps the design honest
about which store is the source of truth, and it is exactly the kind of path that rots unnoticed if
it is written late and never exercised.

## Expected behavior

- [ ] Deleting the state directory and `.git/switchyard/journal.json` still yields a usable `yard journal`.
- [ ] Rebuilt entries clearly report which metadata is unavailable rather than inventing defaults.
- [ ] `undo` still works on a rebuilt entry, or refuses with a clear reason if the guard data is gone.
- [ ] The test deletes the directory for real — it does not mock the absence.
