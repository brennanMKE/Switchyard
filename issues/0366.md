## Description

**Child of #0358, split 2026-09-12.** Brennan, 2026-09-12: **each branch gets its own colour, stable
across refreshes and independent of the lane column.** One deliverable: the gutter's edges and nodes
are coloured by the branch that owns them. This replaces the lane-index palette in #0358's first
planning pass.

### Design

1. **Ownership.** Tips claim history in order: a detached `HEAD`, then `HEAD`'s branch, then the other
   local branches by name, then remote-tracking branches by name. Each tip claims its first-parent
   chain within the loaded rows until it reaches a commit already claimed. So `main` owns its own
   line, and a feature branch owns only the commits not already on `main`. History no tip's
   first-parent chain reaches (merged in from a deleted branch) is unowned and draws `.secondary`.
2. **Edge owner.** A first-parent edge belongs to its child's branch. Any other parent edge — the line
   a merge draws to what it merged — belongs to the branch owning that parent, falling back to the
   child's. Both rows an edge spans compute the same answer, so an edge never changes colour mid-run.
3. **Colour is a pure function of the name**: FNV-1a (64-bit) over the colour key's UTF-8 bytes,
   reduced into a 10-colour system palette. A remote-tracking branch drops its remote segment
   (`origin/feature` → `feature`), so it shares its local branch's colour and #0368's dash tells them
   apart. It is deliberately **not** `hashValue`: Swift seeds `Hasher` per process (documented
   behaviour, SE-0206), so a `hashValue` colour would change on every launch.

### "Unique" cannot strictly hold — flagged

*Measured* 2026-09-12 with the code below (scratch worktree of `main` at `61c94aa`):

- The palette has **10** colours (system colours; yellow and cyan left out for contrast on light).
- Batty's first 100 topological commits carry tips for **16 colour keys** (16 local branches;
  `origin/main` folds onto `main`). All 10 colours are used, and **11 of the 16 keys share a colour
  with another key**; per-colour counts `[1, 1, 1, 1, 3, 2, 2, 1, 2, 2]`.
- Across all **123** of Batty's keys, every colour carries 8–15 branches.
- Collisions are likely even with few branches: five branches on screen share at least one colour
  with probability 1 − (10·9·8·7·6)/10⁵ ≈ 70% (arithmetic under uniform hashing, not measured).

**Collision handling: collisions are accepted, not resolved.** Any rule that moves a branch off its
hashed colour when another branch holds it — probing to the next free colour among loaded branches,
or handing out least-used colours in first-seen order — makes one branch's colour depend on which
*other* branches exist. It would then change when a branch is created, deleted or fetched, which is
exactly the stability asked for. A collision stays readable without breaking stability because:

- every tip carries its name (#0367), tinted in the same colour;
- two branches sharing a colour sit in different columns, each drawn as one continuous line from its
  tip to where it joins;
- remote-only history is dashed (#0368).

**Alternative, for Brennan, if on-screen collisions prove worse than instability:** resolve
collisions among the loaded branches by probing in name order. Colours would then change only when
the loaded set of branches changes, never on a refresh that changes nothing. Not specified here —
implement hash-only.

### `YardKit/Sources/YardUI/BranchColors.swift` (new, *compiled*)

```swift
// BranchColors.swift
//
// #0366: one colour per branch, the same colour on every refresh, every
// launch and every machine, independent of which lane column the branch
// happens to occupy. Ownership says which branch a commit (and so an edge)
// belongs to; the colour is a pure function of the branch's name.

import SwiftUI
import YardGit

/// A branch tip the History pane colours by.
public nonisolated struct BranchTip: Hashable, Sendable {
    /// Short name: `main`, `origin/main`, or `HEAD` for a detached `HEAD`.
    public let name: String
    public let oid: String
    public let isRemote: Bool

    public init(name: String, oid: String, isRemote: Bool) {
        self.name = name
        self.oid = oid
        self.isRemote = isRemote
    }

    /// The name the colour is derived from. A remote-tracking branch drops
    /// its remote segment, so `origin/feature` is drawn in `feature`'s
    /// colour -- the dash (#0368) is what tells them apart.
    public var colorKey: String {
        guard isRemote, let slash = name.firstIndex(of: "/") else { return name }
        return String(name[name.index(after: slash)...])
    }
}

public nonisolated enum BranchOwnership {
    private static let heads = "refs/heads/"
    private static let remotes = "refs/remotes/"

    /// Tips in claiming order: a detached `HEAD`, then `HEAD`'s branch, then
    /// the other local branches by name, then remote-tracking branches by
    /// name. Earlier tips win shared history, so `main` owns its own
    /// first-parent line even where a feature branch also reaches it.
    public static func tips(from refs: RefSnapshot) -> [BranchTip] {
        var result: [BranchTip] = []
        var headBranch: String?
        switch refs.head {
        case let .symbolic(target) where target.hasPrefix(heads):
            headBranch = String(target.dropFirst(heads.count))
        case let .detached(oid):
            result.append(BranchTip(name: "HEAD", oid: oid, isRemote: false))
        default:
            break
        }
        result += refs.refs
            .filter { $0.name.hasPrefix(heads) }
            .map { BranchTip(name: String($0.name.dropFirst(heads.count)), oid: $0.oid, isRemote: false) }
            .sorted { ($0.name == headBranch ? 0 : 1, $0.name) < ($1.name == headBranch ? 0 : 1, $1.name) }
        result += refs.refs
            .filter { $0.name.hasPrefix(remotes) && !$0.name.hasSuffix("/HEAD") }
            .map { BranchTip(name: String($0.name.dropFirst(remotes.count)), oid: $0.oid, isRemote: true) }
            .sorted { $0.name < $1.name }
        return result
    }

    /// oid -> owning tip. Each tip, in `tips` order, claims its first-parent
    /// chain within `rows` until it reaches a commit already claimed. A commit
    /// no tip's first-parent chain reaches (history merged in from a deleted
    /// branch) has no owner.
    public static func owners(in rows: [GraphRow], tips: [BranchTip]) -> [String: BranchTip] {
        let byOid = Dictionary(rows.map { ($0.oid, $0) }, uniquingKeysWith: { first, _ in first })
        var owners: [String: BranchTip] = [:]
        for tip in tips {
            var next: String? = tip.oid
            while let oid = next, let row = byOid[oid], owners[oid] == nil {
                owners[oid] = tip
                next = row.parents.first
            }
        }
        return owners
    }

    /// The branch an edge is drawn for. A first-parent edge belongs to its
    /// child's branch. Any other parent edge -- the line a merge draws to the
    /// history it merged -- belongs to the branch owning that parent, falling
    /// back to the child's. Both rows the edge spans compute the same answer.
    public static func owner(of edge: LaneEdge, in owners: [String: BranchTip]) -> BranchTip? {
        edge.parentIndex == 0 ? owners[edge.child] : (owners[edge.parent] ?? owners[edge.child])
    }
}

public nonisolated enum BranchColor {
    /// System colours only, so each adapts to light, dark and Increase
    /// Contrast. Yellow and cyan are left out: both read poorly as a 2 pt
    /// stroke on a light background.
    public static let palette: [Color] = [
        .blue, .orange, .green, .purple, .pink, .teal, .indigo, .red, .mint, .brown,
    ]

    /// FNV-1a (64-bit) over the key's UTF-8 bytes, reduced into `palette`.
    /// Deliberately not `hashValue`: Swift seeds `Hasher` per process, so a
    /// `hashValue`-based colour would change on every launch.
    public static func index(forKey key: String) -> Int {
        var hash: UInt64 = 0xcbf2_9ce4_8422_2325
        for byte in key.utf8 {
            hash ^= UInt64(byte)
            hash &*= 0x0000_0100_0000_01b3
        }
        return Int(hash % UInt64(palette.count))
    }

    /// `nil` -- history no branch owns -- draws in `.secondary`.
    public static func color(for tip: BranchTip?) -> Color {
        guard let tip else { return .secondary }
        return palette[index(forKey: tip.colorKey)]
    }
}
```

### `LaneGutterView` — the colour increment (*compiled* as part of the full view in #0368)

- New stored property `let owners: [String: BranchTip]`.
- `stroke(_:for:)` strokes with
  `.color(BranchColor.color(for: BranchOwnership.owner(of: edge, in: owners)))` instead of
  `.color(.secondary)`.
- The node's fill (or its merge ring) uses `BranchColor.color(for: owners[row.oid])` instead of
  `.primary`. The `HEAD` ring stays `.primary`.

### `CommitHistoryView` — the increment

- `init` gains `refs: RefSnapshot? = nil`; `ContentView.historyPane(summary:)` passes
  `refs: sidebar?.refs`.
- `body` computes
  `let owners = refs.map { BranchOwnership.owners(in: graphRows, tips: BranchOwnership.tips(from: $0)) } ?? [:]`
  and passes `owners:` through `CommitHistoryRow` to `LaneGutterView`.

### Tests — `YardKit/Tests/YardUITests/BranchColorsTests.swift` (new), all *measured* passing

- `tips(from:)` on `HEAD → main`, with `feature`, `origin/HEAD` and `origin/feature` present, returns
  `["main", "feature", "origin/feature"]` (`origin/HEAD` excluded).
- On #0365's branch-off fixture with `main` at `m2` and `feature` at `f2`: `m2, m1, root` → `main`;
  `f2, f1` → `feature`; the converging edge `f1>m1` in row `m1` → `feature`.

  merge edge `c2>s1#1` → `side`. Without the `side` tip, `s1` is unowned and that edge falls back to
  `main`.
- `BranchTip(name: "origin/feature", oid: …, isRemote: true).colorKey == "feature"`.
- **Pinned indices, proving stability across launches and machines**: `main` = 6, `feature` = 9,
  `issue/0404` = 5, `issue/0364` = 8, `HEAD` = 1.
- Lane independence: lay out the same commits twice with the tips in a different order (so
  `LaneAssigner` puts a branch in a different lane); every commit's owner, and so its colour, is
  identical.
