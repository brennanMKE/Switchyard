## Description

**Child of #0380.** **Question:** in a macOS `List` whose rows use
`.listRowInsets(EdgeInsets(top: 0, leading: 0, bottom: 0, trailing: 8))` and `.listRowSeparator(.hidden)`,
with a `Canvas` gutter at `.frame(maxHeight: .infinity)`, does a vertical line drawn at full height in
each row join into one continuous line?

**Why it matters:** #0365 draws the graph row by row. Any gap between rows breaks every lane into
dashes, and #0368 uses real dashes to mean "remote-only".

### Build

Tab **0384 row gaps** of #0380's spike app. The left list uses #0365's insets; the right list keeps
the defaults, for comparison. Row 3 is selected in both.

### Observe

1. Capture the window (`docs/windows-command.md`) in light appearance, then again in dark (System
   Settings ▸ Appearance).
2. Zoom each capture to 400%. For each list, record the gap between consecutive rows' orange segments
   in pixels (0 if continuous), including directly above and below the selected row.

### Pass or fail, and what changes

- **Pass** — the left list shows 0 px gaps in both appearances, including around the selected row.
  #0365 is unchanged.
- **Fail** — the left list shows gaps. #0365's re-plan picks one of:
  - **(a) Overdraw**: extend the gutter by the measured gap with negative vertical padding, so each
    row's strokes overlap its neighbours'. Cheap; check the selection highlight does not clip it.
  - **(b) Replace `List`** with `ScrollView` + `LazyVStack`, and rebuild selection, keyboard
    navigation and VoiceOver row semantics by hand. Expensive, and #0365 currently forbids it, so
    this is Brennan's call.

## Expected behavior

      both lists in both appearances.
- [ ] #0365 is updated per the outcome.
