## Description

Reported by the #0435 round on 2026-09-27; not yet reproduced by the orchestrator. The command below
failed in the app target's "Ad-hoc seal (unsigned builds)" build phase, added by #0418.

```
xcodebuild build-for-testing -project Switchyard.xcodeproj -scheme Switchyard ... CODE_SIGNING_ALLOWED=NO
```

The failure was `codesign --verify --deep --strict` reporting "bundle format unrecognized" for the
nested `Contents/PlugIns/SwitchyardTests.xctest`. The 'Switchyard UITests' scheme builds clean.

This matters because CLAUDE.md documents
`xcodebuild … -scheme Switchyard -only-testing:SwitchyardTests test` as the unit-test command, so
it may now be broken.

## Expected behavior

- [ ] Reproduced first: `build-for-testing -scheme Switchyard` unsigned, and the documented
      `test -only-testing:SwitchyardTests` command, on `main` after #0434 merges.
- [ ] The seal phase either skips or correctly seals nested test bundles in `PlugIns`, so both
      commands exit 0 with the seal still verified for a plain `build`.

Needs an Opus planning pass before dispatch. Coordinate with #0434, which rewrites the seal script.
