## Description

**Finding 4 of the M1 milestone review, thirteenth pass, 2026-08-18.** `WorktreeContext.canonicalize`
**reverses a multi-component missing tail**, and the whole suite stays green.

`YardKit/Sources/YardGit/WorktreeContext.swift:166`, mutated `tail.reversed().reduce(…)` →
`tail.reduce(…)`: `Test run with 1129 tests in 80 suites passed after 85.060 seconds` — **full suite.**

**The reviewer checked all three mutation traps** — it landed, it compiled, and it demonstrably changes
the answer:

```
canonicalize  /…/T/probe13-D65D21B0/aaa/bbb  ->  /…/T/probe13-D65D21B0/bbb/aaa

wt new  requested /…/T/probe13deep-18910C9A/inner
        result    /…/T/inner/probe13deep-18910C9A   error: nil
```

So **`worktreeAdd` reports `ok: true` with a `worktreePath` that does not exist**, and nothing reddens.

**Why nothing catches it:** every existing fixture creates worktrees whose missing tail is exactly **one
component**, where both directions coincide. Textbook **class 3** — a scan direction where both
directions agree on every fixture.

The site is reachable from a real M1 entry point: unmutated, `wt new` into a two-deep missing path
returns the correct path.
