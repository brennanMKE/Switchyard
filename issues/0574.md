## Description

The window's minimum width is 900 pt (`PaneLayout`: 260 + 360 + 280). The hardening pass
dragged it down to that minimum and found three layout rough edges. All of them are
screenshotted in `issues/0569/`:

1. **Buttons wrap onto two lines at 900 pt** (`0574-hunk-buttons-wrap-900.png`). In the Detail
   pane's Changes view:
   - the hunk header row reads `Discard` / `Hunk…` on two lines, next to a single-line
     `Stage Hunk`;
   - the composer's top row reads `Stash` / `Changes…`.

   `HunkView`'s header row (`FileDiffView.swift`) lets the `@@ … @@` header text keep its full
   width, so the buttons are squeezed. The `Stash Changes…` button has no `lineLimit`.
2. **A long branch name pushes the header's oid past the window edge**
   (`0574-long-branch-header-clipped-900.png`). On
   `feature/a-really-long-branch-name-for-the-header-truncation-check` the tracking line runs the
   full width, and the oid is cut off at `3571`. `RepositoryHeaderView`'s first `HStack` has
   neither `lineLimit` nor `truncationMode`.
3. **A detached HEAD shows its oid twice** (`0574-detached-oid-twice.png`). The header reads
   `Detached HEAD at 3571b01  3571b01`. `TrackingSummary.text` already ends with `headOID` when
   detached, and the header then draws `whereAmI.headOID` again beside it.

All three were measured in the VM on 2026-09-30 by the hardening pass's throwaway spikes, on the
changes fixture and the switch fixture.

## The change — four files

### 1. `YardKit/Sources/YardUI/TrackingSummary.swift` — the oid shown beside the line

Add it to `TrackingSummary`, directly before `operationInProgress`:

```swift
    /// #0574: the oid the header shows beside the tracking line — `nil`
    /// when HEAD is detached (the line already ends with it) or unborn.
    public static func separateOID(for state: WhereAmI) -> String? {
        guard state.branch != nil, !state.headOID.isEmpty else { return nil }
        return state.headOID
    }
```

### 2. `YardKit/Sources/YardUI/RepositoryHeaderView.swift` — one line, the oid kept

Replace the first `HStack(spacing: 8) { … }` body in `body`. It is currently:

```swift
                Text(TrackingSummary.text(for: whereAmI))
                    .font(.headline)
                Text(whereAmI.headOID)
                    .font(.system(.body, design: .monospaced))
                    .foregroundStyle(.secondary)
```

It becomes:

```swift
                // #0574: one line; a long branch or upstream name gives way
                // in the middle, and the oid is never pushed off the edge.
                Text(TrackingSummary.text(for: whereAmI))
                    .font(.headline)
                    .lineLimit(1)
                    .truncationMode(.middle)
                if let oid = TrackingSummary.separateOID(for: whereAmI) {
                    Text(oid)
                        .font(.system(.body, design: .monospaced))
                        .foregroundStyle(.secondary)
                        .fixedSize()
                }
```

### 3. `YardKit/Sources/YardUI/FileDiffView.swift` — hunk buttons keep their width

In `HunkView.body`, add two modifiers to the `Text(hunk.header)` in the header `HStack`, after
`.foregroundStyle(.secondary)`:

```swift
                    // #0574: the header gives way, not the buttons.
                    .lineLimit(1)
                    .truncationMode(.tail)
```

In `HunkView.button(_:)`, add `.fixedSize()` between `.controlSize(.small)` and
`.disabled(!action.isEnabled)`.

### 4. `YardKit/Sources/YardUI/WorkingChangesView.swift` — Stash Changes… on one line

In `commitArea`, on the `Button("Stash Changes…")`, add `.lineLimit(1)` after
`.controlSize(.small)`.

All four were applied in a throwaway worktree on 2026-09-30. `swift build` succeeded, and
`swift test --filter TrackingSummary` printed `Test run with 12 tests in 2 suites passed`,
including the new test below.

## Verification

### Unit test — append to `TrackingSummaryTests` in `YardKit/Tests/YardUITests/TrackingSummaryTests.swift`

It goes inside the `struct` and uses its existing `state(…)` helper, whose default `headOID` is
`"a1b2c3d"`:

```swift
    @Test func theHeaderShowsTheOIDOnce() {
        #expect(TrackingSummary.separateOID(for: state()) == "a1b2c3d")
        #expect(TrackingSummary.separateOID(for: state(branch: nil, headOID: "abcdef0")) == nil)
        #expect(TrackingSummary.separateOID(for: state(headOID: "")) == nil)
    }
```

### VM spike — `SwitchyardUITests/0574HeaderAndDiffLayoutUITests.swift`, new

```swift
// 0574HeaderAndDiffLayoutUITests.swift
//
// #0574: at the 900 pt minimum width the hunk buttons stay on one line; a
// long branch name never pushes the header's oid off the window; and a
// detached HEAD shows its oid once, not twice.

import XCTest

final class Spike0574HeaderAndDiffLayoutUITests: XCTestCase {
    @MainActor
    private func shot(_ app: XCUIApplication, _ name: String) {
        let shot = XCTAttachment(screenshot: app.windows.firstMatch.screenshot())
        shot.name = name
        shot.lifetime = .keepAlways
        add(shot)
    }

    /// Drags the window's bottom-right corner to make it `width` wide
    /// (it cannot go below `PaneLayout.windowMinWidth`, 900 pt).
    @MainActor
    private func resize(_ app: XCUIApplication, width: CGFloat) {
        let window = app.windows.firstMatch
        let frame = window.frame
        let corner = window.coordinate(withNormalizedOffset: .zero)
            .withOffset(CGVector(dx: frame.width - 3, dy: frame.height - 3))
        corner.press(forDuration: 0.6, thenDragTo: corner.withOffset(CGVector(dx: width - frame.width, dy: 0)))
        usleep(800_000)
    }

    @MainActor
    private func git(_ arguments: [String]) {
        let process = Process()
        process.executableURL = URL(fileURLWithPath: "/usr/bin/git")
        process.arguments = ["-C", UITestSwitchFixture.repositoryPath] + arguments
        try? process.run()
        process.waitUntilExit()
    }

    @MainActor
    func testTheHeaderAndHunkButtonsFitAtTheMinimumWidth() {
        let app = XCUIApplication()
        app.launchWithSwitchFixture()
        let window = app.windows.firstMatch
        let notes = app.changesRow("notes.txt", staged: false)
        XCTAssertTrue(notes.waitForExistence(timeout: 30), "notes.txt is not listed")
        resize(app, width: 900)
        XCTAssertEqual(window.frame.width, 900, accuracy: 1, "the window did not go to 900 pt")

        // The hunk buttons: one line each, so both are the same height.
        notes.click()
        let discard = window.buttons.matching(NSPredicate(
            format: "title == 'Discard Hunk…' OR label == 'Discard Hunk…'")).firstMatch
        let stage = window.buttons.matching(NSPredicate(
            format: "title == 'Stage Hunk' OR label == 'Stage Hunk'")).firstMatch
        XCTAssertTrue(discard.waitForExistence(timeout: 30), "no Discard Hunk… button")
        XCTAssertTrue(stage.exists, "no Stage Hunk button")
        XCTAssertEqual(discard.frame.height, stage.frame.height, accuracy: 1,
                       "Discard Hunk… wrapped onto two lines at 900 pt")
        shot(app, "0574-hunk-buttons-900")

        // A long branch: the header's oid stays inside the window.
        git(["switch", "-q", "-c", "feature/a-really-long-branch-name-for-the-header-truncation-check"])
        XCUIApplication(bundleIdentifier: "com.apple.finder").activate()
        usleep(1_500_000)
        app.activate()
        let longHeader = app.header(beginningWith: "On branch feature/")
        XCTAssertTrue(longHeader.waitForExistence(timeout: 30), "the header does not show the long branch")
        let oid = app.staticTexts.matching(NSPredicate(format: "value MATCHES %@", "^[0-9a-f]{7}$")).firstMatch
        XCTAssertTrue(oid.waitForExistence(timeout: 10), "the header shows no oid")
        XCTAssertLessThanOrEqual(oid.frame.maxX, window.frame.maxX,
                                 "the header's oid runs past the window's right edge")
        shot(app, "0574-long-branch-900")

        // Detached: the oid once, in the tracking line.
        let base = app.historyRows(containing: UITestSwitchFixture.baseSubject).firstMatch
        XCTAssertTrue(base.waitForExistence(timeout: 30), "no row for the base commit")
        base.tap()
        app.menuBars.menuBarItems["Commit"].click()
        app.menuBars.menuItems["Check Out (Detached)"].click()
        let detached = app.header(beginningWith: "Detached HEAD at ")
        XCTAssertTrue(detached.waitForExistence(timeout: 30), "Check Out (Detached) did not detach")
        let line = (detached.value as? String) ?? detached.label
        let short = String(line.dropFirst("Detached HEAD at ".count))
        let alone = app.staticTexts.matching(NSPredicate(format: "value == %@ OR label == %@", short, short))
        XCTAssertEqual(alone.count, 0, "the detached header shows \(short) a second time")
        shot(app, "0574-detached-900")
    }
}
```

What the spike relies on, measured by the hardening spikes in the VM on 2026-09-30:

- The corner drag takes the 1024 pt window to exactly 900 pt: `(0, 30, 1024, 678)` →
  `(0, 30, 900, 678)`. Asking for 700 pt stays at 900 pt.
- A `git switch -c` in the fixture, followed by deactivating and re-activating the app, shows
  the long branch in the header.
- The detached header reads `Detached HEAD at 3571b01`, with the fixture's 7-character short
  oid. The header oid and the Detail pane's 12-character oid (`3571b01edf7e`) are different
  texts, which is why the regex asks for exactly 7.

### Commands and the lines they must print

- `cd YardKit && swift test` prints `Test run with N tests … passed`, with the YardUITests run one
  higher than before the round.
- `./scripts/run-ui-tests-vm.sh 0574` prints
  `Test Case '-[SwitchyardUITests.Spike0574HeaderAndDiffLayoutUITests testTheHeaderAndHunkButtonsFitAtTheMinimumWidth]' passed`.
- `./scripts/run-ui-tests-vm.sh 0512` (the detached-header assertion `header(beginningWith:
  "Detached HEAD at")`) still passes.

## Mutations the review runs

1. Make `separateOID` return `state.headOID` unconditionally. The unit test fails on its
   detached line, and the spike fails at "shows … a second time".
2. Remove `.fixedSize()` from `HunkView.button(_:)` and the two modifiers from `Text(hunk.header)`.
   The spike fails at "Discard Hunk… wrapped onto two lines".

## Expected behavior

At the 900 pt minimum width:

- The Detail pane's buttons keep their titles on one line.
- The header's tracking line truncates in the middle instead of pushing the oid off the window.
- A detached HEAD's oid appears once.

At normal widths nothing changes visually.
