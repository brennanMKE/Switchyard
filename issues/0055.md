## Description

**The command that makes this project worth building.** An agent pushes a diff into a real macOS UI,
blocks on a human decision, and receives the answer as structured data. No other git tooling does
this. Treat it as the centerpiece, not a nice-to-have.

Returns `{"decision":"approve"|"reject"|"amend","comments":[...],"editedPatch":"..."}` — exit 0 on
approve, 7 on reject.

## Expected behavior

- [ ] `yard review <range|--staged> --wait` blocks until the human decides.
- [ ] The review surface opens **on the tab for that repository**, routed through the focus-or-open rule (#0084) — it never opens a stray window or targets the wrong tab.
- [ ] If the repository has no tab, one is opened and its window brought forward.
- [ ] Reuses the diff rendering from #0082 rather than growing a second diff view.
- [ ] A review pending on one tab does not block interaction with other tabs.
- [ ] All three decisions round-trip, including `amend` carrying an edited patch.
- [ ] Per-hunk and per-line comments are returned as structured data.
- [ ] Exit 3 when the app is not running — never a silent non-interactive fallback.
- [ ] A timeout is available and produces a distinct, documented outcome.
- [ ] The app quitting mid-review is reported as exit 5, not as a rejection.
- [ ] Session survives a long review — minutes, not seconds.

## Planning decisions — settled by Brennan 2026-09-03, binding on the planning pass

1. **The decision envelope is structured + message.** The wire shape already pinned above
   (`{"decision":"approve"|"reject"|"amend","comments":[...],"editedPatch":"..."}`) gains an optional
   free-text `message` field — what the human typed alongside the decision. Closed enum for the
   decision, structured for comments/patch, optional string for the message. No free-text-only shape.
2. **`--timeout N` is the blocking semantics, and every M4 interactive command inherits it.** On
   expiry the agent receives a **typed timeout envelope** at a **distinct exit code** — a new
   `ExitCode` case named at planning time (4 is taken by `requestFailed`; 3/5/7 are taken). The
   default timeout is generous and labelled as a judgement (suggested: 3600 s). A forgotten session
   must not pin an app process forever, and an agent must never hang without a contract.
3. **Sequencing (Brennan, 2026-09-03):** #0055 first, then #0056 + #0059 (both hang off review),
   then #0057 (merge UI — its interaction design comes back for Brennan's sign-off before
   implementation is dispatched), then #0349 + #0058 (sessions/watch), with #0103 reviving only when
   a command actually needs libgit2.
4. **Exit-code vocabulary check for the timeout:** 4 is `requestFailed` — the timeout case must be a
   new `ExitCode` case, not a reuse.
