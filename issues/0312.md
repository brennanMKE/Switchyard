## Description

**Finding 3 of the M1 milestone review, twelfth pass, 2026-08-18 — and unlike the others this one is a
production defect, not only a coverage gap.** `WorktreeEntry.==` **already omits `prunableReason`**, and
nothing detects it.

`YardKit/Sources/YardGit/WorktreeList.swift:64-74`. Deleting `lhs.lockReason == rhs.lockReason &&` from
the operator: **full suite green, 1115 tests** — so no test asserts the operator per field.

**And the pristine operator does not compare `prunableReason` at all.** Two entries differing only in
*why* git says they are prunable compare **equal**.

**Why that matters:** the type's own doc comment records that agents encode session identity into
`lockReason` (#0021), so an equality that ignores such fields can report "unchanged" across a session
handover.

**This is the hand-written-conformance class.** `encode(to:)` and `description` in this codebase *are*
guarded — by `DescriptionCoverageTests` and the wire tests — precisely because a hand-written conformance
silently omitting a member is a known trap here. `==` has no such guard.

## Expected behavior

- [ ] **Decide whether `prunableReason` belongs in `==`, and say why.** It is a real question: if
      `prunableReason` is derived from `prunable` and adds nothing, excluding it is defensible — but then
      the exclusion should be *deliberate and commented*, not silent. Read `WorktreeList.swift` and git's
      porcelain to answer it.
- [ ] Whichever way: **a test that fails when a stored member is dropped from `==`**. A per-field test is
      the minimum; a stored-member scan in the shape of `ConformanceScan.swift` is better and is what the
      review recommends, since it catches the *next* field too.
- [ ] **Mutation:** drop `lockReason` from the operator. The test must redden. Then drop a second field
      and confirm the same.
- [ ] `cd YardKit && swift test` **twice, in the foreground with an explicit 900000 ms timeout**, both
      green, above the count in `docs/test-baseline.txt`.

## The files

`YardKit/Sources/YardGit/WorktreeList.swift` if `prunableReason` should be compared, and
`YardKit/Tests/YardGitTests/WorktreeListTests.swift`.
