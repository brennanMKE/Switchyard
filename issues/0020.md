## Description

A structured superset of `git worktree list --porcelain -z`, plus what agents actually need: dirty
state, ahead/behind, in-progress operation, attached agent session, and journal depth.

Always parse the `-z` porcelain form. Agent-created worktree paths are machine-generated and will
eventually contain a newline or something equally awkward; the NUL-terminated form is documented as
stable across git versions and independent of user configuration.

## Expected behavior

- [ ] New file `YardKit/Sources/YardGit/WorktreeList.swift`. Create it; do not restructure existing files.
- [ ] Parses `--porcelain -z`, never the human-readable form.
- [ ] Boolean attributes (`bare`, `detached`, `locked`, `prunable`) handled as label-only lines.
- [ ] Lock reason surfaced, since #0021 encodes agent sessions there.
- [ ] A worktree path containing a newline round-trips correctly.
- [ ] Prunable worktrees are flagged with git's stated reason.
- [ ] Tests use **swift-testing** — `import Testing`, `@Test`, `#expect`. Not XCTest. `swift test`'s summary line counts only swift-testing tests, so an XCTest file passes invisibly.
- [ ] `cd YardKit && swift build` succeeds, and `swift test` prints a `Test run with N tests` line you paste. N must be greater than the count on `main` before this change.
