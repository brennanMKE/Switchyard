## Description

Split out of #0012, whose round 1 timed out partly on breadth.

Git refuses to check out a branch that another worktree already has. That is free mutual exclusion
between agents — `docs/switchyard-development-guide.md` treats worktrees as the unit of agent
isolation for exactly this reason. But the refusal is only useful if the caller can find out **which**
worktree holds the branch, rather than just being told no.

## Givens — verified on `main`, treat as true

1. New file `YardKit/Sources/YardGit/SiblingWorktree.swift`.
2. **Enumerate worktrees with `git worktree list --porcelain`**, not by walking a `worktrees`
   directory with `FileManager`. Round 1 of #0012 walked the directory and read sibling `HEAD` files
   directly; both are wrong on a reftable repository and in a linked worktree.
3. Each porcelain record carries `worktree <path>`, `HEAD <oid>` and `branch <ref>` (absent when
   detached). The **first** record is always the main worktree.
4. `WorktreeContext` has **no** memberwise init and **no** nested `WorktreeInfo` type — round 1
   invented both. It is built by `WorktreeContext.resolve(...)`. Declare whatever sibling type you
   need in your own file.
5. `GitProcess` is a concrete struct — `GitProcess()`, `run(_:at:)`, `capture(...)`. No protocol.
6. `FixtureRepository.addWorktree(named:branch:)` builds a real linked worktree for the tests.

## Expected behavior

- [ ] Given a branch name, report which worktree holds it, if any — the **path**, not merely a
      boolean.
- [ ] Reports nothing for a branch no worktree has checked out.
- [ ] Correct when called from the main worktree and from a linked one.
- [ ] A detached worktree is not reported as holding any branch.
- [ ] Tested against both ref formats via `FixtureRepository`.
- [ ] Tests use **swift-testing** — `import Testing`, `@Test`, `#expect`. Not XCTest.
- [ ] `cd YardKit && swift build` succeeds and `swift test` prints a `Test run with N tests` line you
      paste. **N must be greater than the count on `main` before this change** — state both numbers.

## Tests must be able to fail

Build a fixture with a linked worktree on a known branch, assert the reported path is that worktree,
then **assert it is not the current one**. A function returning the caller's own path would satisfy a
weaker test — that exact mistake was the mutation #0094 was checked against.
