## Description

Wrap the canonical skill in Claude Code's plugin layout so it installs with two commands instead of
being copy-pasted, **without a second copy of the skill body**.

Guide §11 decision 31 fixes the layout: **`skills/switchyard/` is the plugin root.** It already holds
`SKILL.md`; this issue adds `skills/switchyard/.claude-plugin/plugin.json` beside it, and a
marketplace manifest at the repository root, `.claude-plugin/marketplace.json`, whose one plugin has
`"source": "./skills/switchyard"`. So the GitHub repository is the marketplace, and installing copies
only that directory. The README gets the install instructions, including the one-line fallback for
OpenCode and any other agent (which is all of #0069 that is worth doing; see there).

One deliverable: **the two manifests** (with the test that pins them and the README section that
tells a human how to use them).

## Givens — the plugin format, checked against Claude Code's documentation on 2026-09-29

From the plugin manifest, marketplace and plugin-loading references at code.claude.com/docs:

- A plugin's manifest is `.claude-plugin/plugin.json` at the plugin root; only `name` is required.
  **"A plugin with `SKILL.md` at its root, no `skills/`, and no `skills` key loads as a single
  skill."**
- A marketplace is `.claude-plugin/marketplace.json` at the marketplace root; required `name`,
  `owner.name`, `plugins[]` with `name` and `source`. A relative `source` resolves from the
  marketplace root. The marketplace name may equal the plugin name; `switchyard` is not reserved.
- A marketplace added from a **local directory** loads a relative-path plugin **in place** (edits
  apply at next session start or `/reload-plugins`). Any other marketplace, GitHub included, copies
  **only the plugin directory** into the plugin cache. Symlinks leading outside the plugin are
  rejected at load — which is why the plugin root is the skill's own directory rather than a
  separate directory linking to it.
- With no `version` in `plugin.json`, a git-hosted plugin is versioned by its commit SHA, so every
  regenerated skill reaches `claude plugin update`. (Setting `version` would freeze installs until
  someone bumps it; the test below forbids it.)

Measured locally on the prototype (`../sy-plan-0066`), without touching `~/.claude`:

- `claude plugin validate .` → `✔ Validation passed with warnings`, exit 0. The one warning is
  `plugins[0] plugin.json → version: No version specified`, which is the intended state.
- `claude plugin validate skills/switchyard` → same, exit 0, the same single warning.
- `claude --plugin-dir ./skills/switchyard plugin list --json` includes
  `{"id": "switchyard@inline", "scope": "session", "enabled": true, "installPath": "…/skills/switchyard"}`
  — the plugin loads. (`--plugin-dir` loads a plugin for that one invocation and installs nothing.)
- The repository-root-as-plugin alternative (`"source": "./"`) was tried and rejected: `validate`
  warns that the root `CLAUDE.md` is not loaded as plugin context, and the plugin would be the
  whole checkout.
- `git check-ignore` ignores none of the new paths. The GitHub repository is public.

### 3. `YardKit/Tests/YardKitTests/SkillPluginTests.swift` — new file, exactly this

```swift
// SkillPluginTests.swift — the Claude Code plugin wrapping the skill (#0068)

import Foundation
import Testing
@testable import YardKit

/// The repository root, from this file's compile-time path.
private let repositoryRoot = URL(fileURLWithPath: #filePath)
    .deletingLastPathComponent()   // YardKitTests
    .deletingLastPathComponent()   // Tests
    .deletingLastPathComponent()   // YardKit (package root)
    .deletingLastPathComponent()   // repository root

private func jsonObject(at relativePath: String) throws -> [String: Any] {
    let data = try Data(contentsOf: repositoryRoot.appendingPathComponent(relativePath))
    return try #require(try JSONSerialization.jsonObject(with: data) as? [String: Any],
                        "\(relativePath) must be a JSON object")
}

/// Guide §11 decision 31: the plugin root is `skills/switchyard/` itself, so
/// the plugin ships the one canonical SKILL.md and nothing else.
@Suite("Claude Code plugin")
struct SkillPluginTests {

    @Test("the marketplace lists one plugin whose source is the skill directory")
    func marketplacePointsAtTheSkillDirectory() throws {
        let marketplace = try jsonObject(at: ".claude-plugin/marketplace.json")
        #expect(marketplace["name"] as? String == ServiceNames.cliName)
        let owner = try #require(marketplace["owner"] as? [String: Any])
        #expect(!(owner["name"] as? String ?? "").isEmpty)
        let plugins = try #require(marketplace["plugins"] as? [[String: Any]])
        #expect(plugins.count == 1)
        #expect(plugins.first?["name"] as? String == ServiceNames.cliName)
        #expect(plugins.first?["source"] as? String == "./skills/switchyard")
    }

    @Test("the plugin manifest names the plugin and carries no version")
    func pluginManifestNamesThePlugin() throws {
        let manifest = try jsonObject(at: "skills/switchyard/.claude-plugin/plugin.json")
        #expect(manifest["name"] as? String == ServiceNames.cliName)
        // No version: Claude Code then versions a git-hosted plugin by commit
        // SHA, so every regenerated SKILL.md reaches installs without a bump.
        #expect(manifest["version"] == nil)
    }

    @Test("the plugin directory holds exactly SKILL.md and its manifest — no second copy")
    func pluginHoldsOnlyTheCanonicalSkill() throws {
        let fm = FileManager.default
        // Finder's .DS_Store is not content; everything else is.
        func entries(_ relativePath: String) throws -> [String] {
            try fm.contentsOfDirectory(atPath: repositoryRoot.appendingPathComponent(relativePath).path)
                .filter { $0 != ".DS_Store" }.sorted()
        }
        #expect(try entries("skills/switchyard") == [".claude-plugin", "SKILL.md"])
        #expect(try entries("skills/switchyard/.claude-plugin") == ["plugin.json"])
        #expect(try entries("skills") == [ServiceNames.cliName])
        #expect(try entries(".claude-plugin") == ["marketplace.json"])
    }
}
```
