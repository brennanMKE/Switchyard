# 0010 — Declare command metadata as data, driving help, schemas, and the skill

## Description

Command names, flags, exit codes, and response schemas are declared in one place as data, not spread
across `switch` statements. Three consumers derive from it: `--help`, the JSON schema output, and the
generated agent skill (#0068).

Deciding this late means retrofitting every command, and a hand-maintained skill drifts from the
binary within a milestone. A skill that lies about flags is worse than no skill.

## Expected behavior

- [ ] Every command declares its name, summary, flags, exit codes, and response schema in one structure.
- [ ] `yard --help` and `yard <cmd> --help` render from it.
- [ ] `yard schema [<command>] --json` emits the response schemas from the same source.
- [ ] A test asserts every registered command has a schema and at least one documented exit code.
- [ ] Adding a command with no documentation fails the build or a test, not review.
