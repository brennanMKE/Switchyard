## Description

**Finding 2 of #0160's fourth umbrella review, 2026-08-17.**

`JournalCheckpoint.around`'s guard asks whether **a** resumable operation is live in the worktree, not
whether **this body** left one. So any `around` call that throws while an earlier operation's rebase is
still in flight **overwrites that operation's entry id with its own**.

Established by probe:

```
conflicting Fixup.run    -> slot = entry A, rebase live
second Fixup.run         -> its `git commit --fixup=` refuses the unmerged index,
                            so no rebase of its own ever starts; it throws
around's catch           -> sees rebase #1 still live, writes entry B

slotAfterFirst=…45T   slotAfterSecond=…F5   CLOBBERED=true
```

Resolving and continuing rebase #1 then lands the mapping on **B**; `A.rewrite == nil`, and the
pre-operation `HEAD` is reachable from **no** stored mapping — which is exactly what #0234 existed to
guarantee.

**The uncovered quadrant is the common one.** `anUnrelatedSuccessfulOperationBetweenAConflictAndIts
ContinueDoesNotClobberTheSlot` pins the *successful* unrelated operation; while a rebase is in
progress, most operations **fail** — the index is unmerged, so anything that stages or commits refuses.

## Expected behavior

- [ ] A second operation cannot claim an occupied slot. **First-writer-wins** (do not write when the
      file already exists and names a live operation) or key the file to the operation — say which you
      chose and why.
- [ ] The probe above becomes a test: conflicting `Fixup.run`, a second `Fixup.run` that throws, then
      continue the first — the mapping lands on the **first** entry, and its pre-operation `HEAD` is
      reachable through the stored mapping, as #0234's test asserts for the single-operation case.
- [ ] `anUnrelatedSuccessfulOperationBetweenAConflictAndItsContinueDoesNotClobberTheSlot` still passes
      unchanged. Say that you ran it.
- [ ] Mutation: restore the unconditional write and confirm the new test reddens.
- [ ] `cd YardKit && swift test` **twice, in the foreground**, both green, **N greater than 1044**.
