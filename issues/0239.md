## Description

**Found while reviewing #0163, 2026-08-17, and filed rather than spending that issue's third round.**

`GitProcess.waitWithDeadline` escalates `SIGTERM` → grace period → `SIGKILL`. **The `SIGKILL` half is
not pinned.** Replacing the escalation with `process.terminate()` alone leaves
`childIgnoringSigtermIsStillKilled` **passing** — in 60 seconds instead of about 2, because the fake
child's own `sleep 60` ends it eventually. The regression shows only as a wall-clock blowup in the log,
and `AGENTS.md` Rule 7c rightly forbids asserting elapsed time.

That escalation is the whole reason the timeout is not just `terminate()`: a child that traps `SIGTERM`
— which is the shape of a pinentry dialog, the case this exists for — survives it. Measured
2026-08-17: `trap '' TERM; sleep 60` needs the `SIGKILL`.

## The shape of a fix

**Assert the signal, not the clock.** A child killed by `SIGKILL` reports `terminationStatus == 9` and
one killed by `SIGTERM` reports `15`, both with `terminationReason == .uncaughtSignal` — measured in
#0163. `Failure.timedOut(after:arguments:)` carries neither today.

The straightforward option is to add the status to the error:

```swift
case timedOut(after: Duration, arguments: [String], terminationStatus: Int32)
```

which is also better diagnostics in production — "the helper ignored SIGTERM and had to be killed" is
worth knowing in a log. Then the test asserts **9** for the trapping child and **15** for the ordinary
one, deterministically and with no timing.

If that error shape is unwelcome, an equivalent is to expose the status through a test seam. Either
way the assertion must distinguish the two signals; anything that only checks *that* it failed will
keep passing under the mutation.

## Expected behavior

- [ ] The escalation to `SIGKILL` is pinned by an assertion that distinguishes it from `SIGTERM`.
- [ ] `childIgnoringSigtermIsStillKilled` **reddens** when the escalation is replaced by
      `terminate()` alone — run that mutation and report it, since it is the whole point.
- [ ] The ordinary (non-trapping) child's test asserts the `SIGTERM` status, so the two cases are
      distinguished rather than both accepting anything.
- [ ] No test asserts elapsed time (Rule 7c).
- [ ] `cd YardKit && swift test` twice in the foreground, both green, **N greater than 1021**.
