## Description

The app has no icon — `Switchyard/Assets.xcassets/AppIcon.appiconset/` holds only the stock Xcode
template `Contents.json`, and its entries are **iOS** idioms on a macOS-only app. `Switchyard.png` at
the repo root is the artwork.

`~/bin/icongen` generates a complete `.appiconset` from a single source image:

```
icongen [-p <platforms>] [-o <output>] <source.png>
  -p   Comma-separated: iOS,iPadOS,macOS,tvOS or "all"  (default: all)
  -o   Output directory                                  (default: ./Assets.xcassets)
```

**Prerequisite: `icongen` requires a 1024×1024 source, and `Switchyard.png` is 1254×1254.** It must be
downscaled first — `sips -z 1024 1024` or equivalent. Downscale from the original rather than any
intermediate, and do not upscale.

Switchyard is macOS-only (guide §1 non-goals), so generate for **macOS only** — not `all`.

## Expected behavior

- [ ] `Switchyard.png` (1254×1254) is committed at the repo root as the source of record.
- [ ] A 1024×1024 downscale is produced from it and used as `icongen`'s input.
- [ ] `icongen -p macOS` output replaces `Switchyard/Assets.xcassets/AppIcon.appiconset/` entirely — the iOS-idiom template entries must be gone.
- [ ] The regenerated `Contents.json` contains **only** macOS idiom entries, and every filename it references exists in the directory.
- [ ] `xcodebuild build -project Switchyard.xcodeproj -scheme Switchyard -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO -quiet` succeeds — paste the output.
- [ ] The build emits no asset-catalog warnings about missing or mismatched icon sizes.
- [ ] Record the exact `icongen` command used in the resolution, so the set can be regenerated when the artwork changes.

## Notes

Blocked by nothing. `icongen` is at `~/bin/icongen`; run `-h` for current usage rather than trusting
this transcription.

**Do not hand-write `Contents.json`.** Regenerate it with the tool — a hand-edited catalog drifts from
the files on disk and fails at build time rather than at edit time.

**Do not touch signing settings.** An icon change never requires them; see `CLAUDE.md`.
