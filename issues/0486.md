## Description

`ResolveCardView.sideDiff(label:path:text:)` (`YardKit/Sources/YardUI/ResolvePane.swift`, line
882) wraps one side of a conflict, which is file content, as context lines. It splits with
`text.split(separator: "\n", …)`, on the `"\n"` **Character**. Swift reads `"\r\n"` as one
Character, so a CRLF file's side is one body line.

Measured 2026-09-29 on `main`, `sideDiff(label: "Ours", path: "f.txt", text: "a\r\nb\r\n")`:

- **before:** `body == [" a\r\nb\r\n"]`, `oldCount == 1`.
- **after:** `body == [" a\r", " b\r", " "]`, `oldCount == 3`. That is the same shape an LF side
  already gets (`"a\nb\n"` gives `[" a", " b", " "]`). The trailing empty piece is existing
  behaviour and is not changed here.

The existing test `ResolvePaneTests` (line ~501) compares against a Character split of an LF-only
side, and still passes: for text with no CR, the two splits agree.

## The files

### 1. `YardKit/Sources/YardUI/ResolvePane.swift`

Replace

```swift
        let lines = text.split(separator: "\n", omittingEmptySubsequences: false).map { " \($0)" }
```

with

```swift
        // The newline *scalar*: a CRLF side's "\r\n" is one `Character`, so
        // a Character split left the whole side as one line (#0486, measured).
        let lines = text.unicodeScalars.split(separator: "\n", omittingEmptySubsequences: false)
            .map { " \(Substring($0))" }
```

### 2. `YardKit/Tests/YardUITests/ResolvePaneTests.swift`

Insert this block **inside `struct ResolvePaneTests`**, immediately before the line `    // MARK: - Helpers`:

```swift
    // MARK: - #0486: a CRLF side

    /// A conflict side is file content, and a CRLF file's "\r\n" is one
    /// `Character`, so the "\n" Character split left the whole side as one
    /// body line (measured on `main`: `body == [" a\r\nb\r\n"]`).
    @Test func aCRLFSideSplitsIntoOneBodyLinePerLine() throws {
        let diff = ResolveCardView.sideDiff(label: "Ours", path: "f.txt", text: "a\r\nb\r\n")
        let hunk = try #require(diff.hunks.first)

        #expect(hunk.body == [" a\r", " b\r", " "])
        #expect(hunk.oldCount == 3)
    }
```
