## Description

**Finding 2 of the M1 milestone review, eleventh pass, 2026-08-18.** Nothing pins where `log`'s trailer
block **ends**.

`YardKit/Sources/YardGit/CommitLog.swift:307`, `} else { break }` → `} else { continue }`: survived the
**full suite**.

**Measured rather than reasoned** — the review ran `parseTrailerBlock` both ways on a five-line body:

| | trailers |
|---|---|
| pristine | `["Fixes"]` |
| mutant | `["Fixes", "Note"]` |

**Body prose after the trailer block is reported as a trailer.** And `trailers` drives `agentOnly`
filtering, so this changes **which commits `log` returns** — not merely what it says about them.
