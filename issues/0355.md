# 0355 — Remove the empty SwitchyardUITests target (template residue)

| | |
|---|---|

## Description

`Switchyard.xcodeproj` declares a `SwitchyardUITests` native target whose
`PBXFileSystemSynchronizedRootGroup` points at `path = SwitchyardUITests` — a directory that does
not exist on disk. Xcode therefore shows the folder empty, and the target builds an empty
`.xctest` bundle. It is stock-template residue from #0045 that was never populated: the repo's
actual UI-layer tests live in `YardKit/Tests/YardUITests/` (swift-testing, run by `swift test`),
and AGENTS.md's build commands already note UI tests cannot run headless here.

## Expected behavior

- [ ] The `SwitchyardUITests` target, its synchronized group, its product reference, and its
      build-configuration list are removed from the project (Xcode GUI delete is the safe route;
      a pbxproj edit must be verified by a clean build of every remaining target).
- [ ] `xcodebuild build -scheme Switchyard … CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO`
      still succeeds and `swift test` is unchanged.
- [ ] AGENTS.md's build-commands section no longer references `-only-testing:SwitchyardTests`'s
      empty sibling.

## Notes

Cosmetic-to-build-health, not a runtime defect — it does not affect the app's behavior. Filed
because a user opening the project reads the empty folder as "this project is broken".
