## Description

**Child of #0358, split 2026-09-12.** One deliverable: the window title names the open repository,
so two windows can be told apart. Moved verbatim from #0358's first planning update.

### Change (*not compiled*)

No `navigationTitle` exists anywhere in `YardKit/Sources/YardUI` or `Switchyard/` (*measured*,
grep). On `ContentView.body`'s outer `Group`:

```swift
.navigationTitle(repositoryPath.map { URL(fileURLWithPath: $0).lastPathComponent } ?? "Switchyard")
.navigationSubtitle(summary.map { $0.whereAmI.branch ?? "detached HEAD" } ?? "")
```

The title is the folder name, so two windows are told apart in Mission Control, the Window menu
and ⌘\` cycling — the failure the Expected behavior measured.

## Expected behavior

- [ ] With a repository open, the window title is its folder name and the subtitle is the current
      branch, or "detached HEAD".
- [ ] With nothing open, the title reads "Switchyard".
- [ ] A reviewer opens two repositories and confirms the Window menu lists them by name, with a
      window capture per `docs/windows-command.md`. There is no unit-testable logic here.
