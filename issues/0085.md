## Description

One file, one type, no behaviour. `CommandSpec` is the declarative description of a `yard` command:
its name, one-line summary, flags, exit codes, and the name of its response schema.

This is the data that #0086 renders as `--help`, #0087 emits as JSON schemas, and #0066 generates the
agent skill from. Splitting it out first means each of those has a fixed shape to build against.

## Expected behavior

- [ ] New file `YardKit/Sources/YardKit/CommandSpec.swift`. Touch nothing else.
- [ ] `struct CommandSpec` with: `name: String`, `summary: String`, `flags: [FlagSpec]`, `exitCodes: [ExitCodeSpec]`, `schemaName: String`.
- [ ] `struct FlagSpec` with: `long: String`, `short: Character?`, `argument: String?` (nil means boolean), `help: String`.
- [ ] `struct ExitCodeSpec` with: `code: Int32`, `meaning: String`.
- [ ] All types `Sendable` and `Equatable`. No global mutable state, no `Atomic`, no actors.
- [ ] New test file asserting a hand-built `CommandSpec` round-trips its fields and compares equal to an identical one.
- [ ] `swift build` succeeds and `swift test` prints a `Test run with N tests` line you paste.

## Notes

Split out of #0010, which timed out as one round. Blocked by #0006 (done).

## Review — round 1 accepted, with a spec defect corrected

The implementation is correct: all three types with the specified fields, `Sendable` and `Equatable`,
no global mutable state, and a real test file. **54 tests pass**, and the round's own log contains the
passing run — no fabricated claim this time.

**The model found a genuine defect in this issue.** `yard` is an `executableTarget`, so
`@testable import yard` does not link in SwiftPM — the file could not live at
`YardKit/Sources/yard/CommandSpec.swift` *and* be unit-tested. It hit the link failure, relocated the
file to the `YardKit` library target, and everything built. The relocation was the right call and the
issue text has been corrected to match.

**Its one fault was editing this issue file** — flipping the checkboxes, changing `Module`, and
rewriting the path — rather than stopping and reporting the block as `AGENTS.md` rule 5 requires. The
edits were reverted and reapplied deliberately by the reviewer.

Accepted.
