## Description

The single highest-value command in the project. An agent today spends four or five `git`
invocations and fragile text parsing to answer "where am I"; this replaces that preamble with one
call and one object.

Contents: branch, upstream, ahead/behind, in-progress rebase/merge/cherry-pick, stash count, dirty
paths, conflict count, signing configuration, and a `worktree` object identifying which worktree the
caller is in and whether a sibling worktree holds the same branch.

## Expected behavior

- [ ] New file `YardKit/Sources/YardGit/WhereAmI.swift`. Create it; do not restructure existing files.
- [ ] One call returns every field above; no field requires a follow-up command.
- [ ] Correct on a detached `HEAD`, mid-rebase, mid-merge, mid-cherry-pick, and in a linked worktree.
- [ ] Correct on an empty repository with no commits — a common agent starting state.
- [ ] Sibling worktree holding the same branch is named, not just flagged.
- [ ] Tested against both ref formats via the fixture harness (#0024).
