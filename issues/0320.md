## Description

**Finding 3 of the M1 milestone review, thirteenth pass, 2026-08-18.** `CommitLogEntry.refs` is silently
truncated by `log.excludeDecoration`.

`YardKit/Sources/YardGit/CommitLog.swift:154` (`%D` in `formatString`), reached from `:164`. **Measured
through the engine**, with tag `v1` on `HEAD`:

```
PROBE refs default:            HEAD -> main, tag: v1
PROBE refs excludeDecoration:  HEAD -> main
```

`%D` obeys `log.excludeDecoration`; the engine passes no `--decorate-refs` or
`-c log.excludeDecoration=`, and no test sets the config.

**Lower blast radius than #0318 and #0319** — the config is uncommon — but the same class, and `refs` is
a documented payload field an agent reads.

## Work log

- **Round 1 — 2026-08-18, Sonnet subagent, 127,644 tokens, 25m40s, accepted.** The longest M1 round of
  the session, and the time went where it should have: **both fixes the issue proposed were wrong, and
  it measured its way to that.**
  - `-c log.excludeDecoration=` **does not clear** the exclude list — it *adds* an empty pattern, which
    drops every decoration. Strictly worse than doing nothing, and the issue had asserted it as the
    obvious fix.
  - `--decorate-refs=*` switches git from its default candidate set to an **explicit accept-list over all
    refs**, so it restored the tag *and* newly decorated Switchyard's own journal anchor refs — breaking
    `commitLogDecorationsNeverCarryJournalRefs`, **caught only by running the full suite** rather than a
    filtered one.
- **The form it landed reproduces git's default candidate set explicitly** — `HEAD`, `refs/heads/*`,
  `refs/remotes/*`, `refs/stash`, `refs/tags/*` — measured byte-for-byte against a config-free
  repository, with and without the config set.
- **Reviewed by re-running.** Full suite twice on the merged result, both `Test run with 1135 tests in
  80 suites passed`. **My first attempt at the mutation did not compile** — emptying the array left an
  untyped literal — which is trap two; caught at the build step rather than reported as a survivor.
