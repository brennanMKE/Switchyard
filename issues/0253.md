## Description

**Finding 1 of #0160's fourth umbrella review, 2026-08-17 — the highest-ranked of three.**

**#0241 amended the *write* side of the in-flight entry-id file. The *read* side was never amended.**
`JournalCheckpoint.inFlightEntryID` validates only that the file's id is still a **live journal
entry** (`JournalAnchor.list(...).contains`) — never that the operation it names is still in progress.

Guide §11 **decision 19**, as amended, says the file *"names an operation that is still in progress,
not merely an entry that still exists"*. **The read path implements exactly the sentence the decision
rejects.**

`Fixup.clearInFlightFile` does not cover this: it fires only on the abort arms **`switchyard` itself**
runs. `Fixup.run` throwing `.blockedOnConflicts` deliberately hands the rebase to the caller, and the
caller running `git rebase --abort` is the **documented alternative** to continuing.

Established by probe — real fixture, real hook, real subprocesses:

```
conflicting Fixup.run          -> slot names entry A, rebase live
user runs `git rebase --abort` -> slot still present = true
unrelated `git commit --amend` -> attachRewrite(decision, entryID: nil) returns A
                                  A.rewrite != nil
```

That is **verbatim #0241's stated symptom** — *"an abandoned fixup's file is consumed by a later
unrelated rewrite"* — reached through the user-abort path instead of `Fixup`'s own.

## Expected behavior

- [ ] `inFlightEntryID` requires a **live resumable operation** before trusting the file — the same

- [ ] The probe above becomes a test: conflicting `Fixup.run`, an out-of-band `git rebase --abort`,
      then an unrelated own rewrite attaches **nothing** and the file is gone.
- [ ] The existing `aConflictingFixupResolvedAndContinuedAttachesToItsPreOperationEntry` still passes —
      a *continued* rebase is still live at attach time, so tightening the read must not break it. Say

      line you meant.
- [ ] `cd YardKit && swift test` **twice, in the foreground**, both green, **N greater than 1044**.
