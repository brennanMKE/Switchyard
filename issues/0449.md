# 0449 — Command specs carry no positional-argument usage, so --help and the skill omit `<commit>` and friends

## Description

Found by the #0066 planner. `CommandSpec` has flags but no positional-argument metadata, so
arguments such as `<commit>` in `reword <commit> --message <m>` reach `--help` and
`skills/switchyard/SKILL.md` only through each command's exit-code-1 text. An agent reading the
skill has to infer the argument shape from an error description.

## Expected behavior

- [ ] `CommandSpec` gains a `usage` (synopsis) field, filled for every registered command.
- [ ] `HelpRenderer` and `renderSkill()` print it; the skill and schema goldens are regenerated.
- [ ] A test fails if any registered command that takes positional arguments has an empty usage.

Needs an Opus planning pass before dispatch.
