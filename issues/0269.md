## Description

**Finding 2 of the M1 milestone review, fifth pass, 2026-08-18.** `log`'s parsed `author` field is
**never asserted anywhere in the suite** — not at its zero value, not at all.

```swift
// CommitLog.swift:230
let author = ""            // was: let author = String(parts[2])
```

`✔ Test run with 1074 tests in 78 suites passed after 129.766 seconds.` — full suite.

**Established by search, not by assumption:** `grep -rn "\.author" YardKit/Tests/` returns only
`BlameTests.swift`, which is a different type (`BlameLine.author`). Inside `CommitLogTests.swift` the
word `author` appears exactly twice — line 91, inside a raw-commit heredoc, and line 126, in a comment.
`LogGraphWireTests` passes `author: "Ada Lovelace"` to the **public memberwise initializer**, so that
value never travels through `CommitLog.parse`.

So the field-index wiring `parts[2]` → `author` has no test that can fail. `%an` could be dropped from
`formatString`, mis-indexed against `%P` or `%G?`, or blanked, and `log` still passes.

**This is stronger than the zero-value shape the four prior passes found**: the field is not asserted at
all, so there is nothing even to strengthen.

## Expected behavior

- [ ] A named test in `YardKit/Tests/YardGitTests/CommitLogTests.swift` that commits with a **known,
      distinctive author** — the fixture already controls `user.name`/`user.email`, so set something
      that cannot collide with a default — and asserts `entry.author` equals it.
- [ ] **Assert it against a commit whose author differs from the committer**, using
      `GIT_AUTHOR_NAME`/`GIT_AUTHOR_EMAIL` on that one commit. `%an` and `%cn` are adjacent concepts and
      a fixture where they are equal cannot tell a `%cn` mis-index from a correct `%an`.
- [ ] **Mutation 1:** `let author = ""` at `CommitLog.swift:230`. Must redden.
- [ ] **Mutation 2:** shift the index — `String(parts[3])` — which is the realistic regression. Must
      redden. Confirm each landed where you meant.
- [ ] `cd YardKit && swift test` **twice, in the foreground**, both green, above the count in
      `docs/test-baseline.txt`.
