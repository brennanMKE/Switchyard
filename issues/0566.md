## Description

Guide §11 decision 45. A borderless **Co-Author** menu at the left of the row above the message
editor (where Stash Changes… already sits on the right). Its items are `CoAuthors.recent` (#0559):
recent authors and people already credited, newest first, without the user. Picking one runs
`MessageTrailers.adding` (#0560) on the current message — git decides where the line goes — and puts
the result in the editor, where the user sees it and can edit it. Nothing is hidden and passed at
commit time; the trailer is ordinary message text, so `commit-msg` hooks and signing see it like any
other line.

- The list reloads with the Amend target on every refresh (`.task(id: revision)`): a commit can bring
  a new author. 0.06 s on git/git, off the main actor.
- **A keystroke typed while git runs is never overwritten**: the result is applied only if the
  editor still holds the message that was sent.
- Disabled while the list is empty (help: "No one else has committed here recently") and while an
  action runs.

Measured in the VM with the prototype (#0568's spike): the menu offered `Bob Quinn
<bob@example.com>` (credited only by a trailer) above `Ann Lee <ann@example.com>` (an author), and
picking Ann turned `0568 a subject…` into `0568 a subject…\n\nCo-authored-by: Ann Lee
<ann@example.com>\n`. The row fitted the default Detail pane with #0567's menu beside it.

No new unit test: the list and the insertion are #0559's and #0560's, tested there; the view wiring
is checked in the VM by #0568.

/// #0566: who the Co-Author menu offers.
@concurrent
public func loadCoAuthors(at path: String) async throws -> [CoAuthors.Person] {
    try CoAuthors.recent(at: path)

/// #0566: `message` with `trailer` added where git puts it.
@concurrent
public func addingTrailer(_ trailer: String, to message: String, at path: String) async throws -> String {
    try MessageTrailers.adding(trailer, to: message, at: path)
}
```

    /// #0566: Co-Author, which adds `Co-authored-by: Name <email>` to the
    /// message (guide §11 decision 45).
    private var coAuthorMenu: some View {
        Menu("Co-Author") {
            ForEach(coAuthors, id: \.self) { person in
                Button(person.identity) { addCoAuthor(person) }
            }
        }
        .menuStyle(.borderlessButton)
        .controlSize(.small)
        .fixedSize()
        .disabled(coAuthors.isEmpty || isBusy)
        .help(coAuthors.isEmpty
            ? "No one else has committed here recently"
            : "Credit someone with a Co-authored-by trailer")
        .accessibilityIdentifier("co-author-menu")
    }

    /// #0566: adds `person`'s trailer where git puts it. The editor is only
    /// changed if it still holds what was sent: a keystroke typed while git
    /// ran is never overwritten.
    private func addCoAuthor(_ person: CoAuthors.Person) {
        let sent = draft.message
        Task {
            guard let updated = try? await addingTrailer(person.trailer, to: sent, at: repositoryPath),
                  draft.message == sent else { return }
            draft.message = updated
        }
    }

    /// "N files staged", prefixed while amending with the commit it replaces.
```
