## Description

Last child of #0425. Guide §11 decision 29's **Merged** bullet is the spec. Merged branches are
dimmed, not hidden, using decision 27's composite unchanged.

- `CommitHistoryView` gains `repositoryPath: String? = nil`. `ContentView` passes its
  `repositoryPath`: one more line in the `CommitHistoryView(` call, after #0428's `branchTips:`.
- A `.task` keyed on the path and the lanes' local branches reads `BranchStatus.read`, limited to
  those branches. It publishes the ancestry and upstream-gone answers at once, then again after
  `BranchStatus.contentPass`, which runs only for the lanes shown.
- `BranchMapLayout.mergedBranches(in:content:)` turns that into short names.
  `BranchMapLayout.dimmedLanes(mergedBranches:)` dims a lane with a parent whose local branches are
  **all** merged. A root lane never dims; it carries every branch sitting at the default's tip, some
  of them merged by ancestry. A remote-only lane never dims, and *unknown* does not dim.
- A dimmed lane draws at opacity 0.35: its vertical, connector, nodes, stub marker and fold. Its
  label draws at 0.45 and its accessibility label ends in `" (merged)"`.

**The fixture changes.** `origin/map-main` and `origin/HEAD` → `origin/map-main` give the map
fixture a default branch. Without them `BranchStatus` falls back to the literal `main`, which does
not exist, and nothing answers merged. `squash-landed` is added off "map base 04"; it re-adds
exactly `file-5.txt`, the file "map base 05" added, which makes it a squash landing.

**Measured on this exact code, 2026-09-26, planning worktree.** A throwaway test ran
`BranchStatus.read`, then `contentPass` limited to the 2-week lanes, then the two new functions:

| repository | lanes (2 weeks) | read + content pass | merged | dimmed lanes |
|---|---|---|---|---|
| map fixture | 32 | 0.28 s | 3 (`map-main`, `merged-old`, `squash-landed`) | 2: `squash-landed`, `merged-old` |
| Switchyard (with #0431's fix) | 51 | 0.62 s | 19 | 18 |

`git merge-tree --write-tree map-main squash-landed` printed `706d0a11…`, equal to
`git rev-parse map-main^{tree}`. Under 2 weeks on Switchyard, 32 lanes stay undimmed, many of them
squash-landed issue branches. Decision 27's content check calls them not-merged or *unknown*
because `main` has since changed the same files. That is the composite's known limit (#0373), not
a defect here.

**Mutations run against the tests below**, each reverted after:

| mutation | tests that fail |
|---|---|
| drop `header.parentLane != nil,` in `dimmedLanes` (root may dim) | `aLaneDimsOnlyWhenEveryLocalBranchOnItIsMergedAndNeverTheRoot` |
| `locals.allSatisfy(…)` → `locals.contains(where: …)` | same |
| drop the `case .merged` guard in `mergedBranches` | `mergedBranchesFollowDecision27sCompositeAndLeaveOutUnknown` |
