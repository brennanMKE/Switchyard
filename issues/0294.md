## Description

**Finding 2 of the M1 milestone review, eighth pass, 2026-08-18.** `listHunks` loses `--unified=3`
undetected, and then reports **the wrong number of hunks**.

`YardKit/Sources/YardGit/Hunks.swift:378`, remove `"--unified=3"`: full suite green,
`Test run with 1103 tests in 78 suites passed after 66.071 seconds`.

**Measured against the engine**, with `diff.context = 10` and a file with two separated changes:

```
pristine:  PROBE-CONTEXT: fileDiffs=1 hunks=[2]
mutant:    PROBE-CONTEXT: fileDiffs=1 hunks=[1]
```

The two changes **merge into one hunk** — `@@ -1,30 +1,30 @@` instead of `@@ -2,7 +2,7 @@` and
`@@ -17,7 +17,7 @@`.

**Hunk identity is what `stage --hunk` and `commit --hunk` act on.** An agent asked to stage only the
first change stages both, silently. The flag is documented as load-bearing at `Hunks.swift:368` —
*"`--unified=3` (overrides `diff.context`)"* — and the documentation is the only thing enforcing it.
