## Description

`yard skill` prints the canonical skill markdown to stdout, so an agent holding only the binary can
read its own instructions with no install step and no package manager.

## Expected behavior

- [ ] The skill markdown is embedded in the binary at build time, not read from a path that may not exist.
- [ ] Output is byte-identical to the committed `skills/yard/SKILL.md`.
- [ ] `yard skill --json` returns it wrapped in the standard envelope for uniformity.
