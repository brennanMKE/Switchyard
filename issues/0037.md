## Description

The GPG path, via `gpg --detach-sign --armor`. There is no way around shelling out here, so no
library choice avoids it.

## Expected behavior

- [ ] Honors `gpg.format = openpgp` and `user.signingKey`.
- [ ] `git log --show-signature` reports the result as verified.
- [ ] Tests skip cleanly when `gpg` is absent rather than failing the suite.
- [ ] A gpg-agent prompt cannot hang the CLI indefinitely — a timeout produces exit 9.
