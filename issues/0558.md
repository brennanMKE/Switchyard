## Description

The Changes view's commit message is a bare `TextEditor` (#0445): no subject guide, no way to
credit a pair, no memory of a message that Undo Commit just took away, `commit.template` silently
ignored (the engine commits with `git commit -m`, which skips it — measured), and a half-written
message lost when the window closes. It is used on every commit.

**Guide §11 decision 45 is the design.** In short: keep **one** editor whose first line is the
subject; add a guide line under it (`Subject 42/50 · Leave line 2 blank · 2 body lines over 72`,
orange on a warning, never blocking); a **Co-Author** menu (recent authors and already-credited
people) that writes a `Co-authored-by:` trailer into the text through `git interpret-trailers`; a
**Recent Messages** menu from `HEAD`'s reflog; start an empty draft from `commit.template` with its
comments stripped; and keep the draft per repository in `UserDefaults`. ⌘↩ already commits
(#0445). Every commit still goes through `commitStaged` / `AmendHead.run` with `-m`, so hooks and
signing are untouched, and nothing opens an editor.

**Candidates weighed, and why each landed where it did:**

| candidate | verdict | why |
|---|---|---|
| subject field + body editor | **no** — one editor, first line is the subject | git's model; Amend's `HEAD` message would be rewritten by a split/join (`a\nb` → `a\n\nb`); no focus choreography; draft stays a `String` |
| 50 subject / 72 body guide | **yes, as counters** (#0563) | cheap, pure, testable; a drawn column means nothing in a proportional font |
| co-author trailers | **yes** (#0559, #0560, #0566) | pairing credit is a daily act; git places the trailer, the text stays visible and editable |
| recent-messages menu | **yes, from the reflog** (#0561, #0567) | the reflog still holds undone and amended commits — the moment reuse matters; no app state |
| draft kept per repository | **yes, `UserDefaults`** (#0564) | `@SceneStorage` dies with the window; `@AppStorage`'s key is fixed at declaration |
| ⌘↩ to commit | **already built** (#0445) | nothing to do |
| `commit.template` | **yes** (#0562, #0565) | `-m` ignores it (measured) so the app silently dropped a team's convention; comments stripped by `git stripspace -s` |
| hooks and signing | **unchanged by construction** | every path still ends in `git commit -m` / `--amend -m` |

## Questions for Brennan (the plan assumed an answer to each; none blocks a child)

1. **The 72-column body guide is a counter, not a drawn line.** Assumed: keep the proportional body
   font and say "2 body lines over 72". The alternative is a monospaced editor with a vertical rule
   at column 72 — a look change, so yours to call. A "Wrap Body at 72" command is also possible.
2. **An unedited `commit.template` disables Commit** ("Edit the message from commit.template"),
   the way git's editor flow aborts on an unedited message. Assumed yes. The length guides never
   block.
3. **Recent Messages replaces the editor's text without asking**, even over a typed draft. Assumed
   fine: it is an explicit pick, and #0564 has already saved nothing better. Alternatives: ask
   first when the draft is not blank, or append instead of replace.
4. **Co-Author only offers people from the last 500 commits** (authors and existing
   `Co-authored-by` values). Assumed enough; there is no "Add Someone…" entry and no Contacts
   lookup — a new pair is credited by typing the trailer once, after which they are offered.
5. **The draft is keyed by the repository's path.** A repository moved on disk starts empty, and
   drafts of deleted repositories linger in the app's defaults (a few bytes each). Assumed fine.
6. **`switchyard commit` (the CLI) gains no `--co-author` flag here.** An agent can already pass the
   trailer in `-m` text. Assumed not needed now.
