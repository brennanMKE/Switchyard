## Description

**Child of #0358, split 2026-09-12.** One deliverable: the sidebar's ref sections collapse, the
current branch is listed first, and a truncated ref name can be read in full.

*Measured*: Switchyard has 309 local and 294 remote-tracking refs, so with plain `Section`s everything
below Branches is effectively unreachable. `RepositorySidebarView.swift`'s header comment records
dropping collapse for the MVP; M7 is where it returns.

### Changes to `YardKit/Sources/YardUI/RepositorySidebarView.swift`

- **Collapsible sections**, with Branches expanded and Remotes and Tags collapsed by default:

  ```swift
  @State private var branchesExpanded = true
  @State private var remotesExpanded = false
  @State private var tagsExpanded = false

  Section("Remotes", isExpanded: $remotesExpanded) {
      // existing ForEach
  }
  ```

  `Section(_:isExpanded:content:)` inside a `.sidebar` `List` *compiled* at `61c94aa`, in a scratch
  view. **Whether it renders a working disclosure on macOS 26 is unverified — spike #0386 settles it**,
  and its failure branch replaces this with `DisclosureGroup`. Worktrees, Rerere and Stashes keep
  plain `Section`s.
- **Current branch first**: `branches` sorts with
  `.sorted { ($0.name == currentRef ? 0 : 1, $0.name) < ($1.name == currentRef ? 0 : 1, $1.name) }`,
  where `currentRef` is `"refs/heads/" + currentBranchName`. It keeps its `checkmark.circle.fill`.
- **`.help(entry.name)`** on each branch, remote and tag row, so the full ref name is readable on
  hover.

Expansion state is per window and not persisted across launches. That is a deliberate first step,
not an oversight.

## Expected behavior

- [ ] Branches, Remotes and Tags each collapse and expand, starting expanded / collapsed / collapsed.
- [ ] The current branch is the first row of Branches.
- [ ] Every ref row shows its full name as help text; `swift test` prints `Test run with N tests`
      with no failures.
