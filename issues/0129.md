## Description

M1 exit criterion 1 (guide §9) requires each read-command engine function to return "a type that
encodes to a `schemaVersion: 1` envelope". None of the engine result types conforms to `Encodable`,
so none can pass through `YardKit`'s `Envelope` (`EncodableResult.init` requires
`Encodable & Sendable`). This issue establishes the whole mechanism on **one type, `WhereAmI`**:
the conformance pattern, the wire-shape rules, and the test target that can see both sides of the
`YardGit`/`YardKit` boundary. Six follow-up issues (see Sequencing) apply the same pattern to the
remaining sixteen result types; they change nothing structural.

**One deliverable:** `WhereAmI` encodes to the v1 envelope, byte-pinned — one extension appended to
`YardKit/Sources/YardGit/WhereAmI.swift`, one new test target in `YardKit/Package.swift`, and one
new test file `YardKit/Tests/YardWireTests/WhereAmIWireTests.swift`. **All three changes are
written out below in full and were compiled, run, and mutation-tested in a copy of this package on
2026-08-07** — `Test run with 448 tests` from the 445 baseline, every mutation row observed red
(or, where marked, observed as a compile failure), then reverted. The round's work is transcription
plus running the verification.

**This round touches `Package.swift`, which the local model has failed at repeatedly (#0124,
#0126) — dispatch it to Sonnet, not Ornith.** It is the only `Package.swift` change in the whole
family; the follow-ups touch only `Sources/YardGit` and `Tests/YardWireTests`.

## Decisions — settled here, binding on the follow-up issues

1. **The conformance lives in `YardGit`, as plain stdlib `Encodable`. The dependency arrow does
   not move.** `Encodable` is a Swift standard-library protocol; conforming to it requires no
   import, so "engine types encode to the envelope" needs no `YardGit → YardKit` edge. Wrapping in
   the envelope stays `YardKit`'s job via `EncodableResult`, whose `init(_ value: some (Encodable
   & Sendable))` accepts any conforming engine type. The alternative — depending `YardGit` on
   `YardKit` — is not an option: CLAUDE.md's Layering section keeps the engine import-free, and
   `LayeringTests.yardGitDoesNotImportYardKit` / `yardKitDoesNotImportYardGit` (in
   `YardKit/Tests/YardKitTests/LayeringTests.swift`) assert both directions from the source today.
   A third source target for conformances would solve a problem that does not exist.
2. **Cross-boundary tests live in one new test target, `Tests/YardWireTests`, depending on both
   `YardGit` and `YardKit`.** Test targets are outside the layering rule (the layering tests scan
   `Sources/` only — verified by reading them). Imports are **not** `@testable`: the wire is a
   public-caller contract, and `@testable` would mask a conformance that silently dropped to
   internal (the #0116 failure class, and the reason `YardGitPublicAPITests` exists).
3. **Wire keys are the Swift member names, verbatim** — camelCase, and `headOID` stays `headOID`.
   Every conforming type declares an explicit `CodingKeys` enum whose cases are the member names
   with **no raw values** (the case name is the wire key). The enum's job is rename-safety: with it,
   renaming a member is a compile error at the enum instead of a silent wire change. Byte
   stability is pinned by literal-JSON tests, not by the enum.
4. **A nil optional is omitted from the wire, never encoded as `null`.** Same rule the envelope
   itself already uses for `result` and `error.hint`. Synthesized `Encodable` does this
   (`encodeIfPresent`) — a hand-written `encode(to:)` that writes `null` is a defect (mutation 4).
5. **Enums with a String raw value encode as that raw value** (a single JSON string) — e.g.
   `ConflictedFile.Kind` as `"UU"`. Enums without a raw value and without associated values
   (`SignatureStatus`) encode as their **case-name string** via an explicit `encode(to:)` with a
   single-value container — `SignatureStatus` has no raw type (#0127 settled that), so its wire
   string is declared, not derived. Enums with associated values (`WorktreeAddError`,
   `WorktreeRemoveError`, `WorktreeTemplate.Report.Outcome`, `SignatureVerification.State`,
   `SigningConfig.Format`) encode as an **object with a stable `code` string plus detail fields**;
   the result errors reuse their existing `code` property and add `"message"` = `description`.
   Uniform shape across all cases of one enum — no string-or-object unions.
6. **`pathBytes` / `originalPathBytes` are not on the wire.** JSON strings must be valid UTF-8, so
   the raw bytes cannot ride in one; the wire carries the lossily-decoded `path` string. If a
   lossless channel is ever needed, an optional base64 field is additive and non-breaking under
   `YardKit/Schemas/README.md`'s rule.
7. **Stored properties only.** Computed conveniences (`success`, `subject`, `shortOid`,
   `willSign`, …) are derivable by the reader and are not encoded.
8. **Byte-pinned tests encode with `JSONEncoder` + `.sortedKeys` and nothing else** — the same
   configuration as `EnvelopeFail.write()` and `YardKit`'s internal `jsonString`, so the tested
   bytes are the emitted bytes. A round-trip test is not acceptable as the only pin: encode-then-
   decode passes when both sides share the same wrong key.

Decisions 3–7 should be recorded as a numbered decision in guide §11 at merge time (a
planning-side task for whoever merges, not part of this round).

## Givens — each measured on this machine, 2026-08-07

1. **`WhereAmI` is already `Sendable`** (`public struct WhereAmI: Sendable, Equatable`), so
   `Encodable` alone satisfies `EncodableResult`'s bound. Measured: the test file below constructs
   `EncodableResult(value)` from the `YardWireTests` module and compiles. (Some later types —
   `CommitLogEntry`, `WorktreeStatus` — lack explicit `Sendable` and will need it added; public
   structs get no implicit `Sendable` across module boundaries. That is the follow-ups' problem,
   re-verified at their own planning passes.)
2. **A same-file extension with a private `CodingKeys` enum synthesizes `encode(to:)`** — the
   extension below compiles and encodes with no hand-written `encode` method.
3. **`JSONEncoder` escapes forward slashes**: `"origin/main"` encodes as `"origin\/main"`
   (measured — visible in the first test's literal). Do not "fix" the literals; they are pasted
   from a real run.
4. **`.sortedKeys` output for a fully-populated `WhereAmI`, verbatim** (this is the first test's
   expected literal):

   ```
   {"ahead":2,"behind":1,"branch":"main","conflictCount":7,"hasConflicts":true,"headOID":"a1b2c3d","isMidCherryPick":false,"isMidMerge":true,"isMidRebase":false,"rawHead":"a1b2c3d4e5f6a7b8c9d0a1b2c3d4e5f6a7b8c9d0","stagedCount":6,"stashCount":3,"unstagedCount":5,"untrackedCount":4,"upstream":"origin\/main"}
   ```

5. **The envelope frame around it, verbatim** (the third test's expected literal, abbreviated here
   to its frame — the full literal is in the test): `{"ok":true,"result":{…payload…},"schemaVersion":1}`.
6. **No `Schemas/` change and no golden-test impact.** `CommandRegistry` is untouched — no command
   registers here (that is M3, guide §11 decision 11) — so `SchemaGoldenTests` compares the same
   two files it does today. Measured: the full suite ran with only the three new tests added to
   the count. When a `whereami` command registers later, its schema file is forced into existence
   by those tests and the payload description lands there through the regenerate-and-diff loop.
7. **Baseline.** `docs/test-baseline.txt` read **445** as this planning pass finished, and it has
   moved eight times today — trust the delta, not the absolute. On the 445 tree the measured
   result after this change is **448**.

## Change 1 — `YardKit/Sources/YardGit/WhereAmI.swift`, append at end of file

```swift
// MARK: - Wire encoding (#0129)

/// `WhereAmI` is a `schemaVersion: 1` payload: it encodes through `YardKit`'s
/// `Envelope` via `EncodableResult`, which requires `Encodable & Sendable`.
/// The conformance lives here, in the engine, as plain-stdlib `Encodable` —
/// the engine still imports nothing (the arrow `YardKit -/-> YardGit` is
/// asserted by `LayeringTests` in both directions).
extension WhereAmI: Encodable {
    /// The stable wire keys. Identical to the member names on purpose: the
    /// enum exists so a member rename becomes a compile error here instead of
    /// a silent wire change. No case carries a raw value — the case name IS
    /// the wire key, and `WhereAmIWireTests` pins the encoded bytes.
    private enum CodingKeys: String, CodingKey {
        case branch, upstream, ahead, behind
        case isMidRebase, isMidMerge, isMidCherryPick
        case stashCount, untrackedCount, unstagedCount, stagedCount
        case hasConflicts, conflictCount, headOID, rawHead
    }
}
```

Do not write an `encode(to:)` method — synthesis handles it, and synthesis is what makes nil
optionals omitted (Decision 4). Do not touch any other type in this round.

## Change 3 — `YardKit/Tests/YardWireTests/WhereAmIWireTests.swift`, new file, in full

```swift
// WhereAmIWireTests.swift — WhereAmI encodes to the schemaVersion 1 envelope (#0129)

import Foundation
import Testing
import YardGit
import YardKit

/// Encodes a value the way the CLI writes envelopes: `JSONEncoder` with
/// `.sortedKeys` and nothing else — the same configuration as
/// `EnvelopeFail.write()` and YardKit's internal `jsonString`. Sorted keys
/// make the bytes deterministic, so tests can assert literal JSON.
func wireJSON(_ value: some Encodable) throws -> String {
    let encoder = JSONEncoder()
    encoder.outputFormatting.insert(.sortedKeys)
    return String(decoding: try encoder.encode(value), as: UTF8.self)
}

@Suite("WhereAmI wire shape")
struct WhereAmIWireTests {

    /// Every field populated, asserted against the literal bytes. A
    /// round-trip cannot catch a key both sides share wrongly; the literal is
    /// the contract.
    @Test func fullValueEncodesToTheLiteralWireShape() throws {
        let value = WhereAmI(
            branch: "main", upstream: "origin/main", ahead: 2, behind: 1,
            isMidRebase: false, isMidMerge: true, isMidCherryPick: false,
            stashCount: 3, untrackedCount: 4, unstagedCount: 5, stagedCount: 6,
            hasConflicts: true, conflictCount: 7,
            headOID: "a1b2c3d",
            rawHead: "a1b2c3d4e5f6a7b8c9d0a1b2c3d4e5f6a7b8c9d0")
        #expect(try wireJSON(value) == #"{"ahead":2,"behind":1,"branch":"main","conflictCount":7,"hasConflicts":true,"headOID":"a1b2c3d","isMidCherryPick":false,"isMidMerge":true,"isMidRebase":false,"rawHead":"a1b2c3d4e5f6a7b8c9d0a1b2c3d4e5f6a7b8c9d0","stagedCount":6,"stashCount":3,"unstagedCount":5,"untrackedCount":4,"upstream":"origin\/main"}"#)
    }

    /// A detached HEAD with no upstream: every nil optional is OMITTED from
    /// the wire, not encoded as null — the same rule the envelope itself uses
    /// for `result` and `error.hint`.
    @Test func nilOptionalsAreOmittedFromTheWire() throws {
        let value = WhereAmI(
            branch: nil, upstream: nil, ahead: nil, behind: nil,
            isMidRebase: false, isMidMerge: false, isMidCherryPick: false,
            stashCount: 0, untrackedCount: 0, unstagedCount: 0, stagedCount: 0,
            hasConflicts: false, conflictCount: 0,
            headOID: "a1b2c3d",
            rawHead: "a1b2c3d4e5f6a7b8c9d0a1b2c3d4e5f6a7b8c9d0")
        let json = try wireJSON(value)
        #expect(json == #"{"conflictCount":0,"hasConflicts":false,"headOID":"a1b2c3d","isMidCherryPick":false,"isMidMerge":false,"isMidRebase":false,"rawHead":"a1b2c3d4e5f6a7b8c9d0a1b2c3d4e5f6a7b8c9d0","stagedCount":0,"stashCount":0,"unstagedCount":0,"untrackedCount":0}"#)
        #expect(!json.contains("\"branch\""))
        #expect(!json.contains("null"))
    }

    /// The M1 exit-criterion sentence, literally: the engine result type
    /// encodes to a `schemaVersion: 1` envelope. Wrapped in the real
    /// `Envelope` through `EncodableResult` — the compile itself proves the
    /// `Encodable & Sendable` bound, and the literal pins the whole response.
    @Test func envelopeWrapsWhereAmIWithTheV1Keys() throws {
        let value = WhereAmI(
            branch: "main", upstream: nil, ahead: nil, behind: nil,
            isMidRebase: false, isMidMerge: false, isMidCherryPick: false,
            stashCount: 0, untrackedCount: 0, unstagedCount: 1, stagedCount: 0,
            hasConflicts: false, conflictCount: 0,
            headOID: "cafc5cd",
            rawHead: "cafc5cde84e5e8b8ddd67d821b0b803b60f43216")
        let json = try wireJSON(Envelope(result: EncodableResult(value)))
        #expect(json == #"{"ok":true,"result":{"branch":"main","conflictCount":0,"hasConflicts":false,"headOID":"cafc5cd","isMidCherryPick":false,"isMidMerge":false,"isMidRebase":false,"rawHead":"cafc5cde84e5e8b8ddd67d821b0b803b60f43216","stagedCount":0,"stashCount":0,"unstagedCount":1,"untrackedCount":0},"schemaVersion":1}"#)

        // Structural read-back of the envelope frame, so a failure here
        // distinguishes "envelope broke" from "payload byte drift".
        let object = try #require(
            try JSONSerialization.jsonObject(with: Data(json.utf8)) as? [String: Any])
        #expect(object["schemaVersion"] as? Int == 1)
        #expect(object["ok"] as? Bool == true)
        let result = try #require(object["result"] as? [String: Any])
        #expect(result["branch"] as? String == "main")
    }
}
```

`wireJSON` is deliberately file-internal-but-not-private: the follow-up issues' test files in this
target reuse it.
