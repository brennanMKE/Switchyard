## Description

The right pane: for a selected commit, its metadata, message, trailers, signature status, and diff
rendered per file and per hunk. For the working tree, the staged and unstaged changes.

This is read-only in M3. It becomes the surface that the three-way merge (#0057) and review sheet
(#0055) build on in M4, so its diff rendering should be factored for reuse rather than inlined.

## Expected behavior

- [ ] Commit metadata, full message, parsed trailers, and signature status all shown.
- [ ] Agent provenance trailers are surfaced distinctly — the point of recording them is that a human can see them.
- [ ] Diff rendered per file and per hunk, with stable hunk IDs available for later staging.
- [ ] Large diffs and large individual files stay responsive; binary files are reported, not rendered.
- [ ] Renames shown as renames rather than as a delete plus an add.
- [ ] Diff rendering is a reusable view, not code welded to this pane.
- [ ] Light and dark appearance both correct.
