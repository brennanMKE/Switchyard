## Description

Switchyard has **no Settings scene at all** — no `Settings` scene in `SwitchyardApp`, no
`SettingsLink` anywhere (grep-verified 2026-09-11). What exists is scattered: CLI
install/uninstall as app-menu items (#0222, `Commands.swift`), broker/transport status in the
transport pane (`TransportStatusBridge`), and the repair action reachable only through that pane.
A user trying to diagnose "why does `switchyard` not work" has no single surface that answers it —
measured during the 2026-09-11 demo failure (#0354): the CLI was not installed, the broker was not
registered, and nothing in the app said so in one place.

**Batty (MIT, same author — adaptation permitted with the copyright notice retained) is the
reference.** Its Settings → Advanced hosts exactly this surface: the CLI's four-state install
inspection (`notInstalled` / `installedHere` / `installedElsewhere` / `blockedByFile`) rendered as
an Install/Uninstall control with the stale-target note, the durability-gate refusals surfaced as
readable alerts, and the broker's live status. See `docs/batty-cli-install.md` §5 and
`BattyKit/Sources/BattyKit/Settings/CLIInstaller.swift` + `SettingsView.swift`.

## Expected behavior

- [ ] A `Settings` scene exists (Cmd-,), hosting at minimum: the CLI install state (the four-state
      inspection, install/uninstall with the existing `CLIInstallActions` machinery), the
      broker/transport status, and the repair action.
- [ ] The menu items (#0222) remain or are absorbed — but the Settings surface is the primary one.
- [ ] The install state shown is the four-state inspection, not a boolean — a stale
      `installedElsewhere` symlink renders with its target path and a self-healing Install.
- [ ] Adapted Batty code retains its copyright notice (MIT sibling rule).

## Notes

The engine half already exists and is tested (`CLIInstaller`'s four states, durability gate,
privileged runner). This issue is the surface, not the machinery. Pairs with #0353 (the gate's
missing translocation case) and #0354 (broker status is the other thing Settings should show).

## Planning pass — 2026-09-11, to code level. One round.

with the notice retained where substantial):

   pane binds — one source of truth.
