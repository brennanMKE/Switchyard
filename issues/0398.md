# 0398 — Sidebar sections do not collapse on macOS 26.6.2: move to DisclosureGroup

## Description

Found by #0386's VM UI test re-derivation (#0395 round 2, measured twice on macOS 26.6.2 /
Xcode 27.0): the sidebar's `Section(isExpanded:)` sections render **no disclosure control at
all** — no chevron on screen or in the accessibility tree, even hovered; three click strategies
inert. The collapse feature #0371 shipped does not collapse on this macOS. The filter half
(#0378) works, including inside collapsed sections.

## Expected behavior

- [ ] The sidebar's Branches/Remotes sections collapse and expand via a visible disclosure
      control on macOS 26.6.2 — re-planned onto `DisclosureGroup` (or whatever the spike's
      follow-up measurement supports), keeping #0371's current-branch-first ordering and #0378's
      filter behaviour.
- [ ] A VM UI test asserts the collapse toggle works (the pipeline from #0395 runs it).

## Notes

The spike's fail branch anticipated exactly this. #0371's shipped implementation needs the
re-plan; this issue carries it.

### Files and literal changes (planning update, 2026-09-23)

- **`YardKit/Sources/YardUI/RepositorySidebarView.swift`** — the three collapsible sections
  (lines 280, 287, 294: Branches, Remotes, Tags) change from
  `Section("X", isExpanded: …) { rows }` to a plain `Section { DisclosureGroup(isExpanded:) }`:
  the `DisclosureGroup` carries the same binding (including #0378's
  `isFiltering ? .constant(true) : $xExpanded` force-expand), its label keeps the section title
  styling, and the rows move inside the DisclosureGroup's content. HEAD, Worktrees, Rerere and
  Stashes stay plain `Section`s — they were never collapsible.
- **`SwitchyardUITests/0386SectionsCollapseUITests.swift`** — unchanged; it already asserts the
  behaviour the spike asked for. After this change its toggle half must pass, making the whole
  test green.
- **Verification**: the package suite (`swift test`, N greater than the round's measured
  baseline — 1957 on main at f6bebe3; measure, do not trust) plus one
  `scripts/run-ui-tests-vm.sh` run whose 0386 test passes end to end in the guest. Host-untouched
  checks after the run (AGENTS.md Rule 13).
