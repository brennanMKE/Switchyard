## Description

Guide §11 decision 40: typing an author's name in the filter should light up that author's commits.
`HistoryFilter.matches` (#0402, `YardKit/Sources/YardUI/HistoryFilter.swift`) checks the message,
the ref chips and an oid prefix, not `CommitLogEntry.author` (`%an`, already loaded for every row).
One more clause, matched like the message: case- and diacritic-insensitive substring.

Existing members used: `CommitLogEntry.author: String`,
`CommitLogEntry.init(oid:parents:author:refs:signatureStatus:message:trailers:)` (`note` defaults to
`nil`), `HistoryFilter.matches(_:chips:query:) -> Bool`.

Measured: the six existing `HistoryFilterTests` still pass with the clause added — their helper's
author is `"A"`, which none of the negative queries (`"abc"`, `"bcde"`, `"clipboard"`) contains. The
#0402 and #0525 VM spikes' queries (`"third commit"`, `"notes"`, `"charlie"`) do not occur in the
fixtures' author, `Switchyard UI Test`.

## The files

### 1. `YardKit/Sources/YardUI/HistoryFilter.swift` — 2 edits

**(a)** Replace

```swift
// its message (subject or body) contains the query, case- and
// diacritic-insensitively; when a ref chip on it matches the way the sidebar
```

with

```swift
// its message (subject or body) or (#0523) its author contains the query,
// case- and diacritic-insensitively; when a ref chip on it matches the way the sidebar
```

**(b)** Replace

```swift
        if chips.contains(where: { RefFilter.matches($0.name, query: q) }) { return true }
```

with

```swift
        if entry.author.range(of: q, options: [.caseInsensitive, .diacriticInsensitive]) != nil {
            return true
        }
        if chips.contains(where: { RefFilter.matches($0.name, query: q) }) { return true }
```
