## Description

Adds `CommitAction.checkOutDetached`, titled **Check Out (Detached)**, to the menu body the History
row's context menu and the menu bar's Commit menu share (`CommitActionMenuItems`, #0359), in its own
group between `[.merge, .rebaseOnto, .setBranchTip]` and `[.addTag, .createBranch,
.editLocalBranch]` (guide §11 decision 38). No shortcut. Disabled with "HEAD is already detached
here" exactly when `HEAD` is detached (`branchName == nil`) at this commit (`chainIndex == 0`);
the busy and in-progress guards that precede every rule apply as for the rest.

It runs as a **ref action**, not a commit request: `ContentView.perform` sends
`runRefAction(.detach(commit: oid))`, so a checkout that would overwrite local changes gets #0510's
Stash Changes and Switch alert. `CommitActionRequest.make` returns `nil` for it (the sheet-composed
actions' branch). The exhaustive switches in `CommitActions.swift` (`title`, `shortcut`,
`progressLabel`, `reason`, `RewriteSelection.chainIndex`, `CommitActionFailure.make`) each gain the
case; `CommitActionMenuTests` counts 16 actions instead of 15.
