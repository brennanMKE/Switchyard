## Description

Every engine test needs real repositories built in a temp directory. This harness is the foundation
of the whole test suite and has to be built before the read commands are tested, not after.

**Every fixture is built twice** — once with the default ref format and once with
`git init --ref-format=reftable` — and the suite runs against both. Reftable becomes the default in
Git 3.0; discovering the engine cannot read it should happen in CI, not on a user's repository.

## Expected behavior

- [ ] Builder constructs repos with arbitrary commit DAGs from a compact description.
- [ ] Every fixture is parameterized over both ref formats and the suite runs both.
- [ ] Fixtures for: linear history, merges, octopus merge, detached HEAD, empty repo, conflicts, mid-rebase, linked worktree, untracked files.
- [ ] Temp directories are cleaned up even when a test fails.
- [ ] Fixtures never touch the user's global git config or `~/.ssh`.
- [ ] Reftable fixtures are skipped with a clear message when the local git is too old, not silently passed.
