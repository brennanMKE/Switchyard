## Description

Build an installable copy into `dist/` and verify it before a human ever drags it to
`/Applications`. Verification is the point — a release script that only builds is a build script.

## Expected behavior

- [ ] Builds Release into a dedicated derived-data path and stages the app into `dist/`.
- [ ] Verifies the bundle contains all components: app, `BrokerAgent`, launchd plist, embedded `yard`.
- [ ] Verifies the bundle **and** the embedded CLI are separately signed.
- [ ] Verifies the embedded `yard` actually runs and reports a real version.
- [ ] Fails loudly on any missing piece rather than producing a subtly broken bundle.
- [ ] **Never** creates, revokes, or modifies certificates or provisioning profiles.
