## Description

Three doc comments in `YardKit/Sources/YardGit/WhereAmI.swift` describe commands the code does not
run. Small, but this is the file an agent-facing command is built on, and a comment that names the
wrong git plumbing sends the next reader to the wrong manual page.

Filed rather than folded into #0012's round 3, which is deliberately scoped to a test-file repair
after two timeouts.

## Givens — verified on `main`, treat as true

1. `rawHead`'s comment claims a `"ref: refs/heads/main"` form. The code always calls
   `git rev-parse HEAD`, so the value is always a SHA or empty.
2. `unstagedCount` and `stagedCount` comments say `git diff --name-status`. The code uses
   `git diff-index`.

## Expected behavior

- [ ] Each comment names the command actually run and describes the actual return shape.
- [ ] No behaviour changes. This is comments only.
- [ ] `cd YardKit && swift build` succeeds and `swift test` prints a `Test run with N tests` line you
      paste. **N must equal the count on `main`** — a comment change must not move it.

## Notes

If a comment and the code disagree, **change the comment**. Do not "fix" the code to match a comment;
the code's behaviour is covered by tests and the comment is not.
