## Description

Bundle identifier, Mach service name, launch agent plist name, URL scheme, log subsystem, CLI binary
name, install location, state directory, journal ref namespace. One file owns all of them and
nothing else hardcodes any of the strings.

This is cheap now and expensive later: these strings end up in the app target, the broker, the CLI,
the installer, the launchd plist, and the hook handler, and a mismatch between any two of them
produces a failure that looks like "XPC is broken".

## Expected behavior

- [ ] `ServiceNames.swift` in `YardKit` holds every value from guide §3.
- [ ] State directory resolution honors `XDG_STATE_HOME`, falling back to `~/.local/state/switchyard/`.
- [ ] A test asserts the bundle identifier matches what is in `project.pbxproj`.
- [ ] Grep confirms no literal `co.sstools.Switchyard` anywhere else in Swift sources.
