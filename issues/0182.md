## Description

**Filed by #0040's review on 2026-08-08, from a mutation the reviewer invented. Companion to
#0181 — same defect shape, different protocol. Re-authored to code level the same day; every
measurement below was made by the planner in a `git archive` copy of `main` at `910e0ec` (which
includes #0181's `ExitClassCoverageTests`) and is pasted from real runs.**

Review replaced the whole of `StagingError.description` with `""` and ran the suite: **all 13
StagingTests green.** `description` is shipped as public API and asserted by nothing.

An error's `description` is **what an agent reads when a command fails.** The CLI contract says
errors are structured, and the message rides in `{"error":{"message":"…"}}` (guide §6) — so an
empty or wrong description is a silent degradation of the one field a human or agent actually acts
on. Several are load-bearing beyond diagnostics: `WorktreeDisturbance.Error` names the worktree
path and branch, `CrossToolGuard.Error` names every diverging ref and both values, and
`JournalRestore.Error.unrestorableObjects` names each `ref → oid` — that last one already lost its
`→` to a transcription drift **no test could see**, precisely because nothing asserts the string.

**The coverage map, re-measured at `910e0ec`:** `grep -rnE 'CustomStringConvertible'
YardKit/Sources/YardGit` lists **31 conformance sites in 29 files** (two files carry two each:
`JournalAnchor.swift` also declares `JournalEntryID`, `JournalRebuild.swift` also declares
`Defect`; the issue as first filed said 28 files). No other target under `YardKit/Sources`
conforms at all (measured: the same grep over `YardKit/Sources` minus `YardGit/` returns nothing).
Six test files mention `.description` somewhere; none stops an emptied one.

## Design — decided, with reasons

**1. #0181's mechanism generalises, and the scan half is now shared.** The registry-plus-source-scan
design carries over unchanged in shape: one constructed sample per conformer, scan compared with
registry as sets in **both** directions, allow-list for recorded omissions, honesty check via
`String(reflecting:)`. What does **not** carry over verbatim is the scanner's line shape: all 31
`CustomStringConvertible` conformances are **declaration-site** (`public enum Error: Swift.Error,
Equatable, CustomStringConvertible {`), where all 27 `ExitClassCarrying` conformances are top-level
extensions. So the scanner moves into its own file, `ConformanceScan.swift`, **parameterised by
protocol name** and recognising both shapes plus comments and the protocol's own declaration —
anything else is reported unrecognized and turns the guard red (measured, M9). #0183 (the same
question for `Equatable`) points the same scanner at a third protocol instead of copying one, and
#0185 migrates `ExitClassCoverageTests` onto it. **This issue does not touch
`ExitClassCoverageTests.swift`.**

**2. Scan identity is `(file, local name)`, runtime identity is the qualified name.** A line scan
cannot see nesting, so a declaration-site conformance yields only the local name (`Error`, ten
times over). Each registry row therefore carries the source **file** and the **qualified** name;
its scan-side key is `file:lastComponent` (`Row.siteLabel`), and the honesty test pins the
qualified name against `String(reflecting: type(of: sample))`. The two are separately load-bearing,
and both were mutation-verified: lying about the qualified part alone leaves `siteLabel` unchanged
and is caught **only** by the honesty test (M6a); lying about the file is caught by the set
comparison in both directions (M6b).

**3. Substance assertions, not literals.** Equality against a full message makes every rewording a
test change, and that churn is how assertions get deleted. Each row instead declares what the
description must **carry**: the interpolated values, verbatim. Rules used in the registry below:

- a fragment is an interpolated value (`"/probe/sibling"`, a 40-char oid), or a short anchored
  phrase where the bare value would match accidentally — counts and small numbers (`"exited 86"`,
  `"5 step(s) requested"`, `"schemaVersion 99"`), never a whole sentence of prose;
- a load-bearing join is pinned by a composed fragment: `"refs/tags/probe-tag → \(oid3)"` is one
  fragment, so flattening the arrow dies (M3) while rewording around it stays green;
- every row also asserts the rendered string is non-empty, which is what kills the `""` mutation
  even for a `.prose` row (M8).

**4. Prose-only descriptions get a `.prose(reason:)` case, unused today.** Every one of the 31
conformers interpolates data in at least one case, so no row needs it — but a future prose-only
description must be a recorded decision, not a silently weaker row. A `.prose` row still asserts
non-emptiness (measured, M8), and a `.carries` row must list at least one fragment (`#require`), so
neither shape can go vacuous.

**5. One sample per conformer, the data-richest case.** Same contract as #0181 decision 6: this
guard says "no conformer ships with an unasserted description", not "every case enumerated". The
six families that already assert descriptions per-case (`CrossToolGuardTests`, `GitProcessTests`,
`IndexSnapshotTests`, `WorktreeDisturbanceTests`, `WorktreePruneGcTests`,
`PipelineContractTests`) keep that depth where it is; the registry is the coverage ledger.

**6. The scan covers `YardKit/Sources/YardGit` only — the engine — not the whole package.**
Deliberately narrower than #0181, and for a reason worth recording: `ExitClassCarrying` is an
engine-owned contract, so a conformance anywhere in the package deserves a stop;
`CustomStringConvertible` is a stdlib protocol any target may legitimately adopt for display. The
contract this guard pins is *description on an engine type = the agent-facing error message*.

**7. One empty-scan detector, and it is the `#require`.** Unlike the exit-class guard, where
`protocolDeclarations == 1` also fails on a broken path, `CustomStringConvertible` expects **zero**
protocol declarations — so when the scan root is broken, the scanner-accounting test stays green
and only `everyDescriptionConformerHasARegistryRow`'s `#require(!scan.sites.isEmpty)` fires
(measured, M5). That `#require` is not belt-and-braces; it is the only thing standing between a
broken path and a vacuously green guard.

### File 1 of 2 — `YardKit/Tests/YardWireTests/ConformanceScan.swift`

```swift
// ConformanceScan.swift — shared source scan behind the conformance-coverage
// guards (#0182; mechanism from #0181).
//
// Swift cannot enumerate a protocol's conformers at runtime, so coverage
// guards list conformers by scanning the sources — the `ServiceNamesTests`
// pattern — and compare the result against a runtime registry as sets in
// both directions. This type is the scan half, parameterised by protocol
// name so the next guard (#0183 asks the same question for `Equatable`)
// extends a call site instead of copying a scanner.
//
// It fails closed the same way #0181's embedded scanner does: exactly three
// line shapes are recognised — a comment, a declaration-site conformance,
// an extension-site conformance — plus the protocol's own declaration, and
// every other line naming the protocol is reported as unrecognized, so a
// conformance shape the scanner cannot parse turns a guard red rather than
// becoming a silently missed conformer.

import Foundation
import Testing

struct ConformanceScan {

    /// One conformance site. `file` is the source file's last path
    /// component; `name` is the type name exactly as the conformance line
    /// writes it — the local name for a declaration-site conformance (a line
    /// scan cannot see nesting), the possibly-qualified name for an
    /// extension-site one. The pair is the identity a registry row claims.
    struct Site: Hashable, Comparable {
        let file: String
        let name: String

        var label: String { "\(file):\(name)" }

        static func < (a: Site, b: Site) -> Bool {
            (a.file, a.name) < (b.file, b.name)
        }
    }

    struct Result {
        var declarationSites: Set<Site> = []
        var extensionSites: Set<Site> = []
        var protocolDeclarations = 0
        var unrecognized: [String] = []
        var duplicates: [String] = []

        var sites: Set<Site> { declarationSites.union(extensionSites) }
    }

    /// Scans every `.swift` file under `root` for lines naming
    /// `protocolName`, classifying each into `Result`.
    static func scan(for protocolName: String, under root: URL) throws -> Result {
        let escaped = NSRegularExpression.escapedPattern(for: protocolName)
        let typeName = "([A-Za-z_][A-Za-z0-9_.]*)"
        let declarationSite = try Regex(
            "^(?:public\\s+|package\\s+|final\\s+|indirect\\s+)*(?:enum|struct|class|actor)\\s+"
                + "\(typeName)(?:<[^>{]*>)?\\s*:[^{]*\\b\(escaped)\\b")
        let extensionSite = try Regex(
            "^(?:public\\s+)?extension\\s+\(typeName)\\s*:[^{]*\\b\(escaped)\\b")
        let protocolDeclaration = try Regex(
            "^(?:public\\s+)?protocol\\s+\(escaped)\\b")

        var result = Result()
        let enumerator = try #require(
            FileManager.default.enumerator(at: root, includingPropertiesForKeys: nil),
            "cannot enumerate \(root.path)")
        for case let url as URL in enumerator where url.pathExtension == "swift" {
            let source = try String(contentsOf: url, encoding: .utf8)
            let lines = source.split(separator: "\n", omittingEmptySubsequences: false)
            for (index, line) in lines.enumerated() where line.contains(protocolName) {
                let trimmed = line.trimmingCharacters(in: .whitespaces)
                if trimmed.hasPrefix("//") { continue }
                if let match = try declarationSite.firstMatch(in: trimmed) {
                    insert(Site(file: url.lastPathComponent, name: String(match[1].substring ?? "")),
                           into: &result.declarationSites, duplicates: &result.duplicates)
                } else if let match = try extensionSite.firstMatch(in: trimmed) {
                    insert(Site(file: url.lastPathComponent, name: String(match[1].substring ?? "")),
                           into: &result.extensionSites, duplicates: &result.duplicates)
                } else if try protocolDeclaration.firstMatch(in: trimmed) != nil {
                    result.protocolDeclarations += 1
                } else {
                    result.unrecognized.append("\(url.lastPathComponent):\(index + 1): \(trimmed)")
                }
            }
        }
        return result
    }

    private static func insert(_ site: Site, into sites: inout Set<Site>,
                               duplicates: inout [String]) {
        if !sites.insert(site).inserted {
            duplicates.append(site.label)
        }
    }
}
```

            #expect(
                runtime == "YardGit.\(row.name)",
                "registry row named \(row.name) constructs a \(runtime)")
        }
    }
