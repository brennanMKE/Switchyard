## Description

The **middle pane** of the three-pane Git View, rendering the DAG and lane assignment from `YardGit`
(#0015) for the tab's active repository and worktree. Read-only at first — mutation arrives with M4
and M5.

Selection here drives the Detail pane (#0082): selecting a commit shows its diff, and selecting the
working-tree row shows staged and unstaged changes. The sidebar (#0081) drives what this pane shows —
switching worktree or clicking a ref re-scopes the graph without touching the tab.

## Expected behavior

- [ ] Renders lanes, edges, refs, and signature status from engine output.
- [ ] Selection is published so the Detail pane follows it, and survives a sidebar-driven re-scope where the selected commit is still visible.
- [ ] Scopes to the tab's active worktree; switching worktree in the sidebar re-scopes without recreating the pane.
- [ ] Scrolling a 50k-commit repository stays responsive, consistent with #0003's numbers.
- [ ] Windowed loading — the full history is never materialized to draw one screen.
- [ ] Light and dark appearance both correct.
- [ ] Journal entries and observed external changes refresh the view without a manual reload.
- [ ] No engine logic in the view layer; anything worth testing lives in the package.
