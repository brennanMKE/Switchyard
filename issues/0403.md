## Description

Selecting a node puts the commit's metadata and its **full diff** in the narrow right column.
Brennan: *"showing the diff in the right column is too much. If I want to see more I can either
double click on the node or hit a button with the commit details in the right column."*

## Expected behavior

- [ ] The right column shows the selected commit's details only: subject, full message, SHA,
      author, date, signature status, trailers, and the list of changed file paths, which is
      compact and non-interactive or at most selectable. No diff hunks.
- [ ] The column has a **Show Changes** button that opens the commit changes window (#0404).

## Actual behavior

`CommitDetailView` and `FileDiffView` render every hunk of the commit in the right column
(visible in `issues/0399/switchyard-batty.png`).

```swift
    /// #0403: opens this commit's changes window (#0406). `nil` hides the
    /// Show Changes button.
    private let onShowChanges: (() -> Void)?
```

2. Replace the init with this. The new parameter has a default, so the `#Preview` and any other
   caller compile unchanged:

```swift
    public init(entry: CommitLogEntry, files: [FileDiff]?, diffError: String?,
                onShowChanges: (() -> Void)? = nil) {
        self.entry = entry
        self.files = files
        self.diffError = diffError
        self.onShowChanges = onShowChanges
    }
```

3. In `diffContent`, replace the non-empty branch, which is the whole
   `VStack(alignment: .leading, spacing: 12) { ForEach(files, id: \.path) { file in FileDiffView(file: file) } }`
   block, with:

```swift
                VStack(alignment: .leading, spacing: 6) {
                    HStack {
                        Text(Self.changedFilesSummary(count: files.count))
                            .font(.subheadline.weight(.semibold))
                        Spacer()
                        if let onShowChanges {
                            Button("Show Changes") { onShowChanges() }
                        }
                    }
                    // #0403: paths only; the diff itself lives in the
                    // changes window (#0404, #0406).
                    ForEach(files, id: \.path) { file in
                        Label(file.path, systemImage: FileChangeKind.of(file).systemImage)
                            .font(.callout)
                            .lineLimit(1)
                            .truncationMode(.middle)
                            .help(file.path)
                    }
                }
```

4. Add this helper inside `CommitDetailView`, under `// MARK: - Diff`:

```swift
    /// #0403: "1 changed file" / "N changed files".
    public nonisolated static func changedFilesSummary(count: Int) -> String {
        count == 1 ? "1 changed file" : "\(count) changed files"
    }
```

5. Update the type's doc comment: `its metadata, then its diff` becomes
   `its metadata, then the paths it changed and a Show Changes button (#0403) that opens the diff in its own window (#0406)`.
