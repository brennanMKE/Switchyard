## Description

The single most useful hook for this project. `reference-transaction` fires for every ref update
from any tool, batched by transaction, receiving `<old-value> SP <new-value> SP <ref-name>` per
update on stdin. That is exactly the event stream Switchyard needs to know what `git` did between
two `yard` commands.

`yard hook ref-txn` records `committed` transactions into the journal as **observed** (not undoable)
entries and forwards them to the app over XPC when one is attached.

## Expected behavior

- [ ] Records `committed` transactions as observed entries, distinct from undoable ones.
- [ ] Returns 0 **immediately** in the `preparing` and `prepared` states — a non-zero exit there aborts the user's transaction.
- [ ] Skips `yard`'s own transactions via the `GitProcess` environment marker (#0008), or the journal records itself recording itself.
- [ ] Fast enough to sit in the path of every ref update; measured, with the number recorded.
- [ ] A crash or exception in the handler cannot abort a user's git operation.
- [ ] Forwards to the app over XPC only when attached, and never blocks waiting for it.
