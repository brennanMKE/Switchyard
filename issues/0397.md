## Description

Found by #0385's VM UI test re-derivation (#0395 round 2, measured twice on macOS 26.6.2 /
Xcode 27.0): the real Create Branch sheet's button updates live as the user types, but **stays
enabled when the typed name collides with an existing branch** — no `RefNameProblem` check exists
in the sheet. Creating would fail at the engine with a raw error instead of being refused at the
surface.

## Expected behavior

- [ ] The Create Branch button disables (with a reason) when the typed name is empty, or collides
      with an existing branch, tag, or is an invalid ref name — the same refusal class the engine
      already returns.
- [ ] Unit-tested in the YardUI test target alongside the sheet's existing tests; N greater than
      the round's measured pre-change baseline.

## Notes

Found by #0385. The surface is #0363's Create Branch sheet.

### Files and literal changes (planning update, 2026-09-23)

- **`YardKit/Sources/YardUI/CommitActionSheets.swift`** — add a pure validator beside the sheet:
  `public nonisolated enum RefNameCheck` with
  `static func problem(name:kind:existing:) -> String?` where `kind` is
  `.branch | .tag` and `existing: [String]` is the list of names to refuse. Returns nil when
  acceptable, else the reason: empty/whitespace → "Enter a name"; name already in `existing` →
  "A branch named “X” already exists" (or tag wording); invalid per git-check-ref-format's common
  rules (leading `-` or `.`, trailing `/` or `.` or `.lock`, `..`, `~ ^ : ? * [ \`, space, `@{`,
  `//`) → "“X” is not a valid name". Pure Swift, no git call — testable without a repository.
- **`CommitActionPromptSheet`** gains `existingBranches: [String] = []` and
  `existingTags: [String] = []` (defaults keep every existing caller compiling), computes the
  problem from `name` as a computed property per prompt kind (createBranch → branches+tags,
  addTag → tags, renameBranch → branches minus the old name), disables the Create/Save button
  when a problem exists, and shows the reason as secondary text under the name field.
- **`YardKit/Sources/YardUI/ContentView.swift`** line ~968 — the one call site passes the names
  from `sidebar?.refs.refs` (entries under `refs/heads/` and `refs/tags/`, short names).
- **`YardKit/Tests/YardUITests/RefNameCheckTests.swift`** (new) — the validator's cases: empty,
  each invalid rule, branch collision, tag collision, rename-own-name allowed, and the sheet's
  disabled-with-reason derivation. N must exceed the round's measured pre-change baseline
  (1941 on main at c0faf82; measure, do not trust).
