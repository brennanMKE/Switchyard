# 0397 — The Create Branch sheet enables its button on a colliding name

| | |
|---|---|
| **Status** | open |
| **Module** | YardUI |
| **Milestone** | M8 |
| **Platform** | macOS |
| **First seen** | 2026-09-22 |

## Description

Found by #0385's VM UI test re-derivation (#0395 round 2, measured twice on macOS 26.6.2 /
Xcode 27.0): the real Create Branch sheet's button updates live as the user types, but **stays
enabled when the typed name collides with an existing branch** — no `RefNameProblem` check exists
in the sheet. Creating would fail at the engine with a raw error instead of being refused at the
surface.

## Expected behavior

- [ ] The Create Branch button disables (with a reason) when the typed name is empty, or collides
      with an existing branch, tag, or is an invalid ref name — the same refusal class the engine
      already returns.
- [ ] Unit-tested in the YardUI test target alongside the sheet's existing tests; N greater than
      the round's measured pre-change baseline.

## Notes

Found by #0385. The surface is #0363's Create Branch sheet.
