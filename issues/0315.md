## Description

**Findings 6 and 7 of the M1 milestone review, twelfth pass, 2026-08-18** — both minor, both one line to
close, filed together because neither is worth its own round.

### Half of `GitProcess.environment()`'s non-interactivity set is unasserted

`YardKit/Sources/YardGit/GitProcess.swift:330, 331, 335, 339, 340`. Deleting `EDITOR`, `VISUAL`,
`PAGER`, `GIT_ASKPASS` and `SSH_ASKPASS`: **full suite green.**

`environmentDisablesEditorsAndPagers` is named for the whole property and asserts **5 of the 10**
variables. The review was clear that severity is genuinely lower — `GIT_EDITOR` and `GIT_PAGER` dominate
git's own precedence, so these five are belt-and-braces — but they are **declared guarantees in the one
function every M1 engine call passes through**, and the fix is five `#expect` lines.

**This matters for the agent contract specifically**: `CLAUDE.md` says nothing is interactive unless the
command name says so, and `GIT_EDITOR` is never invoked. That promise is what these variables implement.

### `BEGIN PGP MESSAGE` armor is unasserted

`YardKit/Sources/YardGit/SignatureVerification.swift:171`. Dropping
`|| signature.contains("BEGIN PGP MESSAGE")`: **full suite green.**

`detectFormatRecognizesEachArmor` covers SSH, `PGP SIGNATURE`, `SIGNED MESSAGE`, none and unrecognised —
but not this one.

**Weaker than the pass's other findings, and the review said so plainly: it did not measure git producing
`PGP MESSAGE` in a `gpgsig` header.** One added line in the existing test closes it either way.
