# 0405 — The history and graph load only 100 commits, so most branch tips never appear

| | |
|---|---|
| **Status** | in-progress |
| **Module** | YardUI |
| **Milestone** | M9 |
| **Platform** | macOS |
| **First seen** | 2026-09-22 |

## Description

`loadCommitHistory` and `loadCommitGraph` both stop at the newest 100 commits. On Batty that hides
almost every branch. Measured 2026-09-22 on `~/Developer/brennanMKE/Batty`: 2,063 commits reachable
from `HEAD --branches --remotes` and 122 local branches. In
`git rev-list --topo-order HEAD --branches --remotes`, the branch tips sit at median position 636
and maximum position 1,907. With the 100 cap, a branch clicked in the sidebar (#0401) or labelled in
the graph (#0400) usually has no loaded commit to show.

Measured load cost, 2026-09-22, same host:

| repository | load | 100 commits | 5,000 commits | everything |
|---|---|---|---|---|
| Batty (2,063 commits) | `git log` with `CommitLog`'s format | 0.01 s | 0.04 s | 0.04 s |
| Batty | `yard-engine graph --limit N` | 0.33 s | 0.34 s | 0.33 s |
| git/git (85,179 commits) | `git log` with `CommitLog`'s format | 0.02 s | 0.12 s | 1.08 s |
| git/git | `yard-engine graph --limit 100000` | — | — | 4.19 s |

**Decision (high confidence, reversible, recorded under Rule 12):** raise the bound to 5,000
commits. That loads all of Batty and costs about 0.1 s on git/git. An unbounded load would take
4+ seconds on git/git, and paging is a later concern.

## Expected behavior

- [ ] One shared constant bounds both loaders, and its value is 5,000.
- [ ] A repository with 150 commits loads all 150 in both `loadCommitHistory` and
      `loadCommitGraph`, where today each returns 100.

## Files and literal changes

**`YardKit/Sources/YardUI/RepositoryLoader.swift`**, the only source file that changes.

1. Add this declaration directly above the doc comment of `loadCommitHistory`:

```swift
/// How many commits the History pane loads (#0405). Shared by
/// `loadCommitHistory` and `loadCommitGraph` so the two collections always
/// cover the same commits. 5,000 loads all of a 2,000-commit repository in
/// about 0.04 s and costs about 0.1 s on git/git (measured 2026-09-22).
public nonisolated let historyLoadLimit = 5_000
```

2. In `loadCommitHistory`, change

```swift
        rangeArguments: ["--topo-order", "-100", "HEAD", "--branches", "--remotes"])
```

to

```swift
        rangeArguments: ["--topo-order", "-\(historyLoadLimit)", "HEAD", "--branches", "--remotes"])
```

3. In `loadCommitGraph`, change

```swift
    try await graphRows(at: path, limit: 100, revisions: ["HEAD", "--branches", "--remotes"])
```

to

```swift
    try await graphRows(at: path, limit: historyLoadLimit, revisions: ["HEAD", "--branches", "--remotes"])
```

4. In `loadCommitGraph`'s doc comment, replace the sentence starting `Bounded to \`limit: 100\``
   with `Bounded by \`historyLoadLimit\` (#0405), the same bound \`loadCommitHistory\` above
   applies,`, and keep the rest of the sentence.

**`YardKit/Tests/YardUITests/CommitGraphLoaderTests.swift`**: append this test. It uses only APIs
that already exist: `FixtureRepository(refFormat:)`, `build(_:)`, `branch(_:at:)`, `checkout(_:)`,
`loadCommitHistory(at:)` and `loadCommitGraph(at:)`.

```swift
@Test("both history loaders load past the old 100-commit bound")
func bothHistoryLoadersLoadPastOneHundredCommits() async throws {
    var repo = try FixtureRepository(refFormat: .files)
    defer { repo.destroy() }

    // A 150-commit chain: c0 <- c1 <- ... <- c149. The old bound (#0405)
    // returned 100 of them from each loader.
    var commits = [FixtureRepository.Commit("c0")]
    for i in 1..<150 {
        commits.append(FixtureRepository.Commit("c\(i)", parents: ["c\(i - 1)"]))
    }
    try repo.build(commits)
    try repo.branch("main", at: "c149")
    try repo.checkout("main")

    let entries = try await loadCommitHistory(at: repo.url.path)
    let rows = try await loadCommitGraph(at: repo.url.path)

    #expect(entries.count == 150)
    #expect(rows.count == 150)
    #expect(entries.last?.oid == repo.oids["c0"])
}
```
