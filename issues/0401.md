# 0401 — Clicking a branch in the sidebar does nothing; it should focus that branch in the graph

| | |
|---|---|
| **Status** | open |
| **Module** | YardUI |
| **Milestone** | M9 |
| **Platform** | macOS |
| **First seen** | 2026-09-22 |

## Description

The sidebar's branch rows are read-only labels. Brennan filtered for `337`, saw `issue/0337` in
the sidebar, and tried to click it: *"it was read-only. I could not click it to make it focus the
branch in the branches view. It is entirely not useful and should be helpful to the user but it is
not."* The screenshot attached to #0399 (`issues/0399/switchyard-batty.png`) shows the filter at
`337` with `issue/0337` as the only sidebar row.

## Steps to reproduce

1. Open a repository with several branches (Batty was used).
2. Click any branch in the sidebar's Branches section, filtered or not.

## Expected behavior

- [ ] Clicking a local or remote branch row selects that branch's tip commit in the graph, scrolls
      the graph so the tip is visible, and updates the detail pane to that commit.
- [ ] The clicked row shows as selected in the sidebar.
- [ ] This works the same while the filter is active.

## Actual behavior

Nothing happens. The row has no selection or tap handling.
