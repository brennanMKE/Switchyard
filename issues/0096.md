## Description

Wrap `git worktree prune` and additionally report what is prunable and which worktrees hold an
abandoned agent session — the mess left behind when an agent crashes or a container is torn down
mid-run.

## Expected behavior

- [ ] New file `YardKit/Sources/YardGit/WorktreePrune.swift`. Create it; do not restructure existing files.
- [ ] Reports prunable worktrees with git's own stated reason, before pruning.
- [ ] Reports worktrees locked to an agent session whose directory is gone — abandoned sessions.
- [ ] **Never removes a worktree still locked by a live agent session.**
- [ ] A dry-run mode that reports without pruning.
- [ ] Tests cover a prunable worktree and a locked one, asserting the locked one survives.
- [ ] `swift build` succeeds and `swift test` prints a `Test run with N tests` line you paste.

## Notes

Split out of #0022. Blocked by #0009, #0024.

The live-session guard is the criterion that matters: prune must be safe to run at any time, which is
the whole reason #0021 locks with a machine-readable reason.
