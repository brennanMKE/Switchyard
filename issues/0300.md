## Description

**Finding 1 of the M1 milestone review, ninth pass, 2026-08-18.** `wt rm`'s dirty-path list is asserted
only for non-emptiness, never for contents.

`YardKit/Sources/YardGit/WorktreeRemove.swift:213-216`:

```swift
return entries.compactMap { entry -> String? in
    guard entry.staged != .unmodified || entry.worktree != .unmodified else { return nil }
    return entry.path
}
```

Two mutations, each confirmed against the **full unfiltered suite**:

| mutation | result |
|---|---|
| `return entry.path` → `return "bogus-path"` | `Test run with 1110 tests in 78 suites passed after 55.912 seconds` |
| `return entry.path` → `return ""` | `Test run with 1110 tests in 78 suites passed after 56.033 seconds` |

**The only production-path assertion is cardinality** — `WorktreeRemoveTests.swift:94-95`:

```swift
if case let .unclean(paths) = result.error {
    #expect(!paths.isEmpty, "error should name dirty paths")
```

`WorktreeRemoveWireTests.swift:43-51,83,96` *do* assert path contents, but they construct
`WorktreeRemoveError.unclean(paths: [...])` from literals — they pin the **encoding** and never reach
`dirtyPaths`.

**The design intent is stated in the source itself** (`WorktreeRemove.swift:246-248`): *"an agent acting
on the dirty paths must not have to parse them out of `message` prose"*. The field exists so an agent
can act on it, and nothing can fail if it is wrong.

Exactly the shape of **#0265** (`GCResult.pruned`'s elements) and **#0277** (`wt repair` asserts how
many, never which), both accepted as criterion-5 violations.

## Expected behavior

- [ ] The dirty-worktree test asserts the **contents** of `paths` — that it contains the file that is
      actually dirty, and no empty strings.
- [ ] **Two distinguishable dirty paths**, not one: the existing `refusesDirtyWorktreeWithoutForce`
      fixture creates a single dirty file, and a constant-returning mutation slips straight through a
      one-element list. One untracked plus one modified tracked file is enough. **This is #0282's lesson
      applied** — the two-distinct-values fixture is what makes a constant die.
- [ ] **Mutation 1:** `return "bogus-path"`. Must redden.
- [ ] **Mutation 2:** `return ""`. Must redden. Confirm each landed on line 215.
- [ ] `cd YardKit && swift test` **twice, in the foreground with an explicit 900000 ms timeout**, both
      green, above the count in `docs/test-baseline.txt`.
