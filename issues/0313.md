## Description

**Finding 4 of the M1 milestone review, twelfth pass, 2026-08-18 — a production defect, measured on
pristine source.** `log` loses **the entire trailer block** after a colon-shaped prose paragraph.

`YardKit/Sources/YardGit/CommitLog.swift:272-287`. Measured through `CommitLog.parseTrailerBlock`, **no
mutation applied**:

```
Fix the thing

Because the API: it changed.

Agent-Name: tool
```

→ `trailers == []`

**Why:** the look-ahead at line 280 accepts *any* non-indented line containing `:` as proof that the
paragraph is trailers. `Trailer.parse` then rejects `Because the API: it changed.` — its key contains
whitespace — and `break`s at line 307, so **the real trailer block is never reached.** Git's own rule is
the **last** paragraph.

**Consequence:** `log --agent-only` silently **excludes legitimately provenanced commits**, and
`trailers` comes back empty for them.

**The mutation that exposed it is the interesting part.** Reversing the separator scan to find the *last*
blank line — which is **more correct than the original** — left the suite green. Neither direction is
asserted, in either direction.

## Expected behavior

- [ ] **Fix the scan to git's rule: the trailer block is the last paragraph.** Read `git help
      interpret-trailers` for the exact definition before writing the code — git's rule has more to it
      than "last blank line", and this issue must not trade one wrong rule for another.
- [ ] **Test the measured case**: a body with a colon-shaped prose paragraph *before* a real trailer
      block, asserting the trailers are found.
- [ ] **Test the `agentOnly` consequence**, which is the harm: such a commit must be returned by an
      `agentOnly` query. #0305 added the mirror-image test (body prose must **not** count as a trailer)
      — check it still passes and say so, because these two pull in opposite directions and a fix that
      breaks #0305's test has gone too far.
- [ ] **Mutation:** restore the first-separator scan. The new test must redden.
- [ ] `cd YardKit && swift test` **twice, in the foreground with an explicit 900000 ms timeout**, both
      green, above the count in `docs/test-baseline.txt`.

## The files

`YardKit/Sources/YardGit/CommitLog.swift` and `YardKit/Tests/YardGitTests/CommitLogTests.swift`.

## Notes

**Milestone M1.** This is a **behaviour change**, unlike most recent M1 issues — `log`'s output changes
for commits with colon-shaped prose.

**#0305 is the constraint to respect**: it pins that a trailer-shaped line in body prose is *not* a
trailer. Both properties must hold — the block is the last paragraph, and prose before it is not
trailers.
