## Description

Side-by-side screenshots of the same repository (Batty, 2,061 commits, 13 visible branches) taken
2026-09-12, both windows showing the same checkout:

- `build/gitup-batty.png` — GitUp's Map view: every branch is a **colored lane** with its name
  labeled at the tip (`main` in red carrying a HEAD badge, `issue/0404` orange, `issue/0364`
  yellow, `issue/0405` green, `issue/0403` purple, `issue/0402` pink, …), remote lanes
  (`origin/main`) drawn **dashed**, merge points drawn as converging curves into the lanes they
  merged into, and a status line reading "On branch main · tracking upstream origin/main ·
  12 commits ahead". One glance answers: what branches exist, where each diverged, what is merged,
  where HEAD sits, and how far the branch is ahead.
- `build/switchyard-batty.png` — Switchyard showing the same repo: the sidebar's "Branches"
  section is a **flat alphabetical list** of names with identical generic icons — no lanes, no
  tip commits, no ahead/behind, no indication of which branches are merged, scrolled off after a
  dozen entries. The main area is a flat commit list whose only nod to topology is a single thin
  vertical line with dots — one lane, no branch colors, no divergence, no merges visible. A
  reviewer cannot see where any branch diverges, whether it is merged, or what the history's
  shape is.

**The engine already has the hard part.** `yard graph` exists (#0003's lane assignment —
`LaneAssignment.swift`, stable topo order, generation numbers), and `YardUI` already ships
`LaneGeometry.swift` and `LaneGutterView.swift`. The pieces are built and tested; the app's main
history view simply does not use them. This is not a "build a graph engine" issue — it is "wire
the existing engine output into the app's history view and the sidebar's branch list".

## Expected behavior

- [ ] The app's history view renders the commit graph with **per-branch colored lanes** from the
      engine's lane assignment — merges drawn as converging edges, not a single straight line.
- [ ] Branch tip labels render at their lane's head, with a HEAD marker on the current branch.
- [ ] Remote lanes render visually distinct (dashed or dimmed), the way GitUp distinguishes them.
- [ ] The sidebar's Branches section binds to live data: tip oid, ahead/behind vs upstream, and
      merged-into-main indication — not a flat name list with generic icons.
- [ ] The tracking status ("on branch main, 12 ahead") is visible without opening a detail pane.
- [ ] The window title names the open repository (measured: it reads "Switchyard" while GitUp's
      reads "Batty" — a second window cannot be told apart from the first).

### Root cause of the one-lane screenshot — it is the loaders, then the gutter

1. **Only `HEAD` is loaded.** `loadCommitHistory` passes `["-100", "HEAD"]` and `loadCommitGraph`
   calls `graphRows(at: path, limit: 100)`, whose `revisions` default is `["HEAD"]`
   (`YardKit/Sources/YardUI/RepositoryLoader.swift`, `YardKit/Sources/YardGit/LaneAssignment.swift`).
   *Measured* on Batty (`/Users/brennan/Developer/brennanMKE/Batty`): 1 merge commit among the 1,182
   reachable from `HEAD`; of the first 100 of `git rev-list --topo-order HEAD --branches --remotes`,
   **68 are not reachable from `HEAD`**. Branches are squash-merged, so a `HEAD`-only walk is a
   straight line no matter how well the gutter draws.
2. **The two loaders disagree on order once widened.** `CommitLog` runs `git log` in its default
   order; `graphRows` is `--topo-order`. *Measured* with `HEAD --branches --remotes`, 100 rows:
   **48 row positions differ on Batty, 19 on Switchyard.** With `--topo-order` on both: **0 differ
   on both repositories.** `CommitHistoryView` iterates `entries` and joins `GraphRow` by oid, so a
   mismatch draws edges between the wrong rows.
3. **One `GraphRow` cannot draw a multi-lane graph.** `LaneGutterView` draws a line from the top
   edge in the node's own lane — a stray line above *every* branch tip — plus the row's outgoing
   parent edges. Edges that cross a row, and edges converging into a node from other lanes, are
   not in `GraphRow`: `LaneAssigner` rule 1 closes converging lanes at the node's row. They must be
   reconstructed from the whole row list (`LaneSegments` below).

### `YardKit/Sources/YardUI/LaneSegments.swift` (new)

```swift
// LaneSegments.swift
//
// #0358: what each History row's lane gutter draws, derived once from the
// whole loaded `[GraphRow]`. A `GraphRow` says where its own node sits and
// where its parent edges leave; it cannot say which edges from rows above
// cross it or end at it, and `LaneGutterView` needs both to draw a
// continuous graph. Pure and `nonisolated`, like `LaneGeometry`.

import YardGit

/// One edge segment in a row's gutter.
public nonisolated struct LaneEdge: Hashable, Sendable {
    /// The lane the edge occupies at this row's top edge.
    public let lane: Int

    /// True when the commit the edge leaves from is not reachable from
    /// `HEAD` or any local branch within the loaded window -- drawn dashed.
    public let isRemoteOnly: Bool

    public init(lane: Int, isRemoteOnly: Bool) {
        self.lane = lane
        self.isRemoteOnly = isRemoteOnly
    }
}

/// The edges one row draws besides its own outgoing `parentLanes`.
public nonisolated struct LaneRowSegments: Equatable, Sendable {
    /// Edges entering at the top that end at this row's node: straight when
    /// `lane == row.lane`, a converging curve otherwise. Empty for a tip --
    /// nothing above continues into it, so no line is drawn above its node.
    public let incoming: [LaneEdge]

    /// Edges crossing this row top to bottom without touching its node.
    public let passThrough: [LaneEdge]

    public init(incoming: [LaneEdge], passThrough: [LaneEdge]) {
        self.incoming = incoming
        self.passThrough = passThrough
    }
}

public nonisolated enum LaneSegments {
    /// One `LaneRowSegments` per row, same order as `rows` (the topological,
    /// newest-first order `graphRows` returns). `localOids` is
    /// `LocalReachability.oids(in:from:)`'s result; `nil` draws every edge
    /// solid.
    public static func make(_ rows: [GraphRow], localOids: Set<String>? = nil) -> [LaneRowSegments] {
        var open: [(edge: LaneEdge, parent: String)] = []
        var result: [LaneRowSegments] = []
        result.reserveCapacity(rows.count)
        for row in rows {
            var incoming: Set<LaneEdge> = []
            var passThrough: Set<LaneEdge> = []
            for item in open {
                if item.parent == row.oid {
                    incoming.insert(item.edge)
                } else {
                    passThrough.insert(item.edge)
                }
            }
            open.removeAll { $0.parent == row.oid }
            let remoteOnly = localOids.map { !$0.contains(row.oid) } ?? false
            for (parent, lane) in zip(row.parents, row.parentLanes) {
                open.append((LaneEdge(lane: lane, isRemoteOnly: remoteOnly), parent))
            }
            result.append(LaneRowSegments(incoming: ordered(incoming), passThrough: ordered(passThrough)))
        }
        return result
    }

    private static func ordered(_ edges: Set<LaneEdge>) -> [LaneEdge] {
        edges.sorted { ($0.lane, $0.isRemoteOnly ? 1 : 0) < ($1.lane, $1.isRemoteOnly ? 1 : 0) }
    }
}

public nonisolated enum LocalReachability {
    /// The oids in `rows` reachable through `parents` from any of `tips`,
    /// without leaving the loaded window. `tips` is `HEAD`'s full oid
    /// (`WhereAmI.rawHead`) plus every `refs/heads/*` entry's oid from
    /// `RefSnapshot.refs`.
    public static func oids(in rows: [GraphRow], from tips: Set<String>) -> Set<String> {
        let byOid = Dictionary(rows.map { ($0.oid, $0) }, uniquingKeysWith: { first, _ in first })
        var seen: Set<String> = []
        var stack = Array(tips)
        while let oid = stack.popLast() {
            guard let row = byOid[oid], seen.insert(oid).inserted else { continue }
            stack.append(contentsOf: row.parents)
        }
        return seen
    }
}
```

### `YardKit/Sources/YardUI/RefChips.swift` (new) — branch-tip labels

*Measured* `%D` with `CommitLog`'s own `--decorate-refs` flags, on a repository holding both
`refs/remotes/origin/main` and a **local** branch literally named `origin/main`:
attached → `HEAD -> main, tag: v2, tag: v1, origin/main, feature` and, one commit down,
`origin/main` (the local branch); detached → `HEAD, tag: v2, tag: v1, origin/main, main, feature`;
the stash commit → `refs/stash`. So `%D` **cannot** tell a local branch from a remote one, but it
*does* peel an annotated tag (`v2`) onto its commit, while `RefSnapshot.Entry.oid` is the tag
object's id. Hence branches from `RefSnapshot`, tags and detached `HEAD` from `%D`:

```swift
// RefChips.swift
//
// #0358: the ref labels a History row shows at its commit. Branches and
// remote-tracking branches come from `RefSnapshot` (full names, so a local
// branch literally named `origin/main` is not mistaken for the remote one --
// `%D` prints both as `origin/main`, measured). Tags and a detached `HEAD`
// come from `CommitLogEntry.refs` (`%D`), because `%D` peels an annotated tag
// onto its commit while `RefSnapshot.Entry.oid` is the tag object's id.

import YardGit

public nonisolated struct RefChip: Hashable, Sendable {
    public enum Kind: Hashable, Sendable {
        case localBranch, remoteBranch, tag, detachedHead
    }

    public let name: String
    public let kind: Kind
    /// The local branch `HEAD` is on, or the detached-`HEAD` chip itself.
    public let isHead: Bool

    public init(name: String, kind: Kind, isHead: Bool) {
        self.name = name
        self.kind = kind
        self.isHead = isHead
    }
}

public nonisolated enum RefChips {
    private static let heads = "refs/heads/"
    private static let remotes = "refs/remotes/"

    /// Chips for the commit `oid`, in display order: `HEAD`'s branch (or the
    /// detached `HEAD`), other local branches, remote-tracking branches, tags.
    public static func make(oid: String, refs: RefSnapshot, decoration: String) -> [RefChip] {
        let decorations = decoration.isEmpty ? [] : decoration.components(separatedBy: ", ")
        var headBranch: String?
        if case let .symbolic(target) = refs.head, target.hasPrefix(heads) {
            headBranch = String(target.dropFirst(heads.count))
        }
        var chips: [RefChip] = []
        if decorations.contains("HEAD") {
            chips.append(RefChip(name: "HEAD", kind: .detachedHead, isHead: true))
        }
        let locals = refs.refs
            .filter { $0.oid == oid && $0.name.hasPrefix(heads) }
            .map { String($0.name.dropFirst(heads.count)) }
            .sorted { ($0 == headBranch ? 0 : 1, $0) < ($1 == headBranch ? 0 : 1, $1) }
        chips += locals.map { RefChip(name: $0, kind: .localBranch, isHead: $0 == headBranch) }
        chips += refs.refs
            .filter { $0.oid == oid && $0.name.hasPrefix(remotes) && !$0.name.hasSuffix("/HEAD") }
            .map { String($0.name.dropFirst(remotes.count)) }
            .sorted()
            .map { RefChip(name: $0, kind: .remoteBranch, isHead: false) }
        chips += decorations
            .filter { $0.hasPrefix("tag: ") }
            .map { RefChip(name: String($0.dropFirst("tag: ".count)), kind: .tag, isHead: false) }
        return chips
    }
}

public nonisolated enum CommitRowAccessibility {
    /// One VoiceOver label for a whole History row -- the gutter itself is
    /// `accessibilityHidden`, so the topology it draws is spoken here.
    public static func label(entry: CommitLogEntry, chips: [RefChip]) -> String {
        var parts = [entry.subject, "commit \(entry.shortOid)", "by \(entry.author)"]
        for chip in chips {
            switch chip.kind {
            case .localBranch: parts.append(chip.isHead ? "current branch \(chip.name)" : "branch \(chip.name)")
            case .remoteBranch: parts.append("remote branch \(chip.name)")
            case .tag: parts.append("tag \(chip.name)")
            case .detachedHead: parts.append("detached HEAD")
            }
        }
        if entry.parents.count > 1 { parts.append("merge commit") }
        return parts.joined(separator: ", ")
    }
}
```

### `YardKit/Sources/YardUI/LaneGutterView.swift` — replace `body` and the stored properties

```swift
struct LaneGutterView: View {
    let row: GraphRow?
    let segments: LaneRowSegments?
    /// This row's commit is reachable only from remote-tracking refs.
    let isRemoteOnly: Bool
    /// This row's commit is the one `HEAD` names.
    let isHead: Bool
    let width: CGFloat

    var body: some View {
        Canvas { context, size in
            guard let row, let segments else { return }
            let midY = size.height / 2
            let node = CGPoint(x: LaneGeometry.xOffset(forLane: row.lane), y: midY)

            func stroke(_ path: Path, lane: Int, dashed: Bool) {
                context.stroke(
                    path, with: .color(LanePalette.color(forLane: lane)),
                    style: StrokeStyle(lineWidth: 2, lineCap: .round, dash: dashed ? [4, 3] : []))
            }
            func edge(from start: CGPoint, to end: CGPoint) -> Path {
                var path = Path()
                path.move(to: start)
                if start.x == end.x {
                    path.addLine(to: end)
                } else {
                    let midway = (start.y + end.y) / 2
                    path.addCurve(to: end, control1: CGPoint(x: start.x, y: midway),
                                  control2: CGPoint(x: end.x, y: midway))
                }
                return path
            }

            for through in segments.passThrough {
                let x = LaneGeometry.xOffset(forLane: through.lane)
                stroke(edge(from: CGPoint(x: x, y: 0), to: CGPoint(x: x, y: size.height)),
                       lane: through.lane, dashed: through.isRemoteOnly)
            }
            for arriving in segments.incoming {
                stroke(edge(from: CGPoint(x: LaneGeometry.xOffset(forLane: arriving.lane), y: 0), to: node),
                       lane: arriving.lane, dashed: arriving.isRemoteOnly)
            }
            for parentLane in row.parentLanes {
                stroke(edge(from: node, to: CGPoint(x: LaneGeometry.xOffset(forLane: parentLane), y: size.height)),
                       lane: parentLane, dashed: isRemoteOnly)
            }

            let radius = LaneGeometry.nodeRadius + 1
            let dot = Path(ellipseIn: CGRect(x: node.x - radius, y: node.y - radius,
                                             width: radius * 2, height: radius * 2))
            let color = LanePalette.color(forLane: row.lane)
            if row.parents.count > 1 {
                // A merge is a hollow ring: punch the edges out under it so the
                // row's own background -- selection highlight included -- shows.
                var clearing = context
                clearing.blendMode = .clear
                clearing.fill(dot, with: .color(.black))
                context.stroke(dot, with: .color(color), lineWidth: 2)
            } else {
                context.fill(dot, with: .color(color))
            }
            if isHead {
                let ring = radius + 3
                context.stroke(
                    Path(ellipseIn: CGRect(x: node.x - ring, y: node.y - ring, width: ring * 2, height: ring * 2)),
                    with: .color(.primary), lineWidth: 1.5)
            }
        }
        .frame(width: width)
        .frame(maxHeight: .infinity)
        .accessibilityHidden(true)
    }
}
```

```swift
public struct CommitHistoryView: View {
    private let entries: [CommitLogEntry]
    private let graphRows: [GraphRow]
    private let refs: RefSnapshot?
    private let headOid: String?
    @Binding private var selection: String?

    public init(
        entries: [CommitLogEntry], graphRows: [GraphRow] = [], refs: RefSnapshot? = nil,
        headOid: String? = nil, selection: Binding<String?>
    ) {
        self.entries = entries
        self.graphRows = graphRows
        self.refs = refs
        self.headOid = headOid
        self._selection = selection
    }

    public var body: some View {
        let rowsByOid = Dictionary(graphRows.map { ($0.oid, $0) }, uniquingKeysWith: { first, _ in first })
        let localTips = Set((refs?.refs ?? []).filter { $0.name.hasPrefix("refs/heads/") }.map(\.oid)
            + [headOid].compactMap { $0 })
        let localOids = refs == nil ? nil : LocalReachability.oids(in: graphRows, from: localTips)
        let segmentsByOid = Dictionary(
            zip(graphRows.map(\.oid), LaneSegments.make(graphRows, localOids: localOids)),
            uniquingKeysWith: { first, _ in first })
        let gutterWidth = LaneGeometry.laneGutterWidth(maxLane: LaneGeometry.maxLane(in: graphRows))

        List(entries, id: \.oid, selection: $selection) { entry in
            CommitHistoryRow(
                entry: entry,
                graphRow: rowsByOid[entry.oid],
                segments: segmentsByOid[entry.oid],
                isRemoteOnly: localOids.map { !$0.contains(entry.oid) } ?? false,
                isHead: entry.oid == headOid,
                chips: refs.map { RefChips.make(oid: entry.oid, refs: $0, decoration: entry.refs) } ?? [],
                gutterWidth: gutterWidth)
            .listRowInsets(EdgeInsets(top: 0, leading: 0, bottom: 0, trailing: 8))
            .listRowSeparator(.hidden)
        }
    }
}

    let graphRow: GraphRow?
    let segments: LaneRowSegments?
    let isRemoteOnly: Bool
    let isHead: Bool
    let chips: [RefChip]

    var body: some View {

                }
                HStack(spacing: 8) {
                    Text(entry.shortOid)
                        .font(.system(.caption, design: .monospaced))
                    Text(entry.author)
                        .font(.caption)
                }
                .foregroundStyle(.secondary)
            }
            .padding(.vertical, 4)
            .opacity(isRemoteOnly ? 0.6 : 1)
        }
        .accessibilityElement(children: .combine)
        .accessibilityLabel(CommitRowAccessibility.label(entry: entry, chips: chips))
    }
}
```

**The visual rules that code encodes**, so a reviewer can check the screenshot against intent:

- **Colour follows the segment's lane.** Incoming and pass-through segments take the lane they run
  in; outgoing edges take the *parent's* lane. A branch's colour therefore runs unbroken until the
  curve where it joins, which is what makes "where did this diverge" legible.
- **Lane changes are vertical-tangent curves**, never straight diagonals.
- **Node shapes carry meaning, not just colour** (Differentiate Without Color): filled dot = commit,
  hollow ring = merge, extra `.primary` ring = `HEAD`. Remote-only history is **dashed and dimmed to
  0.6** and its chips are dash-outlined. Branch names are always text.
- **Symbols match the sidebar**: `checkmark.circle.fill` for the current branch,
  `arrow.triangle.branch` for others, `network` for remotes, `tag` for tags —
  `RepositorySidebarView.swift` already uses those, so the two panes read as one vocabulary.
- **One line per commit.** The screenshot shows subjects wrapping to three lines, tripling row
  height and breaking the graph into islands. The full message is the Detail pane's job.
- **Keep `List(selection:)`.** It gives ↑/↓ navigation, type-select, the system selection highlight
  and VoiceOver row semantics. Do not swap to `ScrollView` + `LazyVStack` for drawing control.
- **Rows must touch.** `.listRowInsets` with zero top/bottom and `.frame(maxHeight: .infinity)` on
  the gutter are what make edges continuous across rows. *Not verifiable in a unit test* — the
  reviewer captures the window (`docs/windows-command.md`) in **both** light and dark appearance and
  checks for gaps between rows.
- **Previews** in both appearances use `.environment(\.colorScheme, .dark)` on a subtree, not
  `.preferredColorScheme` (which switches the whole preview window).
- **Cost**: `LaneSegments.make` runs in `body`, like the existing `rowsByOid`; at 100 rows that is
  negligible. If paging raises the window, compute it once in the loader instead.

### `YardKit/Sources/YardUI/TrackingSummary.swift` (new) — the tracking status

*Measured* from source: `RepositoryHeaderView` renders `upstream` but never `ahead`/`behind`, though
`WhereAmI` carries both (`ahead: Int?`, `behind: Int?`, nil without an upstream). Batty's
`git status -sb` reads `## main...origin/main [ahead 12]`.

```swift
// TrackingSummary.swift
//
// #0358: the one-line tracking status the header shows, built from
// `WhereAmI` alone so it is testable without a repository.

import YardGit

public nonisolated enum TrackingSummary {
    public static func text(for state: WhereAmI) -> String {
        guard let branch = state.branch else {
            return state.headOID.isEmpty ? "No commits yet" : "Detached HEAD at \(state.headOID)"
        }
        guard let upstream = state.upstream else {
            return "On branch \(branch) · no upstream"
        }
        let ahead = state.ahead ?? 0
        let behind = state.behind ?? 0
        switch (ahead, behind) {
        case (0, 0): return "On branch \(branch) · up to date with \(upstream)"
        case (_, 0): return "On branch \(branch) · \(ahead) ahead of \(upstream)"
        case (0, _): return "On branch \(branch) · \(behind) behind \(upstream)"
        default: return "On branch \(branch) · \(ahead) ahead, \(behind) behind \(upstream)"
        }
    }

    /// The in-progress git operation that blocks history changes, or `nil`.
    public static func operationInProgress(for state: WhereAmI) -> String? {
        if state.isMidRebase { return "A rebase is in progress" }
        if state.isMidMerge { return "A merge is in progress" }
        if state.isMidCherryPick { return "A cherry-pick is in progress" }
        if state.hasConflicts { return "There are unresolved conflicts" }
        return nil
    }
}
```

In `RepositoryHeaderView`, replace the branch/oid/upstream line with
`Text(TrackingSummary.text(for: whereAmI)).font(.headline)`, keep the short oid in monospaced
secondary beside it, and
when `operationInProgress(for:)` is non-nil show it as
`Label(message, systemImage: "exclamationmark.triangle.fill").foregroundStyle(.orange)`. #0359's
menu disables every rewrite with that same sentence, so the header explains the disabled menu.
*Measured* strings: `ahead: 12` → `"On branch main · 12 ahead of origin/main"`; detached with
`headOID` `abcdef0` → `"Detached HEAD at abcdef0"`.

### Sidebar Branches section

**Engine gap, measured**: nothing in `YardKit/Sources/YardGit` computes a per-branch ahead/behind or a
merged state — grep for `upstream:track`, `ahead-behind`, `left-right` finds nothing, and
`for-each-ref` appears only in journal code. `WhereAmI` covers `HEAD` alone. The criterion
therefore needs a new engine read that this issue does not specify; see the planning report's
questions. **And "merged into main" is nearly always false in these repositories**: *measured*
`git branch --merged main` lists 4 of Batty's 122 local branches and 11 of Switchyard's 309, because
work lands by squash. Define "merged" before building it.

What does not depend on that read, and should land with the lanes:

- **Current branch first**, then alphabetical; keep its `checkmark.circle.fill`.
- **Collapsible sections.** Switchyard has 309 local and 294 remote-tracking refs (*measured*), so
  with plain `Section`s everything below Branches is unreachable. Use
  `Section("Remotes", isExpanded: $remotesExpanded)` with Remotes and Tags collapsed by default and
  Branches expanded. The file's header comment records dropping this for the MVP; M7 is where it
  returns. (*Not compiled* — confirm `Section(_:isExpanded:content:)` renders a disclosure in a
  `.sidebar` `List` on macOS 26.)
- `.help(entry.name)` on each ref row, so a truncated name can be read in full.
