## Description

Wire `switchyard wt list` into the command registry, following **the six-step pattern in #0115**, which
#0124 established and which this issue does not restate. Read that section first; it names the exact
files, the `CodingKeys` rule that sank two of #0124's rounds, and the golden-schema regeneration
step that an existing test fails without.

## The engine entry point this wraps

```swift
public func worktreeList(path: String, git: GitProcess = GitProcess()) throws -> [WorktreeEntry]
```

in `YardKit/Sources/YardGit/WorktreeList.swift`. `WorktreeEntry`'s `path` is `String?` and **may contain newlines** — never render it through porcelain's human-readable form.

## Expected behavior

- [ ] The arm in `YardKit/Sources/YardCommands/EngineCommands.swift`, resolving `WorktreeContext` for
      the **passed** working directory — never `FileManager.default.currentDirectoryPath`, which is the
      app's, not the caller's.
- [ ] `Encodable` on the result type with an **explicit `CodingKeys` enum listing every case, property
      names unchanged**. If it already conforms, say so and change nothing.
- [ ] A `CommandSpec` in `CommandRegistry.all` — non-empty `summary`, non-empty `schemaName`, exit
      codes 0 and 6 at least.
- [ ] The golden schema regenerated and committed.
- [ ] Tests in `YardKit/Tests/YardCommandsTests/` asserting values a `FixtureRepository` determines,
      plus a not-a-repository case: `error.code == "repository_error"`, exit **6**.
- [ ] Mutations, each run with its killing test named: break the not-a-repository path so it returns
      success; rename one `CodingKeys` case; remove the spec from `CommandRegistry.all`.
- [ ] `cd YardKit && swift test` prints a `Test run with N tests` line greater than the count in
      `docs/test-baseline.txt` at dispatch. State the delta.

## Notes

Guide §6, and M3's exit criterion "every M1 read command runs from the built binary". **Blocked by
#0124.** Nothing in `main.swift` changes — #0124's three-way routing picks up any command in
`CommandRegistry.all`.

Running the real binary end to end needs an installed app and a registered launch agent; that is
#0054's script, not this issue.
