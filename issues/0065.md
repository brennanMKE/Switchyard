# 0065 — Surface rerere recorded resolutions

| | |
|---|---|
| **Status** | open |
| **Module** | yard / Switchyard |
| **Milestone** | M5 |
| **Platform** | macOS |
| **First seen** | 2026-08-06 |

## Description

Git can record how a conflict was resolved and replay that resolution when the same conflict
reappears. For agents this is directly valuable: a human resolves a merge conflict once in
Switchyard's three-way UI, and every subsequent rebase of that branch resolves it without asking.

Surface it in the app so recorded resolutions are **visible and editable** rather than invisible
magic — a replayed resolution that nobody can inspect is indistinguishable from a bug.

## Expected behavior

- [ ] `yard rerere status --json` reports what is recorded.
- [ ] Recorded resolutions are visible in the app and can be deleted or edited.
- [ ] Resolving via #0057 records a resolution when `rerere` is enabled.
- [ ] A replayed resolution is reported in command output, never applied silently.
