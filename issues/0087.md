## Description

A pure function turning a `CommandSpec` into a JSON Schema description of that command's response
envelope. Same shape as #0086: spec in, value out, no I/O.

This is what makes the JSON contract documentable and diffable (#0026) rather than implicit.

## Expected behavior

- [ ] New file `YardKit/Sources/yard/SchemaEmitter.swift`. Touch nothing else except its test file.
- [ ] `func renderSchema(for spec: CommandSpec) -> String` returning pretty-printed JSON, sorted keys so output is stable across runs.
- [ ] The emitted schema includes `schemaVersion`, the command name, and the declared `schemaName`.
- [ ] A test decodes the output with `JSONSerialization` and asserts it is valid JSON — not a string comparison.
- [ ] A test asserts two calls with the same spec produce byte-identical output.
- [ ] `swift build` succeeds and `swift test` prints a `Test run with N tests` line you paste.

## Notes

Split out of #0010. Blocked by `#0085`.

Sorted keys and pretty printing are required, not cosmetic: the committed schemas are reviewed in
diffs, and unstable key order makes every diff noise.
