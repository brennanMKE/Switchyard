## Description

Guide §11 decision 45. `ContentView` holds the draft as `@State private var commitDraft =
CommitDraft()` (#0445), so it survives selecting a commit and coming back, but **closing the window
or quitting throws it away**. This keeps it per repository.

**Where it is kept — decided:** `UserDefaults`, key `commitDraft:<repository path>`, through a small
`CommitDraftStore`. Not `@SceneStorage`: its storage belongs to one scene and is dropped with the
window, and closing then reopening a repository is a new scene — the case this is for. Not
`@AppStorage`: its key is fixed where the property is declared, and one `ContentView` shows whichever
repository its window model holds. Not `.git/`: the app never writes `$GIT_DIR` with `FileManager`,
and `COMMIT_EDITMSG` is git's.

**What is kept:** `CommitDraft.savedText` — the message being written, or, while Amend is on, the
draft Amend set aside (the editor then holds `HEAD`'s message, which is read again next time; the
Amend checkbox is not kept). A blank draft removes the key. A successful commit or amend clears it.

**One writer:** the Changes view writes the draft only through the binding `ContentView` hands it,
and that binding's setter saves — no `onChange` observer. The restore happens in the
`.task(id: repositoryPath)` that already loads the window.

## The files

### 1. `YardKit/Sources/YardUI/CommitDraftStore.swift` — new file, exactly this

```swift
// CommitDraftStore.swift
//
// #0564: the Changes view's unsaved commit message, kept per repository in
// user defaults, so closing the window or quitting does not lose it (guide
// §11 decision 45). `ContentView` restores it when a window opens a
// repository and saves it on every edit; a commit or an amend clears it.

import Foundation

/// Reads and writes one repository's draft. `nonisolated`: a plain value
/// over `UserDefaults`, which is thread-safe.
public nonisolated struct CommitDraftStore {
    /// Every key starts with this, then the repository's path.
    public static let keyPrefix = "commitDraft:"

    private let defaults: UserDefaults

    public init(defaults: UserDefaults = .standard) {
        self.defaults = defaults
    }

    /// The draft saved for `repositoryPath`, or `nil` when none is.
    public func load(for repositoryPath: String) -> String? {
        defaults.string(forKey: Self.key(for: repositoryPath))
    }

    /// Saves `text` for `repositoryPath`; a blank `text` removes the entry,
    /// so a committed or emptied draft leaves nothing behind.
    public func save(_ text: String, for repositoryPath: String) {
        let key = Self.key(for: repositoryPath)
        if text.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty {
            defaults.removeObject(forKey: key)
        } else {
            defaults.set(text, forKey: key)
        }
    }

    static func key(for repositoryPath: String) -> String { keyPrefix + repositoryPath }
}
```

### 2. `YardKit/Tests/YardUITests/CommitDraftStoreTests.swift` — new file, exactly this

```swift
// CommitDraftStoreTests.swift — the draft kept per repository (#0564)

import Foundation
import Testing
@testable import YardUI

/// A defaults suite of its own, removed afterwards.
private func withStore(_ body: (CommitDraftStore) -> Void) {
    let suite = "CommitDraftStoreTests-\(UUID().uuidString)"
    let defaults = UserDefaults(suiteName: suite)!
    defer { defaults.removePersistentDomain(forName: suite) }
    body(CommitDraftStore(defaults: defaults))
}

@Test func eachRepositoryKeepsItsOwnDraft() {
    withStore { store in
        #expect(store.load(for: "/r/a") == nil)
        store.save("Fix the parser\n\nIt dropped the last line.", for: "/r/a")
        store.save("Other repo", for: "/r/b")
        #expect(store.load(for: "/r/a") == "Fix the parser\n\nIt dropped the last line.")
        #expect(store.load(for: "/r/b") == "Other repo")
    }
}

@Test func aBlankDraftRemovesTheEntry() {
    withStore { store in
        store.save("half-written", for: "/r/a")
        store.save(" \n", for: "/r/a")
        #expect(store.load(for: "/r/a") == nil)
    }
}

@Test func whileAmendingTheSetAsideDraftIsWhatIsSaved() {
    var draft = CommitDraft(message: "my draft")
    #expect(draft.savedText == "my draft")
    draft.setAmending(true, headMessage: "HEAD's message")
    #expect(draft.savedText == "my draft")
    draft.setAmending(false, headMessage: "")
    draft.message = "edited"
    #expect(draft.savedText == "edited")
}
```
