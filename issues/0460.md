## Description

Reported by the #0450 planner on 2026-09-29. When fixture generation in the guest failed, the
script exited without its EXIT trap stopping and deleting the clone, and the clone was left
running; the planner deleted it by hand (`tart-lease` showed no leases held). #0424's sweep
reclaims such a clone on the next run once its owner is dead, so this is a leak, not a
correctness bug, but a leaked clone holds one of Apple's two VM slots until then.

## Root cause (measured 2026-09-29, zsh 5.9 arm64-apple-darwin26.0)

**zsh does not run the EXIT trap when errexit fires inside a function.** Nor when a trap handler
calls `exit` while a function is on the stack. `fail` works only because it is an explicit `exit`
called from normal code. Measured with `zsh -f -c`, each line one experiment:

| script (`set -euo pipefail; trap c EXIT` where `c` echoes `TRAP`) | EXIT trap ran? |
|---|---|
| `false` at top level | yes |
| `f(){ false; }; f` | **no** (rc 1) |
| `f(){ exit 1; }; f` | yes |
| `trap 'exit $?' ZERR; f(){ return 3; }; f` | **no** (rc 3) |
| `trap 'exit 143' TERM; f(){ sleep 5; }; f` + `kill -TERM` | **no** (rc 143) |
| `zshexit` hook / `TRAPEXIT` function / `{ f } always { … }` | **no** |

Every clone in `scripts/run-ui-tests-vm.sh` is created and used inside `start_guest`, `run_spike` or
`run_launch_smoke`. So **any** failing command there with errexit on — a fixture script
(`make-map-fixture.sh`, `make-changes-fixture.sh`, `make-remote-fixture.sh`), the inline fixture
`tart exec`, the `$(tart exec … symbolic-ref …)` substitution, a `tart exec … tar | tar -x` pull,
`tart clone` itself — exits the script with the clone running and the export left on disk. A signal
(HUP/INT/TERM: a closed session, Ctrl-C, a harness timeout) had no trap at all. SIGKILL cannot be
trapped; the #0424 sweep remains the backstop for that one.

## Reproduction (measured 2026-09-29)

**Without a VM.** A fake `tart` first on PATH (logs each call; `exec` of `make-map-fixture` exits 1),
script run as `zsh -f scripts/run-ui-tests-vm.sh launch` — **`-f` is required**: `~/.zshenv`
prepends `/opt/homebrew/bin` and silently puts the real `tart` back (the planner's first attempt
without `-f` booted a real clone; it ran the whole launch smoke, passed and cleaned up). Result on
`main` at `3e7eb7ce`: exit **1**, no `==> Cleaning up` line, and the fake's log ends at
`tart exec <clone> … make-map-fixture.sh …` with **no `tart stop` and no `tart delete`**.

**In the VM.** `build/uitest-overlay/scripts/uitest-fixtures/make-map-fixture.sh` containing
`echo "make-map-fixture: deliberate failure (#0460)" >&2; exit 1` (the overlay mechanism from the
script header), then `./scripts/run-ui-tests-vm.sh launch` with the `main` script. Output ended at:

```
==> [launch-smoke] Guest reachable; copying source, generating the fixture
make-map-fixture: deliberate failure (#0460)
```

23 s, no cleanup line, and `tart list` afterwards showed:

```
local  switchyard-uitest-20260929-032904-35180-0 140  73   1 second ago   running
```

The planner stopped and deleted it by hand.

## Givens

- `scripts/run-ui-tests-vm.sh` — `#!/bin/zsh`, `set -euo pipefail` (line 36), `cleanup()` lines
  62-89, `trap cleanup EXIT` line 90. `start_guest` sets the global `CLONE`; `stop_guest` stops,
  deletes and sets `CLONE=""`, so after a clean spike `cleanup` has nothing to stop.
- Two deliberate `set +e` windows run commands that are **expected** to fail: `run_spike`'s
  xcodebuild (lines 368-378) and `run_launch_smoke`'s build-and-open (401-439, which reads
  `${pipestatus[1]}`), plus the memory request (177-180). Measured: a ZERR trap whose handler returns
  when `[[ -o errexit ]]` is false leaves both `$?` and `$pipestatus` intact for the next line.
- ZERR does not fire where errexit would not (`a || b`, `a && b` non-final, `if`, `while`), so
  `(( rc > TEST_RC )) && TEST_RC=$rc`, `grep … || true`, `memory_observer_live || { … }` and the
  sweep's `[[ … ]] || continue` are unaffected — measured.
- A failing command inside `$(…)` fires ZERR **in the subshell** (`$ZSH_SUBSHELL` > 0); the parent
  then fires its own ZERR on the assignment's status. Cleanup must happen only in the parent, once.
- zsh defers a trapped signal until the current foreground child exits (measured: a TERM sent while
  a fake `tart exec` slept 20 s took effect when the sleep ended). A TERM during a guest xcodebuild
  therefore cleans up when that `tart exec` returns, not instantly. Accepted: `tart exec` is
  bounded by the guest command, and the #0424 sweep covers a follow-up SIGKILL.

### The test: `scripts/test-uitest-cleanup.sh` (run by the planner; passes against the fixed script)

It runs the **real** script, not extracted functions: the bug is in how zsh unwinds the whole
script, so an extracted function would not show it. Fakes for `tart`, `vm_stat` and `df` sit first on
PATH (the latter two so the host's free memory and disk can never decide the outcome); `tart-lease` is
absent from that PATH, so no lease is taken. ~5 s.

```zsh
#!/bin/zsh
# test-uitest-cleanup.sh — #0460: once run-ui-tests-vm.sh has cloned a VM,
# every way the run can end stops and deletes that clone. No VM: a fake
# `tart` (and fake `vm_stat`/`df`, so the host's memory and disk never
# decide the outcome) sits first on PATH and logs every call; the real
# script runs under `zsh -f` so ~/.zshenv cannot put the real tart back.
set -euo pipefail

REPO="$(cd "$(dirname "$0")/.." && pwd)"
SCRIPT="$REPO/scripts/run-ui-tests-vm.sh"
WORK="$REPO/build/test-uitest-cleanup-$$"
mkdir -p "$WORK/bin"
# A clone the script failed to stop leaves its fake `tart run` looping (60 s
# at most); kill those too, so the test leaves nothing running.
trap 'pkill -f "$WORK/bin/tart run" 2>/dev/null; rm -rf "$WORK"; true' EXIT

cat > "$WORK/bin/tart" <<'FAKE'
#!/bin/zsh -f
print -r -- "tart $*" >> "$FAKE_TART_LOG"
case "$1" in
  list) print "Source Name Disk Size Accessed State"
        print "local switchyard-uitest-golden 140 73 now stopped" ;;
  run)  # Stays up, bounded, until `tart stop` marks this clone stopped.
        for i in {1..120}; do [[ -f "$FAKE_TART_DIR/stopped-$2" ]] && exit 0; sleep 0.5; done ;;
  stop) touch "$FAKE_TART_DIR/stopped-$2" ;;
  exec)
    case "$FAKE_TART_MODE:$*" in
      fixture-fails:*make-map-fixture*) exit 1 ;;
      fixture-hangs:*make-map-fixture*) touch "$FAKE_TART_DIR/started"; sleep 3; exit 0 ;;
      branch-fails:*symbolic-ref*) exit 1 ;;
      tests-fail:*xcodebuild*) print "** TEST FAILED **"; exit 65 ;;
      *symbolic-ref*) print uitest-main ;;
      *"tar -C"*) tar -cf - -T /dev/null ;;
    esac ;;
esac
exit 0
FAKE
print -r -- '#!/bin/zsh -f
print "Pages free: 100000000."; print "Pages inactive: 0."; print "Pages purgeable: 0."' > "$WORK/bin/vm_stat"
print -r -- '#!/bin/zsh -f
print "Filesystem 1024-blocks Used Available"; print "/dev/disk1 999999999 1 104857600"' > "$WORK/bin/df"
chmod +x "$WORK/bin/tart" "$WORK/bin/vm_stat" "$WORK/bin/df"

failures=0
check() {   # check <case> <description> <condition, eval'd>
  if eval "$3"; then print -r -- "  ok   $1: $2"; else print -r -- "  FAIL $1: $2"; failures=$(( failures + 1 )); fi
}

# run_case <mode> <spike-filter> [term] — runs the script, sets RC, LOG, OUT, CLONE.
run_case() {
  local mode="$1" filter="$2" term="${3:-}"
  local dir="$WORK/$mode"; mkdir -p "$dir"
  LOG="$dir/tart.log"; OUT="$dir/out"; : > "$LOG"
  FAKE_TART_MODE="$mode" FAKE_TART_LOG="$LOG" FAKE_TART_DIR="$dir" \
    PATH="$WORK/bin:/usr/bin:/bin:/usr/sbin:/sbin" \
    zsh -f "$SCRIPT" "$filter" > "$OUT" 2>&1 &
  local pid=$!
  if [[ -n "$term" ]]; then
    for i in {1..120}; do [[ -f "$dir/started" ]] && break; sleep 0.5; done
    kill -TERM "$pid" 2>/dev/null || true
  fi
  RC=0; wait "$pid" || RC=$?
  CLONE="$(awk '$2 == "clone" { print $4; exit }' "$LOG")"
}

# cleaned <case>: the clone was stopped and deleted exactly once.
cleaned() {
  check "$1" "a clone was created" '[[ -n "$CLONE" ]]'
  check "$1" "clone stopped exactly once" '[[ "$(grep -cx "tart stop $CLONE" "$LOG")" == 1 ]]'
  check "$1" "clone deleted exactly once" '[[ "$(grep -cx "tart delete $CLONE" "$LOG")" == 1 ]]'
}

print -r -- "case 1: a fixture script fails in the guest (errexit inside start_guest)"
run_case fixture-fails launch
check fixture-fails "script exits non-zero (rc=$RC)" '(( RC != 0 ))'
cleaned fixture-fails

print -r -- "case 2: a substitution fails in the guest (errexit inside \$(...) in start_guest)"
run_case branch-fails launch
check branch-fails "script exits non-zero (rc=$RC)" '(( RC != 0 ))'
cleaned branch-fails

print -r -- "case 3: the run is sent SIGTERM while a clone is up"
run_case fixture-hangs launch term
check fixture-hangs "script exits 143 (rc=$RC)" '(( RC == 143 ))'
cleaned fixture-hangs

print -r -- "case 4: xcodebuild fails inside run_spike's set +e window"
run_case tests-fail 0382
check tests-fail "script exits with xcodebuild's 65 (rc=$RC)" '(( RC == 65 ))'
check tests-fail "the run reached its RESULT summary" 'grep -qF "RESULT: TEST FAILED (exit 65)" "$OUT"'
cleaned tests-fail

if (( failures == 0 )); then
  print -r -- "CLEANUP TEST PASSED (4 cases: fixture failure, substitution failure, SIGTERM, tolerated test failure)"
else
  print -r -- "CLEANUP TEST FAILED ($failures checks)"
  exit 1
fi
```
