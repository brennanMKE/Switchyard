## Description

Wrap `git worktree repair` for the moved-directory case — reestablishing the links between a main
worktree and its linked worktrees after either end has been moved.

## Givens — verified on `main`, treat as true

1. `YardKit/Sources/YardGit/WorktreeContext.swift` provides `WorktreeContext.resolve(...)` plus
   `topLevel: String?` (nil in a bare repo), `gitDir`, `commonDir`, `worktreeName: String?`,
   `isLinkedWorktree`, `isBare`, and `path(for:git:)`. Use it; do not resolve paths yourself.
2. **`WorktreeContext` does not expose the main worktree's path.** If you need it, take the **first**
   `worktree <path>` line of `git worktree list --porcelain` — that entry is the main worktree from
   any worktree in the repo. Verified from inside a linked worktree. Do not derive it by trimming
   `/.git` off `commonDir`; that breaks on bare repos and on a `.git` file pointing elsewhere.
3. `YardKit/Sources/YardGit/FixtureRepository.swift` provides
   `addWorktree(named:branch:) throws -> URL`, `build(_:)`, `branch(_:at:)`, `checkout(_:)`,
   `destroy()`, and `RefFormat.supported()`. Tests build a **real** linked worktree with it rather
   than simulating one.
4. **Every shell-out goes through `GitProcess`** (`YardKit/Sources/YardGit/GitProcess.swift`). Do not
   construct `Process` directly — the boundary is centralised there so it stays testable, and
   libgit2 does not run hooks.
5. **Never build a path by concatenating onto `.git/`.** Resolve through `git rev-parse --git-path`
   or `WorktreeContext`. Reftable repositories have no `.git/refs/**` at all and return nothing
   rather than erroring.

## Tests must be able to fail

- Assert any extraction is non-empty before comparing it. A helper that silently returns nothing
  turns the next assertion into `[] == []`, which passes unconditionally — that cost #0087 a round.
- No `#expect(true)` or any assertion whose operands are literals.
- Exercise the real failure path, not only the happy one. Say how you confirmed the test fails when
  the behaviour is wrong, rather than asserting that it does.

## Expected behavior

- [ ] New file `YardKit/Sources/YardGit/WorktreeRepair.swift`. Create it; do not restructure existing files.
- [ ] Supports all three invocation positions git does: from the main worktree, from within a moved worktree, and from any worktree passing each moved path as an argument.
- [ ] Reports which links were repaired, not just success or failure.
- [ ] Tests move a linked worktree on disk, assert it is broken, repair it, and assert it resolves again.
- [ ] Tests use **swift-testing** — `import Testing`, `@Test`, `#expect`. Not XCTest. `swift test`'s summary line counts only swift-testing tests, so an XCTest file passes invisibly.
- [ ] `cd YardKit && swift build` succeeds, and `swift test` prints a `Test run with N tests` line
      you paste. **N must be greater than the count on `main` immediately before this change** —
      state both numbers so the increase is visible rather than asserted.
