## Description

Wire `switchyard hunks` into the command registry, following **the six-step pattern in #0115**, which
#0124 established and #0225–#0228 applied four times. One of the four per-command filings #0115's
closure requires (the split the retired #0338 asked for).

## The engine entry point this wraps

```swift
public func listHunks(at path: String, area: DiffArea, git: GitProcess = GitProcess()) throws -> [FileDiff]
```

in `YardKit/Sources/YardGit/Hunks.swift:412`. `FileDiff` and `Hunk` are **already `Encodable`** with
explicit `CodingKeys` (Hunks.swift:488, 497) and `DiffBlameWireTests` pins their bytes (#0132) — step
2 of the pattern is already done and must not be redone.

## Arguments — parse what is required, refuse everything else (guide §6)

`area` is required with no default: exactly one of `--staged` or `--unstaged`
(`DiffArea`, Hunks.swift:7). A missing or unparseable area returns the `usage`
exit code and a structured `EnvelopeFail` — **never a default guess**. This
exact shape was violated before (#0287) and is the reason the criterion exists.
Unknown flags are refused the same way.

## Expected behavior

- [ ] The arm in `YardKit/Sources/YardCommands/EngineCommands.swift`, resolving `WorktreeContext` for
      the **passed** working directory — never `FileManager.default.currentDirectoryPath`.
- [ ] `Encodable` on the result type with an explicit `CodingKeys` enum, property names unchanged.
      Already conforms — say so and change nothing.
- [ ] A `CommandSpec` in `CommandRegistry.all` — non-empty `summary`, non-empty `schemaName` "hunks",
      exit codes 0, 1 (usage), and 6 at least; `payload: nil` with the statusSpec/conflictsSpec/wtSpec
      precedent comment (array-of-objects with nested hunks; `PayloadShape` is flat-only, #0194).
- [ ] The golden schema regenerated and committed (`SCHEMA_REGENERATE=1 swift test --filter
      checkedInSchemasMatchEmitter`).
- [ ] Tests in `YardKit/Tests/YardCommandsTests/` asserting values a `FixtureRepository` determines —
      a modified tracked file under `--unstaged` and, after staging it, under `--staged` — plus a
      not-a-repository case (`error.code == "repository_error"`, exit 6) and a missing/bad-area case
      (`error.code == "usage"`, exit 1).
- [ ] Mutations, each run with its killing test named: break the not-a-repository path so it returns
      success; rename one `CodingKeys` case; remove the spec from `CommandRegistry.all`.
- [ ] `cd YardKit && swift test` prints a `Test run with N tests` line greater than the count in
      `docs/test-baseline.txt` at dispatch. State the delta.

## Notes

Guide §6, and M3's exit criterion "every M1 read command runs from the built binary". Nothing in
`main.swift` changes — the routing picks up any command in `CommandRegistry.all`. Running the real
binary end to end needs an installed app and a registered launch agent; that is #0054's script, not
this issue.
