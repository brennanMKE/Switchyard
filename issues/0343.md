## Description

**Found by #0160's fifteenth umbrella review, 2026-08-18**, and it costs every future review a
diagnosis before it can start.

`compositionDoesNotFallThroughForKnownEngineCommand`
(`YardKit/Tests/YardCommandsTests/RunEngineFallbackTests.swift:38`) calls
`runEngineCommand(arguments: ["whereami"], workingDirectory: FileManager.default.currentDirectoryPath)`
and requires a non-`nil` result — which requires **the test process's own working directory to be
inside a git worktree.**

That is true under `swift test` in a checkout, and **false in a `git archive HEAD` export**, which is
how every mutation-testing review is required to work (CLAUDE.md: *"a review that mutates source works
from `git archive HEAD` into the scratchpad"*). So a reviewer's baseline starts **red for a reason
that has nothing to do with what they are reviewing**, and pass 15 had to bisect it before it could
establish a baseline at all.

The workaround it found — `git init` plus one empty commit in the export root — works, but the next
reviewer will rediscover it.

## Notes

**Milestone M3.** Comes from **#0337**, which added both tests.

**The general rule this is an instance of:** a test that reads
`FileManager.default.currentDirectoryPath` is a test whose result depends on where it is run, and the
suite is run from at least three places — a checkout, a worktree, and an archive export. **Grep for
other uses of it in tests while you are here** and say what you found, even if you change nothing.
