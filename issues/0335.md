## Description

**Found by #0326's round, re-measured independently at review 2026-08-18.** `Foundation.Process` on
Darwin **normalizes non-ASCII environment *values* from NFC to NFD** as they cross the exec boundary.
`GitProcess.run(_:workingDirectory:extraEnvironment:)` is built on `Process`, so every value it
carries is subject to it. Measured with a standalone `swift` script — parent sets `Café Élodie`, child
prints the bytes it received:

```
swift-side bytes:  67  97 102 195 169  32 195 137 108 111 100 101
child saw bytes:   67  97 102 101 204 129  32  69 204 129 108 111 100 105 101
```

`é` (U+00E9, `195 169`) arrives as `e` + U+0301 (`101 204 129`). **Thirteen bytes in, fifteen out.**
Process *arguments* are unaffected — the same string passed as an argument round-trips exactly, which
is how #0326's test worked around it (`--author=` instead of `GIT_AUTHOR_NAME`).

**No production value is affected today, and this issue says so rather than implying a bug.** Every
`extraEnvironment` value the engine sets is ASCII: `GIT_AUTHOR_NAME` / `GIT_COMMITTER_NAME` /
`GIT_AUTHOR_EMAIL` are the literals `"switchyard"` and `"journal@switchyard.invalid"`
(`WorktreeSnapshot.swift:272-276`, `JournalAnchor.swift:254-257`); `GIT_INDEX_FILE` is
`FileManager.default.temporaryDirectory` plus `switchyard-…-<UUID>`, and `temporaryDirectory` is
`/var/folders/…` on macOS. `SWITCHYARD_YARD_INVOCATION` and `SWITCHYARD_JOURNAL_ENTRY` carry an
id from a fixed alphabet.

**The cost is to whoever meets it next.** #0326's round lost time to a byte diff that had nothing to
do with its issue, and every future non-ASCII commit-metadata path — an author name from a real user,
which M3's CLI will carry — walks into it.

## Expected behavior

- [ ] A doc comment on `GitProcess.run`'s and `capture`'s `extraEnvironment:` parameter recording the
      measurement above, in bytes, and saying that **arguments are not affected** — that is the
      workaround and it belongs beside the trap.
- [ ] A named test in `YardKit/Tests/YardGitTests/GitProcessTests.swift` that **pins the current
      behaviour**: pass a precomposed non-ASCII value through `extraEnvironment`, have the child echo
      it back, and assert the received bytes are the **NFD** form. If a future Foundation stops
      normalizing, that test fails and whoever sees it can delete the warning.
- [ ] **Do not add normalization to `GitProcess`.** Re-precomposing every value would be a behaviour
      change affecting paths that currently work, for a case no production caller reaches. If you
      think it should normalize, say so in the issue and stop.
- [ ] `cd YardKit && swift test` **twice, in the foreground with an explicit 900000 ms timeout**, both
      green, above the count in `docs/test-baseline.txt`.

`YardKit/Sources/YardGit/GitProcess.swift` (comments only) and
