## Description

**Measured 2026-08-18 while designing #0330's sweep, and the first thing that sweep found.**
`FileDiff.headerText` is a `schemaVersion: 1` payload field (`Hunks.swift:404` lists it in
`CodingKeys`), and **its `index` line's length is set by the user's `core.abbrev`.**

`listHunks` (`YardKit/Sources/YardGit/Hunks.swift:374-376`) passes no `--full-index`. Measured, git
2.50.1, same fixture and same unstaged edit throughout:

```
core.abbrev unset:  index e45c9c2..6319a87 100644
core.abbrev=4:      index e45c..6319 100644
core.abbrev=16:     index e45c9c2666d44e03..6319a87f8608c8e6 100644
core.abbrev=40:     index e45c9c2666d44e0327c1f9c239a74c508336053e..6319a87f8608c8e6bc44a1d8edfcafdbebd24ea3 100644
```

With `--full-index` added, all four produce the **same** full-40 line — measured, all four values.

**`headerText` is not cosmetic.** `Staging.swift:93` builds the patch it hands `git apply` as
`file.headerText + selected.map(\.patchText).joined()`, so this is also the byte the apply path
depends on. `git apply --cached --check` and `--3way --check` both still succeed under abbrev 4, 8, 16
and 40 — measured — so **this is not currently a broken-apply bug**; it is a wire-payload field
varying with user config, and `--full-index` is the flag whose entire purpose is to stop that.

## Expected behavior

- [ ] `listHunks` adds `--full-index` to its argument vector, after `--default-prefix`.
- [ ] A named test that sets `core.abbrev = 4` in a fixture and asserts the resulting `headerText`
      carries a **full 40-hex** `index` line — assert the hex run's length, not merely that the line
      differs from something.
- [ ] **Verify the config bites first**: without `--full-index`, plain `git diff` under
      `core.abbrev=4` must print `index e45c..6319`.
- [ ] The existing `HunksTests` header assertions still pass. Several pin `headerText` **byte for
      byte**, and `--full-index` lengthens that line in the *default* case too — **so this change
      updates existing expected values, and that is correct, not a regression.** Say which tests you
      updated and why.
- [ ] **Mutation:** drop `--full-index`. The new test must redden.
- [ ] `cd YardKit && swift test` **twice, in the foreground with an explicit 900000 ms timeout**, both
      green, above the count in `docs/test-baseline.txt`.
