## Description

The clean-room process has a required artifact: when a GitUp idea informs a design decision, the
idea is written into `docs/` **in your own words**, and the implementation is written from that note
rather than from the source.

This is not paperwork. It is what makes "clean-room" a true description of the process rather than a
claim about intent, and it is the thing that would matter if the question were ever asked seriously.

## Expected behavior

- [ ] A note exists for the snapshot/undo model, written before #0027 is implemented.
- [ ] A note exists for graph lane assignment, written before #0015 is implemented.
- [ ] A note exists for the rebase engine scope (#0060).
- [ ] Each note is written from understanding, contains no GitUp code, and does not paraphrase its source line by line.
- [ ] Each note records the date and what was read to form the understanding.
