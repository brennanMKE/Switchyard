## Description

**Finding 2 of #0160's second umbrella review, 2026-08-17.** #0160 bullet 5 says #0064
(`rewrite-diff`) can **read** the stored mapping. For a **foreign** rewrite it cannot: the mapping is
write-only, for two independent reasons, both established by probe.

**1. `JournalObserved.Metadata` is `Encodable` only.**

```swift
// JournalObserved.swift:43
public struct Metadata: Sendable, Equatable, Encodable {
```

A probe printed `is Decodable = false`. Nothing reddens today because the tests decode through their
**own mirrored struct** — the same shape preflight check 0d was just written for.

**2. `JournalAnchor.metadata(for:in:git:)` hardcodes the journal namespace.** Unlike `write` and
`updateMetadata`, which both take a `namespace:`, the read accessor does not — so against a real
observed entry's id it fails:

```
fatal: invalid object name 'refs/switchyard/journal/01M0943…'   exit 128
```

This is an asymmetry between #0160's two children: **#0221's half is readable** —
`JournalEntryMetadata` is `Codable` and `attachRewrite` round-trips it in production — and **#0220's
half is not**.

## Expected behavior

- [ ] `JournalObserved.Metadata` conforms to `Codable`. Decoding must handle both kinds: the
      discriminator is `kind`, and the payload field for the other kind is absent, not null.
- [ ] `JournalAnchor.metadata(for:in:git:namespace:)` takes a namespace defaulting to
      `JournalAnchor.refPrefix`, matching `write` and `updateMetadata`. Every existing call site keeps
      today's behaviour by taking the default.
- [ ] A **round-trip test through production**: `JournalObserved.record(...)`, then read the metadata
      back through the accessor with the observed namespace, then decode it, and assert the decoded
      value equals what was recorded — both kinds.
- [ ] The tests' **own mirrored decoding struct is deleted**, if one exists, and the tests decode
      through `Metadata` itself. That mirror is why this gap was invisible (preflight check 0d).
- [ ] Mutation, run and reported: make the accessor ignore its `namespace:` argument and confirm the
      round-trip test reddens.
- [ ] `cd YardKit && swift test` twice in the foreground, both green, **N greater than 1015**.

## The files

- `YardKit/Sources/YardGit/JournalObserved.swift` — the conformance.
- `YardKit/Sources/YardGit/JournalAnchor.swift` — the `namespace:` parameter on the read accessor.
- `YardKit/Tests/YardGitTests/JournalObservedTests.swift` — the round trip, and deleting the mirror.
