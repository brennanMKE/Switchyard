## Description

Split out of #0012, whose round 1 timed out partly on breadth. An agent needs to know whether commits
it makes will be signed, and how — before it makes one, not after.

This is independently useful and has nothing to do with answering "where am I", which is why it is
its own issue.

## Givens — verified on `main`, treat as true

1. New file `YardKit/Sources/YardGit/SigningConfig.swift`.
2. **`GitProcess` is a concrete struct**, constructed `GitProcess()`, with `run(_:at:)` and
   `capture(...)`. There is no runner protocol and no injection seam — do not invent one. Read
   `YardKit/Sources/YardGit/GitProcess.swift` before writing code.
3. Read config through `git config --get <key>`, never by parsing `.gitconfig` files. Config comes
   from system, global, local and worktree scopes and the resolution order is git's job.
4. The keys that matter: `commit.gpgsign`, `gpg.format` (`openpgp` or `ssh`), `user.signingKey`, and
   `gpg.ssh.allowedSignersFile`.
5. `docs/engine-findings.md` records a fact worth encoding: **without
   `gpg.ssh.allowedSignersFile`, git reports a valid SSH signature as untrusted rather than good.**
   So "will sign" and "can verify" are different questions and both belong here.

## Expected behavior

- [ ] A value type reporting: whether signing is on, the format, the signing key if set, and whether
      an allowed-signers file is configured. No printing.
- [ ] Absent config is reported as absent, not as a default guess. `commit.gpgsign` unset is not the
      same as `false` for reporting purposes, even though git treats it that way.
- [ ] Correct in a repository that sets these only globally, and in one that overrides locally.
- [ ] Tested against both ref formats via `FixtureRepository`.
- [ ] Tests use **swift-testing** — `import Testing`, `@Test`, `#expect`. Not XCTest.
- [ ] `cd YardKit && swift build` succeeds and `swift test` prints a `Test run with N tests` line you
      paste. **N must be greater than the count on `main` before this change** — state both numbers.

## Tests must be able to fail

Set the config in a fixture, assert the reported value, then change the config and assert it changed.
A test that only reads a repository with no signing configured passes for an implementation that
returns constants.

## Notes

Do not implement signing itself — that is #0036. This only reports what is configured.
