## Description

**Finding 8 of the M1 milestone review, sixth pass, 2026-08-18.** `hunks` loses `core.quotepath=false`
undetected.

`YardKit/Sources/YardGit/Hunks.swift:375`, mutated:

```swift
var arguments = ["diff"]     // was: ["-c", "core.quotepath=false", "diff"]
```

`Test run with 1078 tests in 78 suites passed after 52.646 seconds.` — **full suite, unfiltered.**

**The failure mode is a hard error, not a cosmetic one.** Without the flag git C-quotes any non-ASCII
path in the `diff --git` header, and `HunkParser` throws `malformedFileHeader` — so `listHunks` returns
an **error** on an ordinary repository that merely contains a non-ASCII filename.

**Why nothing catches it:** nothing in the suite drives a non-ASCII path through `listHunks`.
`quotedPathThrowsInsteadOfMisparsing` (`HunksTests.swift:329`) feeds a literal to the parser, and
`BlameTests.swift:255` does the same for the sibling flag on `blame`. Both pin the parser; neither pins
the argument vector.

Same shape as #0245 (`-z`) and #0267 (`--no-renames`) — and on the same argument vector as #0267.

- [ ] Verify with `git -c core.quotepath=true diff --name-only` that the name really would be quoted
