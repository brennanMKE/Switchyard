## Description

`CommitLog.parseTrailerBlock(from:)` (`YardKit/Sources/YardGit/CommitLog.swift`, line 375) and
`CommitLogEntry.subject` (line 428) split the message on the `"\n"` **Character**. Swift reads
`"\r\n"` as one Character, so a message with CRLF line endings is one line.

CRLF messages are real: git's default `strip` cleanup removes a trailing CR (measured: `git commit
-F` with `"x\r\n"` stores `"x\n"`), but `--cleanup=verbatim`, `git commit-tree` and imported
histories keep them (measured: `--cleanup=verbatim -F` with `"s\r\n\r\nAgent-Name: bot\r\n"`
stores those bytes, and `git log --format=%B%x00` prints them back unchanged).

Measured 2026-09-29 on `main` (git 2.54.0) through `CommitLog.run(path:rangeArguments: ["-1"])` on a
commit made with `--cleanup=verbatim -m "s\r\n\r\nAgent-Name: bot\r\n"`:

- **before:** `subject == "s\r\n\r\nAgent-Name: bot"` (the whole message, trimmed), `trailers == []`.
  So `hasProvenance` is false for an agent commit, and `--agent-only` drops it.
- **after:** `subject == "s"`, `trailers == [Trailer(key: "Agent-Name", value: "bot")]`, and `message`
  is still the stored bytes.

The blank-line test must change with the split. After a scalar split the blank line between
paragraphs is `"\r"`, and `CharacterSet.whitespaces` does not contain CR, so `isBlank` would say
no and the trailer block would still be missed. It moves to `.whitespacesAndNewlines`. Each trailer
line is already trimmed with `.whitespacesAndNewlines` before `Trailer.parse`, so a trailing `\r` is
dropped from the value.

**Unaffected, checked:** `parse(output:)` splits records on `"\u{0}"` and fields on `"\u{01}"`. Both
are control characters, which never join a grapheme cluster, including after `"\n"` or `"\r"`
(`"a\n\u{0}b".split(separator: "\u{0}").count == 2`, measured).

## The files

### 1. `YardKit/Sources/YardGit/CommitLog.swift`

Replace

```swift
        let lines = commitBody.split(separator: "\n", omittingEmptySubsequences: false)

        func isBlank(_ line: Substring) -> Bool {
            line.trimmingCharacters(in: .whitespaces).isEmpty
        }
```

with

```swift
        // Split on the newline *scalar*, not the `Character`: Swift reads
        // "\r\n" as one Character, so a CRLF message would be one line
        // (#0484, measured). A CRLF blank line is then "\r", which
        // `.whitespaces` does not contain, hence `.whitespacesAndNewlines`.
        let lines = commitBody.unicodeScalars.split(separator: "\n", omittingEmptySubsequences: false)
            .map(Substring.init)

        func isBlank(_ line: Substring) -> Bool {
            line.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty
        }
```

### 2. `YardKit/Sources/YardGit/CommitLog.swift`

Replace

```swift
        let firstLine = message.split(separator: "\n").first.map(String.init) ?? ""
```

with

```swift
        // The newline scalar, so a CRLF message's subject is its first line
        // (#0484, measured).
        let firstLine = message.unicodeScalars.split(separator: "\n").first
            .map { String(Substring($0)) } ?? ""
```

```swift
    /// `git commit --cleanup=verbatim` keeps a message's CRs (measured: the
    /// default `strip` cleanup removes them, `verbatim` does not). Swift reads
    /// "\r\n" as one `Character`, so the "\n" Character split saw the whole
    /// message as one line: no trailer block, and a subject that was the
    /// whole message (measured on `main`: `trailers == []`,
    /// `subject == "s\r\n\r\nAgent-Name: bot"`).
    @Test func aCRLFMessageParsesItsSubjectAndTrailers() throws {
        var repo = try FixtureRepository()
        defer { repo.destroy() }
        try repo.build([.init("base")])
        try GitProcess().run(
            ["commit", "-q", "--allow-empty", "--cleanup=verbatim", "-m", "s\r\n\r\nAgent-Name: bot\r\n"],
            workingDirectory: repo.url.path)

        let entry = try #require(try CommitLog.run(path: repo.url.path, rangeArguments: ["-1"]).first)

        #expect(entry.message == "s\r\n\r\nAgent-Name: bot\r\n")
        #expect(entry.subject == "s")
        #expect(entry.trailers == [Trailer(key: "Agent-Name", value: "bot")])
    }
```
