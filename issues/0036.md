# 0036 — Implement SSH commit signing

| | |
|---|---|
| **Status** | open |
| **Module** | YardGit |
| **Milestone** | M2 |
| **Platform** | macOS |
| **First seen** | 2026-08-06 |

## Description

Productionize what #0002 proved: build commit content with `git_commit_create_buffer`, sign with
`ssh-keygen -Y sign -f <key> -n git`, write with `git_commit_create_with_signature` under the
`gpgsig` header.

## Expected behavior

- [ ] Reads `user.signingKey`, `gpg.format`, and `commit.gpgsign` from git config and respects all three.
- [ ] `git log --show-signature` reports the result as verified.
- [ ] Signing failure exits 9 with a structured error, and **no commit is written** on failure.
- [ ] Tests generate a throwaway key in a temp dir and verify via `ssh-keygen -Y verify`.
- [ ] A passphrase-protected key produces a clear error rather than an indefinite hang.

## Notes

Guide §5 "Signing implementation". Blocked by #0002, #0008.

Never write to the user's real git config or read their real signing key in tests.
