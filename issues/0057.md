## Description

Open the three-way merge UI for a conflicted path, block, and return the resolution. The interactive
counterpart to `yard conflicts` (#0017), and the place where a human's judgment gets captured once
and reused by `rerere` (#0065).

## Expected behavior

- [ ] Renders in the **Detail pane** of the conflicted repository's tab, routed through #0084 — not in a detached window.
- [ ] Renders ours, base, and theirs from the blob IDs #0017 reports.
- [ ] Resolution is written to the index and returned as structured data.
- [ ] Handles add/add, delete/modify, and rename conflicts, not only content conflicts.
- [ ] Exit 3 when the app is unavailable; exit 8 when conflicts remain unresolved on return.
- [ ] Cancelling leaves the conflicted state untouched, not half-resolved.
