## Description

**M1 exit criterion served (guide §9, criterion 2):** "The engine behind each of `wt list`, `wt new`,
`wt rm`, `wt where`, `wt gc`, `wt repair` … returns a type that encodes to a `schemaVersion: 1`
envelope."

Found by the M1 milestone review, 2026-08-07. `WorktreePrune.gc` in
`YardKit/Sources/YardGit/WorktreePrune.swift` returns `(reports: [Report], pruned: [String])` — a
tuple. Tuples are non-nominal and cannot conform to `Encodable`, so the full `wt gc` result cannot
pass through `EncodableResult` into an `Envelope`. Five of the six `wt` engine functions return a
nominal encodable type; `gc` is the one that does not. The existing wire test
`envelopeWrapsPruneAndRepairPayloads` (#0135) wraps only `[Report]` — the `pruned` list can never
ride the envelope, because there is no type to encode. An agent calling `wt gc --prune` needs both
halves in one response: what was reported and what was actually pruned.

**One deliverable:** `gc` returns a new nominal type `WorktreePrune.GCResult` — five anchored
edits to `WorktreePrune.swift` plus one new test file
`YardKit/Tests/YardWireTests/GcResultWireTests.swift`. **All changes are written out below in full
and were compiled, run, and mutation-tested in a scratch clone of `main` (`2fd962d`) on
2026-08-07** — the suite went from a measured 530 to `Test run with 533 tests in 34 suites` (+3
exactly), every mutation row observed (two as red tests with the killing tests recorded, one as a
test-target compile failure, one killed by *pre-existing* `YardGitTests`), then reverted. The
round's work is transcription plus running the verification.

## Decisions — settled here

1. **The name is `WorktreePrune.GCResult`, nested.** The prune family already nests its types
   (`WorktreePrune.Report`, `Report.Reportable`), unlike the top-level `WorktreeAddResult` /
   `WorktreeRemoveResult` families — matching the file's own convention, not inventing one. The
   acronym is uppercase (`GC`, not `Gc`) per the project's existing style: `headOID`, `OID`
   uppercase throughout `WhereAmI`.
2. **The member names are the tuple's labels, `reports` and `pruned`, verbatim.** Measured
   consequence: all 12 existing call sites use member access (`.reports` / `.pruned`), never
   destructuring, so **zero caller lines change** — `swift build --build-tests` compiles every
   test target against the new type with no edits outside `WorktreePrune.swift` (Given 2).
3. **`pruned` keeps its name, and its doc comment says exactly what it holds** (measured, Given 1):
   the verbatim stderr lines of `git worktree prune -v` — on a successful prune, one
   `Removing worktrees/<id>: <reason>` line per reaped entry, where `<id>` is the administrative
   directory name under `$GIT_DIR/worktrees`, **not the working-tree path**. Git's wording rides
   verbatim, never paraphrased (the same rule `Report.reason` already follows).
4. **Both members are non-optional arrays, so both keys are always on the wire** — a report-only
   run encodes `"pruned":[]`, never omits the key. #0129 Decision 4 (nil omitted) has no subject
   here: `GCResult` has no optionals. The rest of the #0129 pattern applies unchanged: keys are the
   member names verbatim, explicit `CodingKeys` with no raw values, byte-pins with `JSONEncoder` +
   `.sortedKeys`, conformance in the engine as plain-stdlib `Encodable`.
5. **`WorktreePrune` declares no error enum, so #0146 has no work here** — verified by reading the
   file: `gc` rethrows `GitProcess` failures and throws nothing of its own. Nothing in this issue
   overlaps with #0146's `ExitClassCarrying` sweep.

## Givens — each measured on this machine, 2026-08-07

1. **What `pruned` actually contains, measured end to end twice.** Raw git (2.50.1, Apple
   Git-155): a fixture with one unlocked worktree whose directory was deleted; `git worktree
   prune -v` wrote **nothing to stdout** (0 bytes) and exactly this to stderr (`od -c` confirmed,
   single trailing `\n`):

   ```
   Removing worktrees/wt-unlocked: gitdir file points to non-existent location
   ```

   Through the engine: a throwaway test built a `FixtureRepository.linear()`, added worktree
   `probe`, deleted its directory, ran `WorktreePrune.gc(repositoryPath:prune:true)` — `pruned`
   held exactly one element:
   `Removing worktrees/yard-fixture-<UUID>-wt-probe: gitdir file points to non-existent location`.
   So the elements are prune's per-reap diagnostic lines carrying the **administrative** name, not
   working-tree paths.
2. **All 12 call sites compile unchanged.** Every call site of `WorktreePrune.gc` in the package
   is in `YardKit/Tests/YardGitTests/WorktreePruneGcTests.swift` (lines 73, 92, 114, 127, 150,
   178, 199, 217, 239, 271, 275, 287); none in `Sources/`. All use `.reports` / `.pruned` member
   access — no `let (reports, pruned) = …` destructuring anywhere. Because Decision 2 keeps the
   labels, member access is source-compatible: measured by `swift build --build-tests` printing
   `Build complete!` against the changed source with **no test-file edits**, and by the full
   533-test green run. **Do not edit `WorktreePruneGcTests.swift` at all.**
3. **`WorktreePrune.Report` is already `Encodable`** (#0135) with wire keys
   `path, type, reason, lockReason, removable`, and `Report` is `Equatable`, so
   `GCResult: Sendable, Equatable` synthesizes. The nested `Report` shape inside `GCResult`'s
   wire literals below is #0135's, byte-identical — its own tests in `MaintenanceWireTests.swift`
   stay untouched and green.
4. **`wireJSON` is on `main` in `YardKit/Tests/YardWireTests/WhereAmIWireTests.swift`** (#0129).
   Reuse it; do not redeclare it — a second declaration in the same target is a compile error.
5. **`JSONEncoder` escapes forward slashes**: `worktrees/repo-gone` encodes as
   `worktrees\/repo-gone` (visible in every literal below). Do not "fix" the literals; they are
   pasted from a real run.
6. **Edit hazard (the #0141 bare-`}` class): every anchor below is unique in today's file** —
   each of `    // MARK: - Public surface`, `) throws -> (reports: [Report], pruned: [String]) {`,
   `return (reports, pruned)`, and `return (reports, [])` appears exactly once (`grep -c` prints
   `1` for each). Use the `edit` tool with these anchors, or `cat >>` for the end-of-file append
   only — never `cat >` onto this existing file (AGENTS.md Rule 5c). After the change,
   `grep -c 'private enum CodingKeys'` on the file prints `2` (Report's from #0135, plus
   `GCResult`'s).
7. **Baseline.** `docs/test-baseline.txt` read **530** as this planning pass finished. On the
   scratch clone of `main` (`2fd962d`) the suite measured **530**; after these changes,
   **`Test run with 533 tests in 34 suites`** — the delta is **+3**. Trust the delta, not the
   absolute.
8. **No `Package.swift` change.** The `Tests/YardWireTests` target exists on `main` (#0129).

## Change 1 — `YardKit/Sources/YardGit/WorktreePrune.swift`, five anchored edits

**Edit 1a** — insert the struct. Replace the unique line

```swift
    // MARK: - Public surface
```

with:

```swift
    // MARK: - Public surface

    /// The full result of a `gc` run: everything reported, plus git's own
    /// account of what a prune reaped. A nominal type (not a tuple) so the
    /// whole `wt gc` response can encode to the `schemaVersion: 1` envelope.
    public struct GCResult: Sendable, Equatable {

        /// All prunable and abandoned-session worktrees, exactly as
        /// `report(from:)` returns them, in porcelain order.
        public let reports: [Report]

        /// The verbatim stderr lines from `git worktree prune -v` — on a
        /// successful prune, one `Removing worktrees/<id>: <reason>` line per
        /// reaped entry, where `<id>` is the administrative directory name
        /// under `$GIT_DIR/worktrees`, not the working-tree path. Git's
        /// wording rides verbatim, never paraphrased. Empty when `prune` was
        /// false or nothing was reaped.
        public let pruned: [String]

        public init(reports: [Report], pruned: [String]) {
            self.reports = reports
            self.pruned = pruned
        }
    }
```

**Edit 1b** — the return type. Replace the unique line

```swift

```

with:

```swift
    ) throws -> GCResult {
```

**Edit 1c** — the prune branch. Replace the unique line

```swift

```

with:

```swift
            return GCResult(reports: reports, pruned: pruned)
```

**Edit 1d** — the report-only branch. Replace the unique line

```swift

```


**Edit 1e** — append at end of file (`cat >>` is fine for this one; the file ends with #0135's
`extension WorktreePrune.Report: Encodable { … }` closing brace):

```swift

// MARK: - Wire encoding (#0139)

/// `WorktreePrune.GCResult` is the `schemaVersion: 1` payload for `wt gc`:
/// `gc(repositoryPath:prune:)` returns it, and it rides whole in `result` —
/// both halves, what was reported and what was actually pruned, in one
/// response. Plain-stdlib `Encodable` — the engine still imports nothing.
extension WorktreePrune.GCResult: Encodable {
    /// Stable wire keys, identical to the stored-member names; no raw values.
    /// Both members are non-optional arrays, so both keys are always present
    /// on the wire — `"pruned":[]` for a report-only run, never omitted.
    private enum CodingKeys: String, CodingKey {
        case reports, pruned
    }
}
```

Do not write an `encode(to:)` method — synthesis handles it. Do not touch any other type, and do
not edit `WorktreePruneGcTests.swift` (Given 2).

## Change 2 — `YardKit/Tests/YardWireTests/GcResultWireTests.swift`, new file, in full

New file: create with `cat >` (AGENTS.md Rule 5c — the path does not exist).

```swift
// GcResultWireTests.swift — the wt gc result encodes to the schemaVersion 1
// envelope (#0139): WorktreePrune.GCResult carries both halves — what was
// reported and what was actually pruned — in one response.

import Foundation
import Testing
import YardGit
import YardKit

@Suite("WorktreePrune.GCResult wire shape")
struct GcResultWireTests {

    /// A prune run that reported one prunable entry and reaped it. The
    /// `pruned` element is git's verbatim `git worktree prune -v` stderr line
    /// (measured 2026-08-07): `Removing worktrees/<id>: <reason>`, where
    /// `<id>` is the administrative name under `$GIT_DIR/worktrees`, not the
    /// working-tree path. The nested `Report` shape is #0135's, unchanged.
    @Test func gcResultEncodesToTheLiteralWireShape() throws {
        let value = WorktreePrune.GCResult(
            reports: [WorktreePrune.Report(
                path: "/Users/dev/repo-gone",
                type: .prunable,
                reason: "gitdir file points to non-existent location")],
            pruned: ["Removing worktrees/repo-gone: gitdir file points to non-existent location"])
        #expect(try wireJSON(value) == #"{"pruned":["Removing worktrees\/repo-gone: gitdir file points to non-existent location"],"reports":[{"path":"\/Users\/dev\/repo-gone","reason":"gitdir file points to non-existent location","removable":true,"type":"prunable"}]}"#)
    }

    /// A report-only run (the default): both members are non-optional
    /// arrays, so BOTH keys are always on the wire — `"pruned":[]` is
    /// present, never omitted. An agent reading the response can distinguish
    /// "nothing was pruned" from a missing field.
    @Test func reportOnlyGCResultKeepsBothKeysWithEmptyPruned() throws {
        let value = WorktreePrune.GCResult(reports: [], pruned: [])
        let json = try wireJSON(value)
        #expect(json == #"{"pruned":[],"reports":[]}"#)
        #expect(json.contains(#""pruned""#))
        #expect(json.contains(#""reports""#))
    }

    /// The M1 exit-criterion sentence for `wt gc`, literally: the engine
    /// result type encodes to a `schemaVersion: 1` envelope — the compile
    /// itself proves the `Encodable & Sendable` bound through
    /// `EncodableResult`, and the literal pins the whole response including
    /// an abandoned session's `lockReason` riding inside the envelope.
    @Test func envelopeWrapsGCResultWithTheV1Keys() throws {
        let value = WorktreePrune.GCResult(
            reports: [WorktreePrune.Report(
                path: "/Users/dev/repo-0042",
                type: .abandonedSession,
                lockReason: "switchyard-agent:session=7f3a")],
            pruned: [])
        let json = try wireJSON(Envelope(result: EncodableResult(value)))
        #expect(json == #"{"ok":true,"result":{"pruned":[],"reports":[{"lockReason":"switchyard-agent:session=7f3a","path":"\/Users\/dev\/repo-0042","removable":false,"type":"abandonedSession"}]},"schemaVersion":1}"#)

        // Structural read-back of the envelope frame, so a failure here
        // distinguishes "envelope broke" from "payload byte drift".
        let object = try #require(
            try JSONSerialization.jsonObject(with: Data(json.utf8)) as? [String: Any])
        #expect(object["schemaVersion"] as? Int == 1)
        #expect(object["ok"] as? Bool == true)
        let result = try #require(object["result"] as? [String: Any])
        #expect(result["pruned"] as? [String] == [])
        let reports = try #require(result["reports"] as? [[String: Any]])
        #expect(reports.first?["type"] as? String == "abandonedSession")
    }
}
```
