## Description

Structured, range-limited blame. The range limit is the important part for agents: blaming a whole
file to find out who last touched three lines is wasteful, and `yard absorb` (#0061) needs exactly
this — the commit that last touched a given line range.

## Expected behavior

- [ ] New file `YardKit/Sources/YardGit/Blame.swift`. Create it; do not restructure existing files.
- [ ] `--range A:B` limits computation, not just output.
- [ ] Each line reports commit, author, timestamp, and original line number.
- [ ] Correct across renames when git can follow them.
- [ ] Performance on a large file is measured and recorded in the issue.
- [ ] Tests use **swift-testing** — `import Testing`, `@Test`, `#expect`. Not XCTest. `swift test`'s summary line counts only swift-testing tests, so an XCTest file passes invisibly.
- [ ] `cd YardKit && swift build` succeeds, and `swift test` prints a `Test run with N tests` line you paste. N must be greater than the count on `main` before this change.
