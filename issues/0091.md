# 0091 — Emit the failure envelope to stdout, and nothing else

## Description

`EnvelopeFail.write()` must put **exactly one thing** on stdout: the JSON envelope. Round 2 broke
this — a helper case named `.stderr` calls `Swift.print`, which writes to stdout, so a human-readable
`[error] <code>: <message>` line is emitted *before* the JSON. An agent parsing stdout gets a
non-JSON prefix line and fails on the first character.

This is the whole point of the issue: JSON is the contract, and the contract is that stdout contains
JSON and nothing else.

## Expected behavior

- [ ] `write()` emits the JSON envelope to stdout and **nothing else** — no prefix, no suffix, no human line.
- [ ] Anything written for human consumption goes to **actual stderr** via `FileHandle.standardError`, never `Swift.print`.
- [ ] Delete the `indirect` on `StandardStream` — the enum has no payload and does not need it.
- [ ] A test captures stdout and asserts the captured bytes parse as JSON with **no leading or trailing non-JSON content**.
- [ ] `swift build` succeeds and `swift test` prints a `Test run with N tests` line you paste.
