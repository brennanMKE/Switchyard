## Description

**Finding 2 of the #0160 umbrella review, 2026-08-17.** One `switchyard` operation fires **three**
`post-rewrite` invocations carrying the same entry id, and `JournalEntryMetadata.rewrite` is a single
optional `RewriteMapping` that `attachingRewrite` **replaces** — so it is last-write-wins, and the
pair naming the entry's own pre-operation `HEAD` is the one that gets lost.

Measured by the review in a scratch copy, git 2.50.1, driving `Fixup.run(source:target:)` (the
existing-commit mode, `Fixup.swift:337`), which runs `git commit --amend --fixup=…` **and** an
autosquash rebase inside one `JournalCheckpoint.around`:

```
amend   rebaseMerge=false  0dcb7033… → d599f32…     ← the only pair naming the pre-checkpoint HEAD
amend   rebaseMerge=true   50097fed… → b122f62…     ← an intermediate commit (see #0233)
rebase  rebaseMerge=true   50097fed… → b122f62…, d599f32… → b122f62…

FINAL stored mapping = invocation 3
headBefore present in final mapping's old oids: false
```

The entry's snapshot `HEAD` appears **nowhere** in the stored mapping, so nothing can connect the
state the entry captured to the commit the operation produced — which is what bullet 5 exists for.

The existing end-to-end test passes because it drives the **staged-index** mode, which happens to fire
only two invocations.

## The design choice, and it is the substance of this issue

**A — store an ordered list.** `rewrite` becomes `[RewriteMapping]`, appended per invocation. Honest,
loses nothing, and pushes the composition onto every consumer including #0064.

**B — compose on attach.** Keep one mapping: skip mid-rebase amends (**#0233**), and merge a preceding
standalone `amend` into the final `rebase` mapping by chaining old→new through the intermediate. The
stored mapping then reads as "what this operation did", which is what an entry means.

**B is the better shape and the more delicate one**, because the chaining is where an off-by-one hides:
after #0233 the surviving invocations are the standalone `amend` (`A → B`) and the final `rebase`
(`B → C`, plus others), and the composition must yield `A → C` without inventing a pair for a commit
that never existed. Whichever is chosen, **say which and why in the code**, and pin the composition
with a test built on the measurement above.

## The files

- **`YardKit/Sources/YardGit/JournalEntryMetadata.swift`** — `RewriteMapping` and `attachingRewrite`.
- **`YardKit/Sources/YardGit/JournalCheckpoint.swift`** — `attachRewrite`, where the composition

- **`YardKit/Tests/YardGitTests/PostRewriteAttachTests.swift`** — the end-to-end test.
- **`YardKit/Tests/YardWireTests/`** — the encoded shape, if it changes.
