## Description

Guide §11 decision 42 in the Changes view (`WorkingChangesView`).

- `loadWorkingDiffs(at:options:)` passes `options` to **both** async `listHunks` calls (default
  `.standard`, so `WorkingChangesTests`' calls are unchanged).
- The view owns `@State diffOptions = DiffViewOptions()` (not persisted) and `@State
  diffsDrawnWith` — the options the loaded `diffs` were drawn with. The diffs reload in a new
  `.task(id: DiffLoad(revision:options:))`; the Amend target keeps its own `.task(id: revision)`.
  A load cancelled by the next one (`CancellationError`, which `GitProcess` throws when its task is
  cancelled) leaves the pane alone instead of showing the error.
- With a file selected, `DiffOptionsBar(options:stagingNote: true)` sits over its diff.
- **`actsOnHunks = diffOptions.isStandard && diffsDrawnWith.isStandard`**: Stage/Unstage Hunk and
  Discard Hunk… are disabled and `lineSelection` is `nil` (lines not selectable) unless both hold —
  the second so that switching back to standard options does not re-enable the buttons over the
  filtered listing still on screen. New options clear the line selection. File-level Stage,
  Unstage, Discard Changes… and the section buttons are not touched: they act on paths.
- A tracked file with no diff while `diffsDrawnWith.ignoresWhitespace` shows "Only whitespace
  changed in <path>" (`-w` leaves it out of the listing — measured in #0535).

The engine refuses a filtered hunk id on its own (#0535's
`aHunkIDFromAWhitespaceIgnoringListingStagesNothing`); the disabled buttons and the note are the
visible half. #0542's VM spike pins them (Stage Hunk disabled with whitespace ignored, enabled after
Reset, and staging after Reset).

### 3. `YardKit/Tests/YardUITests/WorkingDiffOptionsTests.swift` — new file, exactly this

```swift
// WorkingDiffOptionsTests.swift — the Changes view's diffs drawn with diff
// options (#0539, guide §11 decision 42)

import Testing
@testable import YardGit
@testable import YardUI

@Test(arguments: FixtureRepository.RefFormat.supported())
func loadWorkingDiffsDrawsBothSidesWithTheOptions(format: FixtureRepository.RefFormat) async throws {
    var repo = try FixtureRepository(refFormat: format)
    defer { repo.destroy() }
    try repo.build([.init("base", files: ["a.txt": "setup\nfoo();\nbar();\n", "ws.txt": "y\n"])])
    try repo.writeUntracked(["ws.txt": "  y\n"])
    try await GitProcess().run(["add", "ws.txt"], workingDirectory: repo.url.path)
    try repo.writeUntracked(["a.txt": "setup\nif ready {\n    foo();\n}\nbar();\n"])

    let shown = try await loadWorkingDiffs(at: repo.url.path, options: DiffOptions(ignoresWhitespace: true))
    let pinned = try await loadWorkingDiffs(at: repo.url.path)

    #expect(shown.file("a.txt", staged: false)?.hunks.first?.body.contains("-foo();") == false,
            "the unstaged side is drawn with whitespace ignored")
    #expect(pinned.file("a.txt", staged: false)?.hunks.first?.body.contains("-foo();") == true)
    #expect(shown.staged.isEmpty, "the staged side is drawn with whitespace ignored")
    #expect(pinned.staged.map(\.path) == ["ws.txt"])
}
```
