## Description

Define the agent provenance trailer format once, before any commits carry it, because changing it
later means the existing commits are wrong forever.

Suggested shape, following the `Co-authored-by` convention so existing tooling ignores it gracefully:

```
Agent-Name: claude-code
Agent-Model: claude-opus-5
Agent-Session: 01J8X...
```

## Expected behavior

- [ ] `docs/provenance.md` specifies exact trailer keys, value formats, and ordering.
- [ ] The trailers-versus-notes split from #0059 is documented in the same file.
- [ ] Parsing rules are specified for `yard log --agent-only`.
- [ ] Behavior with multiple agents on one commit is defined.
- [ ] Verified against `git interpret-trailers` so standard tooling reads them correctly.

## Notes

Guide §6 "Agent provenance". Blocks #0038, #0059.

## Fix

`docs/provenance.md` (110 lines) specifies the three trailer keys, their value formats and ordering,
what happens when more than one agent is on a commit, the parsing rules for `yard log --agent-only`,
and the trailers-versus-notes split from #0059.

**Implemented by Ornith via OpenCode — the first issue delegated end to end.**

## Verification

All five done-criteria met, checked against the file rather than against the model's summary:

- Trailer keys and value formats — `## The trailers`, `## Value constraints`.
- Trailers-vs-notes split — `## The trailers-versus-notes split (#0059)`.
- `--agent-only` parsing rules — `## Parsing rules`, including two failure cases: an `Agent-Name`
  with no model or session keeps the commit and warns, while a model or session with no `Agent-Name`
  is ignored as an accidental copy.
- Multiple agents — primary/secondary convention, with the first `Agent-Name` deciding `--agent-only`
  matching.
- `git interpret-trailers` — verified independently, not just by the model: a commit carrying two
  `Agent-Name` trailers round-trips through `--parse`, and
  `%(trailers:key=Agent-Name,valueonly)` returns both values.

## Gotchas

The model reasoned about a case the issue did not name: an incomplete provenance record. Its rule —
keep the commit, blank the missing fields, warn on stderr — is right, and the stated reason is right
too: hiding an incomplete record is a worse signal than surfacing it.
