## Description

Define the agent provenance trailer format once, before any commits carry it, because changing it
later means the existing commits are wrong forever.

Suggested shape, following the `Co-authored-by` convention so existing tooling ignores it gracefully:

```
Agent-Name: claude-code
Agent-Model: claude-opus-5
Agent-Session: 01J8X...
```

## Review — round 1 rejected

Round 1 produced a well-structured 110-line `docs/provenance.md` that addresses all five
done-criteria in prose, and the model genuinely ran `git interpret-trailers --parse` rather than
claiming to. But independent verification found five defects, three of them factual errors about git
that would mislead whoever implements #0038 and #0019.

**Fix these in round 2:**

1. **`%trailers` is not a git format atom.** The doc cites `git log --format=%trailers`, which
   expands to `%t` (tree hash) followed by the literal text `railers` — verified output
   `4b825dcrailers`. The correct atom is `%(trailers)`.

2. **Trailer key matching is case-insensitive, not case-sensitive.** The doc asserts `Agent-Name`
   and `Agent-Model` are "case-sensitive on read". Verified otherwise:
   `%(trailers:key=Agent-Name)` matches a lowercase `agent-name:` trailer. Correct the claim, and
   say what canonical casing we *write* versus what we must *accept* on read.

3. **The trailer block must be the last paragraph of the message — the doc never says so.** This is
   the most consequential omission, because it is a hard git requirement rather than a convention:
   a message with any prose *after* the trailers parses as **zero** trailers. Verified. Anything
   that appends to a commit message after provenance is written silently destroys the whole block,
   which directly affects #0038.

4. **A false cross-reference.** The doc claims `switchyard-git-internals-and-undo.md` "points at
   this file". It contains no mention of `provenance.md`. Either remove the claim or add the pointer
   to that document.

5. **The issue's second half is untouched.** The title is "Write docs/provenance.md **and fix the
   trailer format**". The guide's §6 "Suggested shape" wording is unchanged — it still reads as a
   suggestion. Promote it to the settled format and point it at `docs/provenance.md`.

Keep everything else: the primary/secondary agent convention, the incomplete-record rule, and the
notes-versus-trailers split are all correct and well argued.
