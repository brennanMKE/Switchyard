## Description

Define the agent provenance trailer format once, before any commits carry it, because changing it
later means the existing commits are wrong forever.

Suggested shape, following the `Co-authored-by` convention so existing tooling ignores it gracefully:

```
Agent-Name: claude-code
Agent-Model: claude-opus-5
Agent-Session: 01J8X...
```

### The five edits

1. **`docs/provenance.md` line ~107 uses `%trailers`, which is not a git atom.** It expands to `%t`
   (the tree hash) followed by the literal text `railers` — verified output `0858569railers`. Replace
   every occurrence with **`%(trailers)`**. The working forms are:
   - `git log -1 --format='%(trailers)'`
   - `git log -1 --format='%(trailers:key=Agent-Name,valueonly)'`

2. **Line ~37 claims trailer keys are "case-sensitive on read". They are not.** A commit whose
   trailer reads `agent-name: ornith-lower` is matched by
   `git log -1 --format='%(trailers:key=Agent-Name,valueonly)'`, which returns `ornith-lower`.
   Correct the claim: state that Switchyard **writes** the canonical casing `Agent-Name`,
   `Agent-Model`, `Agent-Session`, but must **accept any casing on read**, because git matches
   case-insensitively.

3. **Add git's hard last-paragraph requirement, which the document omits entirely.** The trailer
   block must be the **final paragraph** of the commit message. If any prose follows it,
   `git interpret-trailers --parse` returns **zero** trailers and `%(trailers)` returns nothing — the
   whole block is silently void. Add a section saying so, and state the consequence for #0038:
   anything that appends to a commit message after provenance has been written destroys the entire
   provenance record with no error.

4. **Line ~85 falsely claims `switchyard-git-internals-and-undo.md` "points at this file".** It does
   not — that document contains no reference to `provenance.md`. Delete the claim. Do not edit the
   other document.

5. **Promote the format in the development guide.** `docs/switchyard-development-guide.md` line ~495
   still calls the trailer shape a "Suggested shape". Change that wording so it reads as the settled
   format, and keep its existing pointer to `docs/provenance.md`.
