## Description

Define the agent provenance trailer format once, before any commits carry it, because changing it
later means the existing commits are wrong forever.

Suggested shape, following the `Co-authored-by` convention so existing tooling ignores it gracefully:

```
Agent-Name: claude-code
Agent-Model: claude-opus-5
Agent-Session: 01J8X...
```

## Expected behavior

- [ ] `docs/provenance.md` specifies exact trailer keys, value formats, and ordering.
- [ ] The trailers-versus-notes split from #0059 is documented in the same file.
- [ ] Parsing rules are specified for `yard log --agent-only`.
- [ ] Behavior with multiple agents on one commit is defined.
- [ ] Verified against `git interpret-trailers` so standard tooling reads them correctly.
