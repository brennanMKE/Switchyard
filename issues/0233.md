## Description

**Finding 1 of the #0160 umbrella review, 2026-08-17.** The mid-rebase dedup rule — *only the final
`rebase` invocation is authoritative* — is enforced on the **foreign** path and **structurally
unreachable on the own path**.

In `JournalObserved.record(_ decision:…)` the gate sits *after* the own/foreign split
(`JournalObserved.swift:142-149`):

```swift
guard !decision.isOwnInvocation else { return nil }      // own invocations leave here
if decision.source == .amend {                            // ...so never reach this
    let rebaseMergePath = try context.path(for: "rebase-merge", git: git)
    if fileManager.fileExists(atPath: rebaseMergePath) { return nil }
}
```

and `JournalCheckpoint.attachRewrite` (`JournalCheckpoint.swift:298-313`) has no equivalent.

**Established by the review**, in a scratch copy: deleting the whole `if decision.source == .amend`
block reddens exactly one test — `aMidRebaseAmendDoesNotProduceItsOwnObservedEntry` — and every
`PostRewriteAttach` test stays green. A probe that fired a real own autosquash and routed each
invocation through `attachRewrite` attached the mapping `50097fe → b122f62`, **whose old oid is an
intermediate commit that never existed before the rewrite**.

The tell was already in the test file: `PostRewriteAttachTests` picks the authoritative invocation
**itself**, in a helper (`finalInvocation` → `logged.last`). Nothing in production does that.

## Expected behavior

- [ ] The `rebase-merge` gate moves to a helper both `JournalObserved.record(_ decision:)` and
      `JournalCheckpoint.attachRewrite` call, **before** the own/foreign split — so the rule is one
      implementation rather than two, and cannot be enforced on one path only.
- [ ] An own-path test mirroring `aMidRebaseAmendDoesNotProduceItsOwnObservedEntry`: a mid-rebase
      `amend` decision with an entry id attaches **nothing**, and the entry's metadata still carries
      no `rewrite`.
- [ ] `PostRewriteAttachTests`' own `finalInvocation` helper is **no longer needed to make the tests
      pass** — the production code selects. Keep it if it still aids readability, but say whether a
      test now passes the mid-rebase invocation directly and gets nothing.
- [ ] Mutation, run and reported: delete the shared gate and confirm **both** the foreign test and the
      new own test redden.
- [ ] `cd YardKit && swift test` twice, both green, above the count in `docs/test-baseline.txt`.
