## Description

**Proposal 1 of #0044's fifth umbrella review, 2026-08-17**, filed as an ordinary issue. Two small,
related gaps in how the per-worktree ref namespaces are pinned.

**1. `refs/bisect/*` capture is unpinned.** Adding a `refs/bisect/` skip to
`RefSnapshot.listDirectRefs` leaves **all 1044 tests green**. This is verbatim **#0249**'s class: the
equivalent mutation for `refs/rewritten/` kills `roundTripRestoresRefsRewritten`, and for
`refs/worktree/` kills `aCaptureFromASiblingFiltersToSomethingSafeToApply` — **bisect has neither.**

Decision 6 names only `refs/rewritten/*` and `refs/worktree/*`, so this is not a decision violation.
But #0044's own premise lists `refs/bisect/` alongside them, `RefSnapshot.perWorktreeNamespaces`
carries it, and **a mid-bisect undo would silently stop round-tripping.**

**2. The gate-order test has no vacuity guard.**
`aForeignEntryStillReportsTheWorktreeGateEvenWhenTheGuardWouldFire` genuinely pins decision 3 today —
the fifth review's M10 kills it. But it asserts only that the **gate** error comes out; **nothing
asserts the guard would in fact have fired** on this fixture.

That is precisely how #0230's original went dead: #0232 landed four hours later, made the fixture's
rogue ref invisible to the guard, and the test kept passing while pinning nothing. #0248 re-keyed it
without adding the check. **This umbrella has already lost one pin exactly this way**, which is the
argument for two lines of insurance.

## Expected behavior

- [ ] A round-trip test for `refs/bisect/*`, symmetrical with `roundTripRestoresRefsRewritten` —
      write one, checkpoint, move it, restore, assert it is back.
- [ ] Mutation: add a `refs/bisect/` skip to `listDirectRefs` and confirm the new test reddens.
- [ ] `aForeignEntryStillReportsTheWorktreeGateEvenWhenTheGuardWouldFire` gains a `#require` that
      `CrossToolGuard.diff(recorded: believed, applied: target, current: now)` is **non-empty** for its
      fixture — so the test fails loudly if a future change makes the guard indifferent, instead of
      passing while pinning nothing.
- [ ] Mutation: neutralise the fixture's drift so the guard would not fire, and confirm the new
      `#require` fails rather than the test silently passing.
- [ ] `cd YardKit && swift test` **twice, in the foreground**, both green, above the count in
      `docs/test-baseline.txt`.
