## Description

Per-file, per-hunk conflicts with ours, base, and theirs blob IDs — the structured form of what an
agent otherwise has to scrape out of conflict markers in the working tree.

Blob IDs rather than inline text so the caller can fetch exactly the version it needs, and so the
three-way merge UI (#0057) has something precise to open.

## Expected behavior

- [ ] Reports index stages 1, 2, and 3 per conflicted path.
- [ ] Distinguishes content conflicts from add/add, delete/modify, and rename conflicts.
- [ ] Works during a merge, a rebase, and a cherry-pick.
- [ ] Exit code 8 is used when a caller's operation is blocked on unresolved conflicts.
