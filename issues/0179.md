## Description

**Filed by #0168's review on 2026-08-08, from a mutation the table lacked.**

#0168 decisions 2 and 8 state the contract: *"Every refusal is typed, `ExitClass.repositoryError`
(6)"*, and `MissingObject` is `Encodable` for the wire. **Neither is asserted anywhere.**

Review mutated the conformance —

```swift
extension JournalRestore.Error: ExitClassCarrying {
    var exitClass: ExitClass { .signingFailed }   // was .repositoryError
}
```

— changing the code an agent receives from **6 to 9**, and ran the full suite: `Test run with 704
tests in 50 suites passed`. Nothing caught it.

## Why this matters more than a missing assertion usually does

The CLI's exit codes are the agent-facing contract (guide §6, and `CLAUDE.md`: *"Exit codes are
meaningful"*). An agent that gets 9 instead of 6 for a refused restore concludes signing failed and
takes an unrelated recovery path.

It also **breaks with local convention**, which is what makes it an oversight rather than a
decision: `CrossToolGuardTests`, `WorktreeDisturbanceTests` and `JournalLockTests` all assert
`exitClass` for their own error types, and `YardWireTests/ExitClassWireTests.swift` asserts it for
the wire payloads. `JournalRestore.Error` is the only refusal type in this family without one.

## What this issue must deliver

- **One `#expect(err.exitClass == .repositoryError)` per refusal case** of `JournalRestore.Error` —
  not one case sampled. The mutation above must go red.
- **A `MissingObject` encode assertion** pinning its literal JSON bytes, per decision 8. Golden
  bytes, not a round trip: `parse(serialize(x)) == x` passes when both directions are wrong the
  same way, and a bare `Codable` on a payload-free enum silently encodes `{"case":{}}` (SE-0295).
  #0155 demonstrated both hazards on a real wire format.
- **A test for the pruned-cursor degradation clause** — decision 1's last sentence,
  `entries.contains(where: { $0.id == cursor })`. It has no test and no mutation row, and it is the
  path taken when pruning has removed the entry the cursor names.

Expected: **+1 to +3 tests**. Add a mutation row per assertion, each observed red.

## Notes

This is the fourth issue where the code was right and the evidence was missing — after #0176,

## Given — read from the merged code, 2026-08-08

1. `JournalRestore.MissingObject` is `Sendable, Equatable` at its declaration and gains `Encodable`
   through an **extension** at `JournalRestore.swift:400`, carrying a `CodingKeys` enum with
   `case ref, oid` and no custom `encode(to:)`. The conformance is therefore **synthesised**, and
   its own doc comment says byte pinning "lands with the undo envelope (M3)" — this issue brings
   that forward, because a synthesised conformance is exactly what silently changes shape when a
   member is renamed or reordered.
2. The pruned-cursor clause is `JournalRestore.swift:268`,
   `entries.contains(where: { $0.id == cursor })`, guarding the guard: when the cursor names an
   entry that pruning has removed, the cross-tool comparison is **skipped** rather than run against
   a snapshot that cannot be fetched. No test covers it and no mutation row targets it.

## Change 1 — `YardKit/Tests/YardWireTests/…`, a golden-bytes test for MissingObject

Add to the wire target, beside the other wire pinning. `MissingObject` is `public`, so no
`@testable` import is needed.

```swift
    /// #0168 decision 8: a missing object rides the structured error payload
    /// and agents branch on `ref`/`oid`, so the shape is contract. The
    /// conformance is SYNTHESISED — a renamed or reordered member changes the
    /// wire silently, and a round-trip test cannot see it because both
    /// directions move together. Golden bytes, per #0155.
    @Test func missingObjectEncodesItsPinnedBytes() throws {
        let encoder = JSONEncoder()
        encoder.outputFormatting = [.sortedKeys, .withoutEscapingSlashes]
        let bytes = try encoder.encode(JournalRestore.MissingObject(
            ref: "refs/tags/probe-tag", oid: "0123456789abcdef0123456789abcdef01234567"))
        #expect(String(decoding: bytes, as: UTF8.self) == """
            {"oid":"0123456789abcdef0123456789abcdef01234567","ref":"refs/tags/probe-tag"}
            """)
    }
```

**The round must measure the expected string rather than trusting it.** Encode the value, print the
bytes, and paste what it actually produced. If it differs from the literal above, the literal is
wrong and the issue is at fault — say so rather than editing the assertion to match a guess.

## Change 2 — `YardKit/Tests/YardGitTests/JournalRestoreTests.swift`, the pruned-cursor path

Append one test proving the guard is skipped, not merely that restore succeeds: seed a journal,
stand the cursor on an entry, **delete that entry's anchor** so the cursor names a pruned id, move a
ref underneath, and assert the restore proceeds without the guard's `repositoryChanged` refusal.

Without the clause the same fixture must fail, because `refsSnapshot(of: cursor,…)` cannot fetch a
snapshot for an anchor that no longer exists.
