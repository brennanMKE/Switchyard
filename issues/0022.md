## Description

The rest of the worktree lifecycle, including the mess agents leave behind. An agent that crashes,
or a container torn down mid-session, leaves the worktree directory gone and its administrative
entry behind.

## Expected behavior

- [ ] `wt rm` releases the lock and the agent session, and refuses when unclean without `--force`, matching git.
- [ ] `wt where` resolves worktree id, path, `$GIT_DIR`, `$GIT_COMMON_DIR`, and the main worktree path.
- [ ] `wt gc` wraps `git worktree prune` and additionally reports prunable and abandoned-session worktrees.
- [ ] `wt repair` wraps `git worktree repair` for the moved-directory case, in all three invocation positions git supports.
- [ ] `wt gc` never removes a worktree still locked by a live agent session.
