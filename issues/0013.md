# 0013 — Implement yard status

| | |
|---|---|
| **Status** | open |
| **Module** | yard / YardGit |
| **Milestone** | M1 |
| **Platform** | macOS |
| **First seen** | 2026-08-06 |

## Description

Per-file worktree state with staged and unstaged distinguished at the hunk level, so an agent can
tell what is already staged without diffing twice.

## Expected behavior

- [ ] Per-file entries distinguish staged, unstaged, untracked, ignored, and conflicted.
- [ ] Renames and copies are reported as such, with both paths.
- [ ] Submodule state is reported rather than silently flattened.
- [ ] Paths with spaces, newlines, and non-UTF-8 bytes round-trip correctly through JSON.
- [ ] Tested against both ref formats.

## Notes

Guide §6. Blocked by #0009, #0011.

Non-UTF-8 paths are not hypothetical — git permits arbitrary bytes, and the JSON encoder has to
decide on a representation rather than crash or silently lose the path.
