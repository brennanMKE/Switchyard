## Description

**Finding 1 of the M1 milestone review, eighth pass, 2026-08-18.** `listHunks` loses `--no-color`
undetected — and the result is criterion 3's forbidden shape reached through a criterion 5 gap.

`YardKit/Sources/YardGit/Hunks.swift:377`, remove `"--no-color"`: full suite green,
`Test run with 1103 tests in 78 suites passed after 78.036 seconds`.

**Measured against the engine**, in a repository with `color.ui = always` and one file with two changed
regions:

```
pristine:  PROBE-COLOR: fileDiffs=1 hunks=[2]
mutant:    PROBE-COLOR: fileDiffs=0 hunks=[]
```

git emits `^[[1mdiff --git a/f.txt b/f.txt^[[m`. `HunkParser` matches on `hasPrefix("diff --git ")`
(`Hunks.swift:163`), never opens a file block, and **returns `[]` without throwing** — so `listHunks`
tells an agent *"nothing changed"* on a dirty repository.

**`color.ui = always` is ordinary user configuration** — it is what people set to pipe git through
`less -R`. This is not an exotic state.

**My own #0289 commit message claimed this vector was "fully pinned". It was not.** #0289's own notes
named `--default-prefix`, `core.quotepath=false` and `--no-renames` as "the other four flags" — three,
not four. `--no-color` and `--unified=3` (**#0294**) were never checked by anyone.

## Expected behavior

- [ ] A named test in `YardKit/Tests/YardGitTests/HunksTests.swift`: a repository with
      `color.ui = always` configured, asserting `listHunks` returns the file's diff.
- [ ] **Verify the colour actually appears** without the flag — run `git diff` without `--no-color` in
      the fixture and show the escape sequence — otherwise a git that declines to colour a non-tty pins
      nothing. (Note `color.ui = always` rather than `auto` is exactly what forces it for a pipe.)
- [ ] **Mutation:** drop `--no-color`. The new test must redden — and it reddens by returning **`[]`**,
      not by throwing, which is the part worth asserting explicitly.
- [ ] `cd YardKit && swift test` **twice, in the foreground with an explicit 900000 ms timeout**, both
      green, above the count in `docs/test-baseline.txt`.
