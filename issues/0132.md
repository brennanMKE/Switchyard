## Description

Apply #0129's settled wire pattern (Decisions 1–8) to the diff and blame payloads:

| type | source file |
|---|---|
| `FileDiff`, `Hunk` | `YardKit/Sources/YardGit/Hunks.swift` |
| `BlameLine` | `YardKit/Sources/YardGit/Blame.swift` |

All are already `Sendable`. Same-file `extension … : Encodable` with explicit no-raw-value
`CodingKeys` (#0129 Decision 3), tests in `YardKit/Tests/YardWireTests/`.

Traps:

- `Hunk.patchText` and `BlameLine.isUncommitted` are computed — not encoded (Decision 7).
  `Hunk.body` is `[String]` and an empty body encodes as `[]`, never omitted.
- `FileDiff.hunks` nests `Hunk`, so `FileDiff`'s literal test pins the nested shape too; a
  separate `Hunk`-only literal keeps a failure attributable.
- `BlameLine.oid` for uncommitted lines is the all-zeros OID constant — a fine literal fixture,
  and it keeps `isUncommitted` derivable by the reader without a wire field.

## Expected behavior (re-author to code level before dispatch, per CLAUDE.md)
