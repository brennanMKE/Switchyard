# 0051 — Implement CLIInstaller and the File menu install action

| | |

## Description

Symlink `/usr/local/bin/yard` into the bundle, driven from **File ▸ Install Command Line Tool…**.
The installer lives in the package, not the app target, because it presents no UI and returns
results the app renders — which is what makes its state machine unit-testable, and where the actual
bugs were last time.

## Expected behavior

- [ ] Symlink, not copy, so the link tracks the bundle.
- [ ] Four states modeled, not a boolean: not installed, installed correctly, installed elsewhere, stale link.
- [ ] **Refuses to install when the app is running from a build directory** — a link into DerivedData breaks on the next clean build.
- [ ] Sweeps `~/.local/bin` for a stale link it previously created.
- [ ] Detects `PATH` shadowing by another `yard` and reports it.
- [ ] Privilege escalation for `/usr/local/bin` (root-owned) handled with a clear prompt.
- [ ] Returns reports; the app presents them. The installer presents no alerts itself.
- [ ] Uninstall action fully reverses it.
- [ ] State machine and shell quoting unit-tested in the package.

## Planning update — 2026-08-17. The state machine here; the privileged action in #0222.

Nine criteria, and they divide cleanly at the point where the code stops being pure. **This issue is
everything that can be decided without touching the filesystem as root**: the four states, the
inspection, the durability refusal, the `PATH` shadow report, the legacy sweep's *decision*, and the
`Report` values the app renders. `NSAppleScript` privilege escalation, the actual `ln -sfn`, uninstall,
and the File menu item are **#0222**.

That is not an arbitrary cut. RemoteControl's own doc says the installer exists in the package
"because the state machine is where the bugs are", and a state machine is testable exactly to the
extent it is not doing privileged I/O.

### `YardKit/Sources/YardKit/CLIInstaller.swift`

Port from `../../RemoteControl/BridgeKit/Sources/BridgeKit/CLIInstaller.swift` — **MIT, same author,
retain the copyright notice**, as `XPCProtocols.swift:1-7` already does. Substitutions: `remotectl` →
`switchyard`, `ServiceNames.cliBundlePath` → **`ServiceNames.cliBundleRelativePath`** (this project's
spelling, value `"Resources/bin/switchyard"`), and the legacy sweep path becomes
`~/.local/bin/switchyard`.

The pieces to take, and why each one earns its place:

```swift
public enum State: Equatable, Sendable {
    case notInstalled
    case installedHere                       // the link points into THIS bundle
    case installedElsewhere(String)          // a link, but to somewhere else
    case blockedByFile                       // something that is not a symlink is in the way
}
```

- **`inspect(_ path: URL, expecting target: URL) -> State`** — `static`, pure over the filesystem it is
  handed, which is what lets a test point it at a staged temp directory. `blockedByFile` exists because
  a regular file at the destination otherwise reads as "nothing installed" while a broken command sits
  on `PATH`.
- **`isBundleDurable`** — false when the bundle path contains `/DerivedData/` or `/Build/Products/`.
  This is criterion 3 and the reason it matters is stated in the source: launching from Xcode runs the
  DerivedData copy, and a link into it breaks on the next clean build, surfacing much later as
  `switchyard: command not found`. **Installing must refuse, not warn.**
- **`requiresAuthentication`** — `!FileManager.default.isWritableFile(atPath:)` on the destination
  directory. Reported here; acted on in #0222.
- **`shellQuoted(_:)`** — single-quote wrapping so a path containing a space or a quote cannot break
  out of the generated command. Bring it now, `nonisolated static`, **with its tests**, even though the
  command that uses it lands in #0222. It is the one piece of #0222 that is pure, and it is the piece
  where a bug is a shell injection rather than a wrong dialog.
- **`Report`** with `severity`, `title`, `detail`. The installer **presents nothing**; it returns
  values and the app renders them (criterion 7).

### `PATH` shadowing (criterion 5) and the legacy sweep (criterion 4)

Both are *reports* in this issue, not actions.

- **Shadowing:** split `PATH`, look for an executable named `switchyard` in an entry that comes
  **before** the destination directory, and report it. RemoteControl's own note records why this is
  not hypothetical: `~/.local/bin` sits earlier on that machine's `PATH` than `/usr/local/bin`, so a
  leftover link there silently shadows a correct install.
- **Legacy sweep:** report that `~/.local/bin/switchyard` exists and points into a Switchyard bundle.
  Removing it is #0222's, in the same privileged step that writes the new link — and it must happen
  **first**, since it is the one earlier on `PATH`.

Take `PATH` from an injected value defaulting to `ProcessInfo.processInfo.environment["PATH"]`, or the
tests cannot cover it without mutating the process environment.

### Tests — `YardKit/Tests/YardKitTests/CLIInstallerTests.swift`

Everything below runs against a **staged temp directory**, never `/usr/local/bin`, and never as root.
`../../RemoteControl/BridgeKit/Tests/BridgeKitTests/CLIInstallerTests.swift` is the model.

- Each of the four states, constructed on disk: no file; a symlink to the staged bundle's CLI; a
  symlink to some other path; a regular file.
- `isBundleDurable` false for a path containing `/DerivedData/`, false for `/Build/Products/`, true for
  `/Applications/Switchyard.app`.
- `shellQuoted` for a path with a space, a path with a single quote, and an ordinary path. **Assert the
  exact output string**, not that it "contains" the path — a quoting test that checks containment
  passes for the unquoted input.
- Shadowing detected when an earlier `PATH` entry holds an executable of that name; **not** reported
  when the only match is the destination itself.
- The legacy path reported when present, silent when absent.
