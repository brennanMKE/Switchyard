## Description

**Finding of the M1 milestone review's second pass, 2026-08-17.** `whereAmI`'s **upstream / ahead /
behind** block — `YardKit/Sources/YardGit/WhereAmI.swift:173-199`, the
`if branchName != nil { … rev-parse --abbrev-ref @{upstream} … rev-list --left-right --count
HEAD...@{upstream} … }` — **has no test that can fail.**

Measured: replacing `if branchName != nil {` with `if false {`, so all three fields are permanently
`nil`, leaves the **full** suite green — `Test run with 1040 tests in 78 suites passed`. A weaker
mutation, transposing `ahead` and `behind`, also survives.

By inspection: `grep -rn "ahead" Tests/` finds three test-side sites. `WhereAmITests.swift:21` asserts
`ahead == nil` in an **empty** repository; the three `WhereAmIWireTests` sites construct a `WhereAmI`
value literally and never call the function. **No fixture in the suite ever gives a branch an
upstream.**

And `WhereAmITests.branchWithoutUpstreamShowsNilAheadBehind` is *named* for this behaviour while its
body contains **no `#expect` for `ahead` or `behind` at all** — only `#expect(r.branch == "main")`,
followed by a comment saying they stay nil. That is the assert-nothing shape `AGENTS.md` Rule 7 exists
for.

**Sharper than #0245's case**, because since #0194 all three fields are **published** in
`YardKit/Schemas/whereami.json` with absence semantics an agent will rely on — *"Absent when there is
no upstream to compare against"* — and nothing verifies the function ever produces them.

## Expected behavior

- [ ] A fixture with a **real upstream**. `FixtureRepository` has `linear`/`merged`/`octopus`/
      `conflicted*` presets and **no remote or upstream helper today**, so this needs one — a local
      bare repo added as `origin` and a branch with its tracking ref set is the usual shape. Put it on
      `FixtureRepository` so the next command that needs an upstream inherits it.
- [ ] Assertions that are **asymmetric**: `upstream == "origin/main"`, and `ahead != behind` so a
      transposition dies. Equal values would pass under the mutation that swaps them.
- [ ] `branchWithoutUpstreamShowsNilAheadBehind` gains the `#expect`s its name promises — it currently
      asserts only the branch name.
- [ ] Mutations, each run and reported: `if branchName != nil` → `if false`, and transposing `ahead`
      and `behind`. Both must redden a named test.
- [ ] `cd YardKit && swift test` **twice, in the foreground**, both green, **N greater than 1040**.

## The files

`YardKit/Tests/YardGitTests/WhereAmITests.swift`, and `YardKit/Sources/YardGit/FixtureRepository.swift`
for the upstream helper. **`WhereAmI.swift` is read-only here** — the production code appears correct;
this is a test gap, exactly as #0245 was.
