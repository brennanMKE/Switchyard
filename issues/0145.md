| # | mutation | verdict | named test(s) that died |
|---|---|---|---|
| Y1 | report `ctx.commonDir` as `gitDir` | **RED** | `linkedWorktreeSplitsGitDirFromCommonDir`; `linkedWorktreeSplitsGitDirFromCommonDirAcrossRefFormats`; `linkedGitDirDiffersFromCommonInRefFormats` |

This is the mutation that matters for this function. `$GIT_DIR` and `$GIT_COMMON_DIR` are **equal in
the main worktree and different in a linked one**, so collapsing them is invisible everywhere except a
linked worktree — which is exactly where every path-resolution bug in this project lives. All three
killing tests exercise a linked worktree, and two of them across both ref formats.

`CLAUDE.md` is explicit that `HEAD` lives in `$GIT_DIR` while `refs/heads/*` lives in
`$GIT_COMMON_DIR`, so a function that conflated them would resolve refs correctly in the main worktree
and wrongly everywhere else. The distinction is now pinned by a named test rather than by a comment.
