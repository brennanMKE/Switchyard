## Description

**M1 exit criterion served (guide §9, criterion 5):** "every engine function has tests that can
fail: each has a mutation recorded against a named test that dies under it."

Found by the M1 milestone review, 2026-08-07. `yardWhere`
(`YardKit/Sources/YardGit/WorktreeWhere.swift`) has a recorded, executed mutation (#0094: replacing
the porcelain lookup with `ctx.topLevel` "fails four tests across both ref formats") — but the four
tests are not named. #0109's table names tests for the same class of mutation, but those
(`siblingHoldsBranch`, `mainWorktreeReportedFromLinked`) target `siblingWorktree` in
`SiblingWorktree.swift`, a different function; #0130's row for `WorktreeWhere` is a
compile-failure mutation, not a red test.

## Expected behavior

The #0094 mutation is re-applied, the four test names in
`YardKit/Tests/YardGitTests/WorktreeWhereTests.swift` that go red are recorded in this issue's
work log, and the mutation is reverted with the suite green.
