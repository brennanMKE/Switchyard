## Description

**Child of #0358, split 2026-09-12.** One deliverable: the header shows the tracking status ("On
branch main · 12 ahead of origin/main") and, when one is under way, the git operation in progress.
Moved verbatim from #0358's first planning update (*compiled* at `2d96d3e`,
`Test run with 7 tests in 2 suites passed`).

### `YardKit/Sources/YardUI/TrackingSummary.swift` (new)

*Measured* from source: `RepositoryHeaderView` renders `upstream` but never `ahead`/`behind`, though
`WhereAmI` carries both (`ahead: Int?`, `behind: Int?`, nil without an upstream). Batty's
`git status -sb` reads `## main...origin/main [ahead 12]`.

```swift
// TrackingSummary.swift
//
// #0358: the one-line tracking status the header shows, built from
// `WhereAmI` alone so it is testable without a repository.

import YardGit

public nonisolated enum TrackingSummary {
    public static func text(for state: WhereAmI) -> String {
        guard let branch = state.branch else {
            return state.headOID.isEmpty ? "No commits yet" : "Detached HEAD at \(state.headOID)"
        }
        guard let upstream = state.upstream else {
            return "On branch \(branch) · no upstream"
        }
        let ahead = state.ahead ?? 0
        let behind = state.behind ?? 0
        switch (ahead, behind) {
        case (0, 0): return "On branch \(branch) · up to date with \(upstream)"
        case (_, 0): return "On branch \(branch) · \(ahead) ahead of \(upstream)"
        case (0, _): return "On branch \(branch) · \(behind) behind \(upstream)"
        default: return "On branch \(branch) · \(ahead) ahead, \(behind) behind \(upstream)"
        }
    }

    /// The in-progress git operation that blocks history changes, or `nil`.
    public static func operationInProgress(for state: WhereAmI) -> String? {
        if state.isMidRebase { return "A rebase is in progress" }
        if state.isMidMerge { return "A merge is in progress" }
        if state.isMidCherryPick { return "A cherry-pick is in progress" }
        if state.hasConflicts { return "There are unresolved conflicts" }
        return nil
    }
}
```

In `RepositoryHeaderView`, replace the branch/oid/upstream line with
`Text(TrackingSummary.text(for: whereAmI)).font(.headline)`, keep the short oid in monospaced
secondary beside it, and
when `operationInProgress(for:)` is non-nil show it as
`Label(message, systemImage: "exclamationmark.triangle.fill").foregroundStyle(.orange)`. #0359's
menu disables every rewrite with that same sentence, so the header explains the disabled menu.
*Measured* strings: `ahead: 12` → `"On branch main · 12 ahead of origin/main"`; detached with
`headOID` `abcdef0` → `"Detached HEAD at abcdef0"`.
Once #0376 lands, `operationInProgress(for:)` gains
`if state.isMidRevert { return "A revert is in progress" }` after the cherry-pick line. It cannot be
added before, because the field does not exist yet.
