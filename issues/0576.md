## Description

`commitDiff` runs `git diff-tree --root -p --cc --no-commit-id …`. For a clean merge, `--cc` (the
combined diff) is **empty**, because each file the merge brought in matches one of its parents. So
the app cannot show what a merge brought in (#0575). This issue adds a parameter that selects the
first-parent diff instead. The default stays `--cc`, so every existing caller is unchanged: the
synchronous `commitDiff` that `Split` uses, `ReviewRequestServing`, and every pinned `HunksTests`
case. #0577 is the one caller that opts in.

**Measured, git 2.54.0 (Apple Git-157), 2026-10-05.** The repository: `main` has `base`
(README.md). `docs2` branches from it and adds `docs.md`. In the diverged shape, `main` also adds
`main.txt`. Then `git merge --no-ff --no-edit docs2` runs on `main`.

| command on the merge commit | ff shape | diverged shape |
|---|---|---|
| `diff-tree --root -p --cc --no-commit-id HEAD` | 0 bytes | 0 bytes |
| `diff-tree --root -p --diff-merges=first-parent --no-commit-id HEAD` | `docs.md` only (`new file mode 100644`, `+docs`) | `docs.md` only |
| `diff-tree --root -p -m --first-parent --no-commit-id HEAD` | `docs.md` | **`docs.md` and `main.txt`** — `--first-parent` is a revision-walk option that `diff-tree` ignores, so this is plain `-m` (one diff per parent). Do not use it. |

For the **root** commit and an **ordinary** commit, `--cc` and `--diff-merges=first-parent`
produce byte-identical output (measured with `cmp` on both). So `.firstParent` is safe to pass for
any revision.

## The change — one file, `YardKit/Sources/YardGit/Hunks.swift`

### 1. The async `commitDiff` gains `merges:`

Today (around line 680):

```swift
public func commitDiff(
    at path: String,
    revision: String,
    options: DiffOptions = .standard,
    git: GitProcess = GitProcess()
) async throws -> [FileDiff] {
    let output = try await git.run(
        commitDiffArguments(revision: revision, options: options), workingDirectory: path)
    return try HunkParser().parse(output.text)
}
```

Becomes:

```swift
public func commitDiff(
    at path: String,
    revision: String,
    options: DiffOptions = .standard,
    merges: MergeDiffBase = .combined,
    git: GitProcess = GitProcess()
) async throws -> [FileDiff] {
    let output = try await git.run(
        commitDiffArguments(revision: revision, options: options, merges: merges),
        workingDirectory: path)
    return try HunkParser().parse(output.text)
}
```

Add one line to that function's doc comment: `/// #0576: `merges` picks a merge commit's diff — see `MergeDiffBase`.`
**Do not change the synchronous `commitDiff(at:revision:git:)`.** `Split` uses it, and merges
cannot be split.

### 2. `commitDiffArguments` takes it

Today (around line 694):

Becomes (the rest of the function is unchanged):

```swift
    arguments += ["diff-tree", "--root", "-p", merges.flag, "--no-commit-id"]
```

### 3. The new type — directly above `// MARK: - Stash diff (#0493)`

```swift
/// Which diff `commitDiff` draws for a merge commit (#0576). A root or
/// ordinary commit diffs identically under both (measured, git 2.54.0:
/// byte-identical `diff-tree` output for each).
public enum MergeDiffBase: Sendable, Equatable {
    /// `--cc`, the combined diff: only what differs from every parent —
    /// empty for a clean merge, whatever it brought in.
    case combined
    /// `--diff-merges=first-parent`: everything the merge brought into the
    /// branch it was made on — the merged branch's files for a clean merge.
    /// Not `-m --first-parent`: `diff-tree` ignores `--first-parent`, which
    /// leaves plain `-m`, one diff per parent (measured).
    case firstParent

    var flag: String {
        switch self {
        case .combined: "--cc"
        case .firstParent: "--diff-merges=first-parent"
        }
    }
}
```

Leave the long `--cc` doc comment above `commitDiff` (sync) as it is. It is still true of the
default.

## Verification — append to `YardKit/Tests/YardGitTests/HunksTests.swift`

That file already does `@testable import YardGit` and `import Testing`. These three test names

```swift

// MARK: - #0576: a merge commit's first-parent diff

/// `main` ← a; `docs2` ← a + d (adds docs.md); when `diverged`, `main` ← m
/// (adds main.txt); then `git merge --no-ff docs2` on `main` — the shape
/// Brennan's 2026-10-05 report merged from the app. Returns the merge's oid.
private func mergedDocs2(_ repo: inout FixtureRepository, diverged: Bool) throws -> String {
    try repo.build([.init("a", files: ["README.md": "readme\n"])])
    try repo.branch("docs2")
    try repo.checkout("docs2")
    try repo.build([.init("d", files: ["docs.md": "docs\n"])])
    try repo.checkout("main")
    if diverged { try repo.build([.init("m", files: ["main.txt": "main\n"])]) }
    try GitProcess().run(
        ["merge", "-q", "--no-ff", "--no-edit", "docs2"], workingDirectory: repo.url.path)
    return try repo.revParse("HEAD")
}

@Test(arguments: [false, true])
func firstParentDiffOfACleanMergeListsWhatTheMergeBroughtIn(diverged: Bool) async throws {
    var repo = try FixtureRepository()
    defer { repo.destroy() }
    let merge = try mergedDocs2(&repo, diverged: diverged)

    let files = try await commitDiff(at: repo.url.path, revision: merge, merges: .firstParent)

    #expect(files.map(\.path) == ["docs.md"])
    #expect(files.first?.hunks.map(\.body) == [["+docs"]])
}

@Test func combinedDiffOfTheSameCleanMergeStaysEmpty() async throws {
    var repo = try FixtureRepository()
    defer { repo.destroy() }
    let merge = try mergedDocs2(&repo, diverged: true)

    let files = try await commitDiff(at: repo.url.path, revision: merge)

    #expect(files.isEmpty)
}

@Test func firstParentDiffOfAnOrdinaryCommitMatchesTheCombinedOne() async throws {
    var repo = try FixtureRepository()
    defer { repo.destroy() }
    _ = try mergedDocs2(&repo, diverged: true)
    let d = try #require(repo.oids["d"])
    let root = try #require(repo.oids["a"])

    for revision in [d, root] {
        let combined = try await commitDiff(at: repo.url.path, revision: revision)
        let firstParent = try await commitDiff(
            at: repo.url.path, revision: revision, merges: .firstParent)
        #expect(!combined.isEmpty)
        #expect(firstParent == combined)
    }
}
```

   `-m --first-parent` trap from the table above.

  merge brought into its first parent's branch. Its default, `.combined`, is unchanged.
