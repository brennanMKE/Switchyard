## Description

Apply #0129's settled wire pattern (Decisions 1–8) to the maintenance and template results:

| type | source file | traps |
|---|---|---|
| `WorktreePrune.Report` (+ nested `Reportable`) | `YardKit/Sources/YardGit/WorktreePrune.swift` | `Reportable` is String-raw and encodes as its raw value (Decision 5); `Report.description` is computed, not encoded |
| `WorktreeRepair.Repaired` | `YardKit/Sources/YardGit/WorktreeRepair.swift` | two String members, the simplest type in the family |
| `WorktreeTemplate.Report` (+ nested `Outcome`) | `YardKit/Sources/YardGit/WorktreeTemplate.swift` | `Entry` is already `Codable` with synthesized keys — decide at planning time whether to leave it synthesized or pin it with an explicit `CodingKeys`, and state why; `Outcome` has associated values (`missingSource`, `destinationExists`, `commandFailed(exitCode:stderr:)`, `failed`) and encodes as an object with a stable `code` string plus detail fields (Decision 5); `succeeded` is computed, not encoded (Decision 7) |

## Expected behavior (re-author to code level before dispatch, per CLAUDE.md)

- [ ] All listed types gain `Encodable`; structs use explicit `CodingKeys` enums, `Outcome` an
      explicit `encode(to:)` per Decision 5; nil optionals omitted, never `null`.
- [ ] Literal-JSON tests in `YardKit/Tests/YardWireTests/MaintenanceWireTests.swift`, covering
      each `Outcome` case shape and one envelope passthrough, literals pasted from a real run at
      planning time.
- [ ] `cd YardKit && swift test` prints a `Test run with N tests` line; N must exceed the
      pre-change baseline by exactly the number of new tests, both counts settled and stated at
      planning time.
