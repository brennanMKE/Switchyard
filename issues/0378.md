## Description

Brennan, 2026-09-12, filed from the M7 planning questions. One deliverable: a filter field at the top
of the sidebar narrows the Branches, Remotes and Tags lists as the user types. Switchyard has 309
local and 294 remote-tracking refs (*measured*), and scrolling is not a way to find one.

### Interaction

- A native search field: `.searchable(text: $refFilter, placement: .sidebar, prompt: "Filter")` on the
  sidebar `List` in `YardKit/Sources/YardUI/RepositorySidebarView.swift` (*compiled* at `61c94aa`, in a
  scratch view).
- **Match rule**: case- and diacritic-insensitive substring on the short ref name (below).
- **Scope**: Branches, Remotes and Tags. While the query is non-empty, Worktrees, Rerere and Stashes
  are hidden, so the list shows only results.
- **Collapsed sections** (#0371) show their matches while filtering, without changing the stored
  expansion, so clearing the field restores the user's layout.
- **No matches**: `ContentUnavailableView.search(text: refFilter)` in place of the list (*not compiled*).
- **Clearing**: the field's own clear button, and Esc. *Unverified* for the sidebar placement on
  macOS 26 — reviewer checks.
- The current branch stays first among the matches (#0371's sort).

### `RefFilter` (*compiled* and tested at `61c94aa`)

```swift
// YardKit/Sources/YardUI/RefFilter.swift (new)

import Foundation

/// #0378: the sidebar filter's match rule.
public nonisolated enum RefFilter {
    /// Case- and diacritic-insensitive substring match on the short ref
    /// name. An empty or all-whitespace query matches everything.
    public static func matches(_ name: String, query: String) -> Bool {
        let trimmed = query.trimmingCharacters(in: .whitespaces)
        return trimmed.isEmpty
            || name.range(of: trimmed, options: [.caseInsensitive, .diacriticInsensitive]) != nil
    }
}
```

*Measured* passing: `""` and `"  "` match `issue/0404`; `"issue/04"` matches `Issue/0404`; `"naive"`
matches `naïve`; `"feat"` does not match `main`.
