## Description

Apply #0129's settled wire pattern (its Decisions 1–8, binding here) to the status and conflicts
payloads:

| type | source file |
|---|---|
| `WorktreeStatus`, `WorktreeStatusEntry` (+ nested `State`, `SubmoduleState`) | `YardKit/Sources/YardGit/WorktreeStatus.swift` |
| `ConflictedFile` (+ nested `StageEntry`, `Kind`) | `YardKit/Sources/YardGit/Conflicts.swift` |

**One deliverable:** the status and conflicts payloads encode to the v1 envelope, byte-pinned —
one wire-encoding section appended to each of the two source files, plus one new test file
`YardKit/Tests/YardWireTests/StatusConflictsWireTests.swift`. **All three changes are written out
below in full and were compiled, run, and mutation-tested in a copy of this package on
2026-08-07** — the suite went from 453 to `Test run with 460 tests` (+7 exactly), every mutation
row observed (three as red tests, one as a compile failure, one as red tests on the wrapper
shape), then reverted. The round's work is transcription plus running the verification.

**This is where #0129 Decision 6 (`pathBytes` stays off the wire) gets its first real subject
matter.** `WorktreeStatusEntry` carries `pathBytes: [UInt8]` and `originalPathBytes: [UInt8]?`;
`ConflictedFile` carries `pathBytes: [UInt8]`. The `CodingKeys` enums below deliberately omit
those members, and — measured, Given 9 — **deleting a `CodingKeys` enum here is observable**,
unlike in #0129/#0130: synthesis without the enum encodes `pathBytes` as a JSON array of integers
(`"pathBytes":[99,97,102,233,…]`). The enum is the mechanism that enforces Decision 6, not just
rename-safety.

**No `Package.swift` change.** The `Tests/YardWireTests` target and its `wireJSON` helper already
exist — #0129 creates both, which is why this issue is **blocked by #0129 and must not be
dispatched before #0129 is squash-merged to `main`**. Reuse `wireJSON`; do not redeclare it
(a second declaration in the same target is a compile error).

**Blocked by:** #0129.

## Givens — each measured on this machine, 2026-08-07

1. **The status types are NOT `Sendable` on `main`, and the bound fails without it.** Measured:
   with `Encodable` alone, the test target fails to compile — `error: type 'WorktreeStatus' does
   not conform to the 'Sendable' protocol` at `EncodableResult(status)` and inside the `#expect`
   macro expansion. Public structs get no implicit `Sendable` across module boundaries, so the
   extensions in Change 1 add `Sendable` alongside `Encodable` for `WorktreeStatusEntry`, its
   nested `State`, and `WorktreeStatus` (nested `SubmoduleState` is already
   `Equatable, Sendable`). A same-file extension may declare `Sendable`; these are same-file.
   The `ConflictedFile` family is already `Sendable` throughout — Change 2 adds `Encodable` only.
2. **`WorktreeStatusEntry.State` and `ConflictedFile.Kind` are String-raw enums**, verified by
   reading the declarations: `public enum State: String, CaseIterable` with raw values `"."`,
   `"A"`, `"D"`, `"M"`, `"?"`, `"!"`, `"u"`; `public enum Kind: String, Sendable, CaseIterable`
   with raw values `"UU"`, `"AA"`, `"DD"`, `"AU"`, `"UA"`, `"DU"`, `"UD"`. #0129 Decision 5's
   first clause applies: each encodes as its raw value, a single JSON string. A bare
   `extension …: Encodable {}` is sufficient — the stdlib's `RawRepresentable` default
   implementation encodes the raw value; no `CodingKeys`, no `encode(to:)`. Measured: the
   literals below came out `"staged":"M"`, `"worktree":"?"`, `"kind":"UU"` from exactly the bare
   extensions in Changes 1–2.
3. **What happens to a non-UTF-8 path, measured end to end.** APFS itself refuses to create one
   (`open(b'caf\xe9.txt')` → `OSError errno 92, Illegal byte sequence`), but git holds them fine —
   `git update-index --index-info` fed stage-2/3 entries at the raw-byte path `caf\xe9.txt`
   produced a genuinely unmerged index, and `git status --porcelain=v2 -z` then emitted the raw
   byte: `… c a f 351 . t x t \0` in `od -c` (351 octal = 0xE9). Fed through the real parser and
   encoder, the wire carries the **lossily-decoded string**: 0xE9 becomes U+FFFD REPLACEMENT
   CHARACTER, whose UTF-8 bytes `ef bf bd` appear unescaped in the JSON (measured with
   `od -tx1`: `… 63 61 66 ef bf bd 2e 74 78 74 …`). Valid JSON, decodable by any consumer;
   `pathBytes` stays the lossless in-process source of truth, off the wire per Decision 6.
4. **`\#u{FFFD}` is the escape for U+FFFD inside a raw string literal.** The test literals use
   `#"…"#` so that JSONEncoder's `\/` stays a two-character sequence; inside `#"…"#` a unicode
   escape needs the `#`: `\#u{FFFD}`. Measured: the pasted test file compiles and both non-UTF-8
   tests pass against it. Do not "fix" either escape form; the literals are pasted from a real run.
5. **`WorktreeStatus` encodes as `{"entries":[…]}`, not a bare array** — settled here, pinned by
   mutation R5. An object can gain sibling fields additively under `YardKit/Schemas/README.md`'s
   rule; a bare array cannot. `conflictedFiles(at:)` returns `[ConflictedFile]` with no wrapper
   type, so the conflicts payload rides as a JSON array in `result` (the envelope test pins that
   too).
6. **Edit hazard (the #0130 Given-7 class):** `WorktreeStatus.swift` already contains
   `extension WorktreeStatus: ExpressibleByArrayLiteral {` (line 137) and a fileprivate
   `extension Array {` (line 357). Changes 1–2 are **appended at end of file**; do not use a
   search-and-replace keyed on `extension WorktreeStatus` — it would hit the
   `ExpressibleByArrayLiteral` extension too. `Conflicts.swift` has no extensions today.
7. **No custom-`==` divergence (the #0130 Given-3 class, checked and clear).**
   `SubmoduleState`'s hand-written `==` compares exactly the three stored Bools its `CodingKeys`
   encode; `WorktreeStatusEntry` has no `Equatable` at all; `ConflictedFile`'s is synthesized.
   Nothing here encodes a field that equality skips.
8. **Baseline.** `docs/test-baseline.txt` read **450** as this planning pass finished. On a
   scratch tree of `main` + #0129's three changes the suite measured **453**; after this change,
   **`Test run with 460 tests in 24 suites`** — the delta is **+7**. Trust the delta, not the
   absolute.
9. **Deleting the `CodingKeys` enum is OBSERVABLE for the byte-carrying types** — the opposite of
   #0129/#0130, where synthesized keys were byte-identical and the row was omitted as
   unobservable. Measured as mutation R1: with `WorktreeStatusEntry`'s enum deleted, five tests
   go red and the failure output shows `"pathBytes":[110,111,116,101,115,…]` riding the wire.
   For `WorktreeStatus`, `SubmoduleState`, and `StageEntry` deletion remains unobservable (their
   member names match the keys byte-for-byte), so their enums are pinned by the presence grep
   instead.

## Change 1 — `YardKit/Sources/YardGit/WorktreeStatus.swift`, append at end of file

Appended after everything, including the existing `extension WorktreeStatus:
ExpressibleByArrayLiteral` and the fileprivate `extension Array` — see Given 6.

```swift
// MARK: - Wire encoding (#0131)

/// `WorktreeStatusEntry` is a `schemaVersion: 1` payload component: it encodes
/// through `YardKit`'s `Envelope` via `EncodableResult` (`Encodable &
/// Sendable`). Plain-stdlib `Encodable` — the engine still imports nothing.
/// `Sendable` is added here too: public structs get no implicit `Sendable`
/// across module boundaries, and `EncodableResult`'s bound needs it.
extension WorktreeStatusEntry: Encodable, Sendable {
    /// The stable wire keys. Identical to the member names on purpose; no raw
    /// values — the case name IS the wire key, and `StatusConflictsWireTests`
    /// pins the encoded bytes. `pathBytes` and `originalPathBytes` are
    /// deliberately absent (#0129 Decision 6): a JSON string must be valid
    /// UTF-8, so the wire carries the lossily-decoded `path` /
    /// `originalPath`; raw bytes never ride the wire.
    private enum CodingKeys: String, CodingKey {
        case path, staged, worktree, originalPath, submodule
    }
}

/// String-raw enum: encodes as its raw value, a single JSON string — the
/// porcelain character itself (#0129 Decision 5).
extension WorktreeStatusEntry.State: Encodable, Sendable {}

extension WorktreeStatusEntry.SubmoduleState: Encodable {
    /// Stable wire keys, identical to the member names; no raw values.
    private enum CodingKeys: String, CodingKey {
        case commitChanged, hasModifications, hasUntracked
    }
}

/// `WorktreeStatus` is the whole-status payload: an object with one `entries`
/// key, not a bare array — an object can gain sibling fields additively under
/// `YardKit/Schemas/README.md`'s rule; a bare array cannot.
extension WorktreeStatus: Encodable, Sendable {
    /// Stable wire keys, identical to the member names; no raw values.
    private enum CodingKeys: String, CodingKey {
        case entries
    }
}
```

Do not write an `encode(to:)` method anywhere — synthesis handles it, and synthesis is what makes
nil optionals omitted (#0129 Decision 4). The same applies to Change 2.

## Change 3 — `YardKit/Tests/YardWireTests/StatusConflictsWireTests.swift`, new file, in full

```swift
// StatusConflictsWireTests.swift — status and conflicts payloads encode to the
// schemaVersion 1 envelope (#0131): WorktreeStatus, WorktreeStatusEntry, ConflictedFile.

import Foundation
import Testing
import YardGit
import YardKit

@Suite("Status and conflicts wire shapes")
struct StatusConflictsWireTests {

    // MARK: - WorktreeStatusEntry

    /// A staged rename with a dirty submodule, every wire field populated. The
    /// literal proves `pathBytes` / `originalPathBytes` never appear (#0129
    /// Decision 6) and that the two `State` fields encode as their porcelain
    /// raw characters (#0129 Decision 5).
    @Test func worktreeStatusEntryFullValueEncodesToTheLiteralWireShape() throws {
        var value = WorktreeStatusEntry(
            path: "docs/renamed.md",
            pathBytes: Array("docs/renamed.md".utf8),
            originalPath: "docs/original.md",
            originalPathBytes: Array("docs/original.md".utf8))
        value.staged = .modified
        value.worktree = .unmodified
        value.submodule = try #require(
            WorktreeStatusEntry.SubmoduleState(subToken: "SCMU"))
        #expect(try wireJSON(value) == #"{"originalPath":"docs\/original.md","path":"docs\/renamed.md","staged":"M","submodule":{"commitChanged":true,"hasModifications":true,"hasUntracked":true},"worktree":"."}"#)
    }

    /// An untracked file: `originalPath` and `submodule` are nil and OMITTED
    /// from the wire, not encoded as null — and the raw-bytes fields are
    /// absent by name, pinning Decision 6 as a key-level fact.
    @Test func worktreeStatusEntryNilOptionalsAreOmittedFromTheWire() throws {
        var value = WorktreeStatusEntry(path: "notes.txt")
        value.staged = .unmodified
        value.worktree = .untracked
        let json = try wireJSON(value)
        #expect(json == #"{"path":"notes.txt","staged":".","worktree":"?"}"#)
        #expect(!json.contains("\"originalPath\""))
        #expect(!json.contains("pathBytes"))
        #expect(!json.contains("null"))
    }

    /// A path that is not valid UTF-8 — git can commit one on other
    /// filesystems even though APFS refuses to create one. The wire carries
    /// the lossily-decoded `path` string: the invalid byte 0xE9 becomes
    /// U+FFFD REPLACEMENT CHARACTER, which is valid UTF-8 and therefore a
    /// legal JSON string. The raw bytes stay off the wire (#0129 Decision 6);
    /// `pathBytes` remains the lossless in-process source of truth.
    @Test func nonUTF8PathRidesTheWireAsTheLossyDecodedString() throws {
        let rawPath: [UInt8] = Array("caf".utf8) + [0xE9] + Array(".txt".utf8)
        let value = WorktreeStatusEntry(
            path: String(decoding: rawPath, as: UTF8.self),
            pathBytes: rawPath)
        let json = try wireJSON(value)
        #expect(json == #"{"path":"caf\#u{FFFD}.txt","staged":".","worktree":"."}"#)
        #expect(!json.contains("pathBytes"))
    }

    /// The whole-status payload is an object with one `entries` key — an
    /// object can gain sibling fields additively under the schema rule; a
    /// bare array cannot.
    @Test func worktreeStatusEncodesAsAnEntriesObject() throws {
        var entry = WorktreeStatusEntry(path: "a.txt")
        entry.worktree = .modified
        let value = WorktreeStatus(entries: [entry])
        #expect(try wireJSON(value) == #"{"entries":[{"path":"a.txt","staged":".","worktree":"M"}]}"#)
    }

    // MARK: - ConflictedFile

    /// A both-modified conflict with all three stages, every field populated.
    /// `kind` encodes as the porcelain XY raw value (#0129 Decision 5), each
    /// stage as an `{mode, oid}` object, and `pathBytes` never appears.
    @Test func conflictedFileFullValueEncodesToTheLiteralWireShape() throws {
        let value = ConflictedFile(
            path: "file.txt",
            pathBytes: Array("file.txt".utf8),
            kind: .bothModified,
            base: ConflictedFile.StageEntry(
                oid: "df967b96a579e45a18b8251732d16804b2e56a55", mode: "100644"),
            ours: ConflictedFile.StageEntry(
                oid: "ba2906d0666cf726c7eaadd2cd3db615dedfdf3a", mode: "100644"),
            theirs: ConflictedFile.StageEntry(
                oid: "2299c37978265a95cbe835a4b0f0bbf15aad5549", mode: "100644"))
        #expect(try wireJSON(value) == #"{"base":{"mode":"100644","oid":"df967b96a579e45a18b8251732d16804b2e56a55"},"kind":"UU","ours":{"mode":"100644","oid":"ba2906d0666cf726c7eaadd2cd3db615dedfdf3a"},"path":"file.txt","theirs":{"mode":"100644","oid":"2299c37978265a95cbe835a4b0f0bbf15aad5549"}}"#)
    }

    /// Real bytes, end to end: the `u` record `git status --porcelain=v2 -z`
    /// emitted for an add/add conflict at a NON-UTF-8 path (created via
    /// `git update-index --index-info`; measured 2026-08-07) parses through
    /// `ConflictParser` and encodes with the nil `base` omitted, the lossy
    /// path, and no raw-bytes key. This is the parser+encoder conjunction —
    /// each half passing alone would not prove the wire.
    @Test func conflictParserOutputForANonUTF8ConflictEncodesLossily() throws {
        let record = "u AA N... 000000 100644 100644 000000 "
            + "0000000000000000000000000000000000000000 "
            + "587be6b4c3f93f93c489c0111bba5596147a26cb "
            + "975fbec8256d3e8a3797e7a3611380f27c49f4ac caf"
        let bytes = Array(record.utf8) + [0xE9] + Array(".txt".utf8) + [0x00]
        let files = try ConflictParser().parse(Data(bytes))
        let file = try #require(files.first)
        #expect(files.count == 1)
        #expect(file.pathBytes.contains(0xE9))
        let json = try wireJSON(file)
        #expect(json == #"{"kind":"AA","ours":{"mode":"100644","oid":"587be6b4c3f93f93c489c0111bba5596147a26cb"},"path":"caf\#u{FFFD}.txt","theirs":{"mode":"100644","oid":"975fbec8256d3e8a3797e7a3611380f27c49f4ac"}}"#)
        #expect(!json.contains("\"base\""))
        #expect(!json.contains("null"))
        #expect(!json.contains("pathBytes"))
    }

    // MARK: - Envelope passthrough

    /// The M1 exit-criterion sentence for both payloads: each wraps in the
    /// real `Envelope` through `EncodableResult` — the compile itself proves
    /// the `Encodable & Sendable` bound — and each full response is
    /// byte-pinned with the v1 frame keys. The conflicts payload is a JSON
    /// array in `result`, matching `conflictedFiles(at:)`'s `[ConflictedFile]`.
    @Test func envelopeWrapsStatusAndConflictsPayloads() throws {
        var entry = WorktreeStatusEntry(path: "a.txt")
        entry.staged = .added
        let status = WorktreeStatus(entries: [entry])
        #expect(try wireJSON(Envelope(result: EncodableResult(status))) == #"{"ok":true,"result":{"entries":[{"path":"a.txt","staged":"A","worktree":"."}]},"schemaVersion":1}"#)

        let conflicts = [ConflictedFile(
            path: "file.txt",
            pathBytes: Array("file.txt".utf8),
            kind: .bothDeleted,
            base: ConflictedFile.StageEntry(
                oid: "df967b96a579e45a18b8251732d16804b2e56a55", mode: "100644"),
            ours: nil,
            theirs: nil)]
        let json = try wireJSON(Envelope(result: EncodableResult(conflicts)))
        #expect(json == #"{"ok":true,"result":[{"base":{"mode":"100644","oid":"df967b96a579e45a18b8251732d16804b2e56a55"},"kind":"DD","path":"file.txt"}],"schemaVersion":1}"#)

        // Structural read-back of one envelope frame, so a failure here
        // distinguishes "envelope broke" from "payload byte drift".
        let object = try #require(
            try JSONSerialization.jsonObject(with: Data(json.utf8)) as? [String: Any])
        #expect(object["schemaVersion"] as? Int == 1)
        #expect(object["ok"] as? Bool == true)
        let result = try #require(object["result"] as? [[String: Any]])
        #expect(result.first?["kind"] as? String == "DD")
    }
}
```
