## Description

Distribute staged hunks into the correct prior commits automatically, by matching each hunk against
the commit that last touched those lines. The highest-leverage command for cleaning up an agent's
messy branch, and the one most likely to be the reason someone installs Switchyard.

## Expected behavior

- [ ] Each hunk is matched to a target commit via range-limited blame (#0018).
- [ ] Hunks with no confident target are left staged and reported, never guessed into the wrong commit.
- [ ] `--dry-run` reports the planned distribution without touching anything.
- [ ] Auto-checkpoints; `yard undo` restores the pre-absorb state exactly.
- [ ] Conflicts exit 8 leaving a resumable state.
- [ ] Signed commits stay signed through the rewrite.

## Notes

Guide §6. Blocked by #0018, #0060.

The "no confident target" path is the one that matters. Absorbing a hunk into the wrong commit is
worse than not absorbing it, because the human reviewing the result will not notice.

## Planning pass — 2026-09-09, to code level. One round.

**The mechanism** (composed from resolved, measured pieces per #0060's decision): absorb is
Fixup's measured sequence generalized to many targets —

1. **Match**: for each staged hunk, run structured blame (#0018, `Blame.swift`) on the hunk's path
   against `HEAD`, restricted to the lines the hunk touches. All blamed lines resolving to one
   ancestor commit = confident target. Mixed tips, boundary commits, or uncommitted lines = **no
   confident target** — the hunk stays staged and is reported, never guessed.
2. **Stage per target**: build a patch containing only that hunk and `git apply --cached` it, then
   `git commit --fixup=<target>` through `CommitCreate`'s signing path. Hunks with no confident
   target are never staged away — they remain in the index, reported.
3. **Replay once**: one `git rebase --autosquash` from the lowest target's parent — autosquash
   replays multiple fixups in a single pass, so this is Fixup's measured sequence with N fixups
   instead of one. Signing precedence and the conflict contract are Fixup's, measured.
4. **Checkpoint**: the whole distribution + rebase runs inside one
   `JournalCheckpoint.around(operation: "absorb")` — undo reverses it as a single step (#0212's
   trap). Conflicts leave the rebase in progress (resumable, exit 8), exactly Fixup's measured
   shape.
5. **Signing**: `CommitCreate.Signing` forwarded to the fixup commits and the rebase — the #0060
   decision's explicit-`-S` rule, never config-reliant.
