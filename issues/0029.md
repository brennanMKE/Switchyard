## Description

Cross-repo state — the repository registry, cross-repo recent operations, agent session records, UI
state — lives in `$XDG_STATE_HOME/switchyard/`, falling back to `~/.local/state/switchyard/`. Not in
the repo, because it is not repo-specific; not in `~/Library/Application Support`, because `yard`
runs in shells, CI, and agent sandboxes where that path is awkward or absent.

The app uses the same path, which enables "what did I do everywhere today" across repositories.

## Expected behavior

- [ ] Path resolution honors `XDG_STATE_HOME` and falls back correctly.
- [ ] Registry records known repositories and recent operations across them.
- [ ] Concurrent writes from two `yard` processes do not corrupt the store.
- [ ] Directory is created with restrictive permissions — it records repository paths and agent sessions.
- [ ] A test asserts the CLI and the app resolve to the same path.
