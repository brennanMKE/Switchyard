## Description

UI tests will not run under CLI-driven `xcodebuild` in this environment — the runner times out
enabling automation mode because it lacks Accessibility rights. RemoteControl hit exactly this and
solved it with a documented manual script, which is the approach to carry forward.

## Expected behavior

- [ ] Script covers: broker ping with the app closed, on-demand activation, live data from the running app, app-pushed events, streaming progress.
- [ ] Failure scenarios covered: app quits mid-session, CLI killed mid-session, broker restarted under the app, two concurrent sessions, nothing registered at all.
- [ ] Each scenario states the expected output and exit code so a human can tell pass from fail.
- [ ] Referenced from `issues/Issues.md` as the verification path for XPC issues.
