## Description

**Split out of #0047 on 2026-08-17.** #0047 delivers the anonymous listener and broker registration;
this issue owns the **session lifecycle** on the app side:

- Sessions survive minutes with heartbeats.
- Teardown handled on **every** path: the CLI exits, the CLI is killed, the app quits, the broker
  restarts, the connection is interrupted.
- Orphaned sessions are reaped rather than accumulating.

Split because #0047 was five criteria and these three are a different thing from "can the app be found
at all". RemoteControl's `AppXPCServer.swift` is 571 lines and most of it is session machinery built
around its own `BridgeRequest` shape; porting it wholesale would import a design Switchyard has not
chosen yet.

## What has to be settled first

**What a Switchyard session *is*.** RemoteControl's sessions exist because its app streams progress back
to an attached CLI. Switchyard's CLI marshals a command and prints a reply — guide §5, *"the CLI marshals
arguments over XPC and prints the reply. It stays small."* Most commands are request/reply and need no
session at all.

So before any code: **name the commands that need a long-lived session.** `review`, `ask` and
`resolve --interactive` are the interactive ones (CLAUDE.md, the agent surface), and they are the
candidates. If the answer is "only the interactive ones, and they are M4", then this issue is **premature
and should be marked so** rather than built speculatively — say that plainly if that is where the
reading lands.

## Expected behavior

- [ ] The question above answered in this issue, with the command list, before any code.
- [ ] If sessions are needed now: teardown on each of the five paths, each with a test or a recorded
      manual verification — several are not unit-testable and #0054 owns the manual script.
- [ ] Orphan reaping with a stated policy: what makes a session orphaned, how often it is checked, and
      what is logged when one is reaped.
- [ ] If sessions are **not** needed now: the issue is closed `wontfix` with the reasoning, and the
      criteria move to whichever milestone owns the interactive commands.

## Notes

**Blocked by #0047.**

`../../RemoteControl/RemoteControl/AppSession.swift` is 53 lines and is the shape to read first — it is
much smaller than the server that manages it, and it shows what a session actually holds.

Do not port the heartbeat design without checking it against guide §4; RemoteControl's cadence was tuned
