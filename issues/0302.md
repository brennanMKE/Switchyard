# 0302 — CommitLog's agentOnly filter is applied twice

## Description

**Raised as a proposal by the M1 milestone review's fifth, seventh and ninth passes. The ninth
measured it**, which is what preflight check 8g asks for when a proposal survives three passes.

`CommitLog` applies its `agentOnly` filter **twice**:

- `CommitLog.swift:240` — inside the parse loop, with a doc comment at `:239` saying *"apply the filter
  inside the loop so we skip early"*;
- `CommitLog.swift:178-180` — again, over the parsed array.

**Measured, ninth pass:**

| mutation | result |
|---|---|
| remove the in-loop filter only | **SURVIVED**, full suite green |
| remove the outer filter only | **SURVIVED**, full suite green |
| remove **both** | **`runAgentOnlyReturnsFilteredEntries(format:)` dies** |

**So the behaviour is pinned and criterion 5 is met** — this is not a coverage gap. It is that **neither
site can ever have a mutation recorded against it**, because each is dead given the other. That makes
the pair permanently invisible to the one technique this project relies on.

## Expected behavior

- [ ] **One filter, not two.** The in-loop site is the one to keep, per its own doc comment — it skips
      early rather than building entries it will discard.
- [ ] After the collapse, **a mutation removing the surviving filter must redden
      `runAgentOnlyReturnsFilteredEntries`**. That is the whole point: the behaviour becomes
      mutation-testable where today it is not.
- [ ] **Check the two filters are actually equivalent before deleting either.** They operate at
      different points — one on a parse-time value, one on a constructed entry — and if they differ in
      any case (a malformed trailer, an entry the parser drops), collapsing them is a behaviour change
      rather than a cleanup. **Say what you checked.**
- [ ] `cd YardKit && swift test` **twice, in the foreground with an explicit 900000 ms timeout**, both
      green, at or above the count in `docs/test-baseline.txt`.

## The files

`YardKit/Sources/YardGit/CommitLog.swift`, and
`YardKit/Tests/YardGitTests/CommitLogTests.swift` only if the collapse needs a test it does not have.
