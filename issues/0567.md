## Description

Guide §11 decision 45. A borderless **Recent Messages** menu left of Co-Author. Its items are
`RecentMessages.list` (#0561): the full messages of the last commits made in this worktree, from
`HEAD`'s reflog, so a commit taken back by Edit ▸ Undo Commit or replaced by an amend is still
there. Each item is titled by its subject, cut to 60 characters with `…`. Picking one **replaces**
the editor's text with that whole message (body and trailers too); #0558 question 3 asks whether it
should ask first when the editor holds a draft.

The list reloads on every refresh (`.task(id: revision)`), 13 ms on git/git. Disabled while empty
("No commits have been made here yet") and while an action runs. Writing `draft.message` goes
through #0564's saving binding, so a reused message is kept like a typed one.

Measured in the VM (#0568's spike): after committing `0568 a subject…` with Ann's trailer, the menu
offered that subject; picking it put `0568 a subject…\n\nCo-authored-by: Ann Lee <ann@example.com>`
back in the editor.

## The files

### 1. `YardKit/Sources/YardUI/CommitComposer.swift` — 1 edit

Add at the end of the file:

```swift

/// #0567: the messages Recent Messages offers, newest first.
@concurrent
public func loadRecentMessages(at path: String) async throws -> [String] {
    try RecentMessages.list(at: path)
}

/// #0567: a Recent Messages item's title: the message's first line, cut to
/// `recentMessageTitleLength` characters with an ellipsis.
public nonisolated let recentMessageTitleLength = 60

public nonisolated func recentMessageTitle(_ message: String) -> String {
    let subject = message.prefix { $0 != "\n" }
    guard subject.count > recentMessageTitleLength else { return String(subject) }
    return subject.prefix(recentMessageTitleLength - 1) + "…"
}
```

(`nonisolated` on the `let` is required: without it `YardUI`'s default MainActor isolation makes
the constant main-actor-isolated and the `nonisolated` function cannot read it — a compile error in
the prototype.)

### 2. `YardKit/Tests/YardUITests/RecentMessageTitleTests.swift` — new file, exactly this

```swift
// RecentMessageTitleTests.swift — a Recent Messages item's title (#0567)

import Testing
@testable import YardUI

@Test func aRecentMessageIsTitledByItsSubject() {
    #expect(recentMessageTitle("Fix the parser\n\nIt dropped the last line.") == "Fix the parser")
    #expect(recentMessageTitle("One line") == "One line")
}

@Test func aLongSubjectIsCutWithAnEllipsis() {
    let sixty = String(repeating: "a", count: 60)
    #expect(recentMessageTitle(sixty) == sixty)
    let title = recentMessageTitle(sixty + "b\n\nbody")
    #expect(title == String(repeating: "a", count: 59) + "…")
    #expect(title.count == 60)
}
```
