## Description

Guide §11 decision 30: at the bottom of the Changes view there is a multi-line message editor
(`TextEditor`, placeholder "Commit message") and a **Commit** button with ⌘↩. Commit runs #0441's
`.commit(message:)`, which is `commitStaged` (#0440): `git commit -m`, so hooks run and signing
follows `commit.gpgsign`. It is one journal entry, so Edit ▸ Undo reads **Undo Commit** and puts the
branch and the index back. One deliverable: **the commit area**.

- **Disabled with a reason.** `WorkingChanges.commitBlockedReason(message:)` (#0441) is the
  button's help tag: conflicts first, then an empty index, then a blank message. While any mutation
  or journal traversal runs, `isBusy` disables it too.
- **The draft lives in `ContentView`** (`commitMessage`), bound into the view, so selecting a commit
  and coming back keeps it. A successful commit clears it. A failure keeps it, and the alert shows
  git's stderr, which is where a rejecting hook's output lands (#0440's measurement), through
  `WorkingChange.failure(for:)`.
- A multi-line `TextEditor`, not a `TextField(axis: .vertical)`: a commit body needs a blank line
  after the subject, and Return must insert it.

**Measured in the planning VM, 2026-09-28:** typing into `textViews["commit-message"]` enables
Commit; ⌘↩ typed **inside the editor** fires the button (the commit appears in History and
`staged.txt` leaves Staged Changes). After clicking a file row, so that focus is off the editor,
Edit ▸ **Undo Commit** removes the commit from History and lists `staged.txt` under Staged Changes
again. That last step needs #0448 (menu Undo reaches the journal) and #0443's `runJournal` rule
(a `nil` selection stays `nil`). Before either fix, the same spike failed at that step.

The editor's `.accessibilityIdentifier("commit-message")` also lands on the placeholder `Text` in
its overlay (measured: a `StaticText` with that identifier appears). The spike queries
`textViews[…]`, so this is harmless.

### 3. `SwitchyardUITests/0445CommitUITests.swift` — new file, exactly this

```swift
import XCTest

/// #0445: a message and ⌘↩ commit the staged changes — the commit appears
/// in History — and Edit ▸ Undo Commit takes it back.
final class Spike0445CommitUITests: XCTestCase {
    @MainActor
    func testCommandReturnCommitsAndUndoRevertsIt() {
        let app = XCUIApplication()
        app.launchWithChangesFixture()

        let staged = app.changesRow(UITestChangesFixture.staged, staged: true)
        XCTAssertTrue(staged.waitForExistence(timeout: 30), "staged.txt is not listed as staged")
        let commit = app.buttons["commit-button"]
        XCTAssertTrue(commit.exists, "no Commit button")
        XCTAssertFalse(commit.isEnabled, "Commit is enabled with an empty message")

        let message = app.textViews["commit-message"]
        XCTAssertTrue(message.exists, "no commit message editor")
        message.click()
        message.typeText("0445 committed from the app")
        XCTAssertTrue(commit.isEnabled, "Commit stayed disabled with a message and a staged file")
        message.typeKey(.return, modifierFlags: .command)

        let row = app.historyRows(containing: "0445 committed from the app").firstMatch
        XCTAssertTrue(row.waitForExistence(timeout: 30), "the new commit is not in History")
        XCTAssertTrue(app.waitUntilDisappears(staged, timeout: 30), "staged.txt is still staged")

        // Move focus off the message editor: the Edit menu's Undo forwards
        // to a first-responder text view (#0393).
        app.changesRow(UITestChangesFixture.untracked, staged: false).click()
        app.menuBars.menuBarItems["Edit"].click()
        let undo = app.menuBars.menuItems["Undo Commit"]
        XCTAssertTrue(undo.waitForExistence(timeout: 10), "the Edit menu offers no Undo Commit")
        undo.click()
        XCTAssertTrue(app.waitUntilDisappears(row, timeout: 30), "Undo Commit left the commit in History")
        XCTAssertTrue(
            app.changesRow(UITestChangesFixture.staged, staged: true).waitForExistence(timeout: 30),
            "Undo Commit did not put staged.txt back in Staged Changes")

        let shot = XCTAttachment(screenshot: app.windows.firstMatch.screenshot())
        shot.name = "changes-commit-undone"
        shot.lifetime = .keepAlways
        add(shot)
    }
}
```
