## Description

`Squash.run` (Squash with Parent…) folds `HEAD` into its parent with `git commit-tree` and passes no
author, so **the squashed commit's author becomes the current user, dated now**. `git commit
--amend` (Brennan's `fixup` alias, measured) and GitUp both keep the parent's author, and Fixup with
Parent (#0581) does too; Squash should agree with it.

`git commit-tree` takes the author from `GIT_AUTHOR_NAME` / `GIT_AUTHOR_EMAIL` / `GIT_AUTHOR_DATE`
and otherwise from the current identity and the current time. Measured 2026-10-05 (git 2.54.0): a
commit authored `Carol 1640995200 +0000`, rebuilt with `commit-tree <its tree> -p <its parent>` and
no environment, came back authored `Current User 1791233853 -0700`. `git commit --amend` and
GitUp's rewrites keep the author; a rewrite that silently re-attributes someone else's commit to
the user is wrong, and on a shared branch it misattributes work.
