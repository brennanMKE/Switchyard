## Description

**Split out of #0049 on 2026-08-17.** #0049 registers the broker launch agent and decides when to
repair it. This issue shows a human what the transport is doing:

- the Mach service name (`ServiceNames.machServiceName`);
- the login-item status, with `SMAppService.Status.label` wording and a button that calls
  `SMAppService.openSystemSettingsLoginItems()` when the status is `.requiresApproval`;
- whether the app's anonymous endpoint is currently registered with the broker;
- how many CLI clients are connected.

It is what turns "the CLI can't connect" from a guess into a reading. Those two failures — the agent
awaiting approval, and the app simply not running — are indistinguishable from a terminal, which is
the whole reason RemoteControl grew this pane.

## Expected behavior

- [ ] A view in **`YardKit/Sources/YardUI/`**, not the app target — guide §11 decision 10, so it is
      reachable from `swift test`. `YardUI` sets `.defaultIsolation(MainActor.self)`.
- [ ] Driven by an `@Observable` model injected as a protocol or a value, so a test can render every
      state without an `SMAppService` anywhere near it. **No test may call `register()`.**
- [ ] Every state rendered and asserted: not registered, requires approval, enabled, not found;
      endpoint registered vs not; zero vs several clients.
- [ ] Dark mode honoured — semantic colours only, no hardcoded light-mode values.
