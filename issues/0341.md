## Description

**A gap the UI work found, which no amount of engine review would have.** #0082's detail pane must show
the diff of a **selected commit**, and **no engine function returns one.** `listHunks` (`Hunks.swift:392`)
runs `git diff` and `git diff --cached` — the working tree and the index. `blameFile` and `CommitLog`
cover the rest. There is nothing for "what did commit X change".

This is the first thing building the app has surfaced that reviewing the engine did not, and it is the
argument for the app-first sequencing CLAUDE.md adopted on 2026-08-18.

## The measured command

`git diff <rev>^!` is the obvious spelling and **it is wrong**: on a **root commit** it returns empty
output with exit 0, because a root commit has no parent. Measured, git 2.50.1, in a fresh repository
with one commit:

```
$ git diff …flags… 'HEAD^!'
(no output)                       exit=0
```

`git diff-tree --root -p --no-commit-id` handles all three shapes. Measured on the same fixtures:

```
# root commit
diff --git a/a.txt b/a.txt
new file mode 100644
index 0000000000000000000000000000000000000000..587be6b4c3f93f93c489c0111bba5596147a26cb
--- /dev/null
+++ b/a.txt
@@ -0,0 +1 @@
+x

# ordinary commit
diff --git a/f.txt b/f.txt
index 036b411d72d7610c361efdb2f03d7cda995e8196..0aea296c994fa8a12ae7d210c8cdd2e0bc6f566a 100644
--- a/f.txt
+++ b/f.txt
@@ -1,6 +1,7 @@
```

`--no-commit-id` is what removes the bare oid line `diff-tree` otherwise prints first, which
`HunkParser` cannot parse. Both outputs above feed `HunkParser().parse(_:)` unchanged.

## Notes

**Milestone M3**, and **#0082's detail pane is blocked on it** — that pane cannot show a commit's diff
until this exists.

**`--no-renames` is pinned here too, deliberately, and it has a consequence worth knowing:** the detail
pane will show a rename as a delete plus an add. #0082's original text asks for renames shown as
renames; that is **not achievable from this function** and needs either a second call or a different
flag. Do not solve it here — #0082 should record the contradiction and decide.
