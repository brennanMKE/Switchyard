## Description

**Finding 3 of the M1 milestone review, sixth pass, 2026-08-18.** `wt new` never asserts the path it
created.

`YardKit/Sources/YardGit/WorktreeAdd.swift:136`, mutated:

```swift
let requested = path                            // was: WorktreeContext.canonicalize(path)
```

`Test run with 1078 tests in 78 suites passed after 107.883 seconds.` — **full suite, unfiltered.**

`requested` is the only source of `WorktreeAddResult.worktreePath` on both the success path (`:170`) and
the failure path (`:153`), and **no test anywhere reads `worktreePath` from a `worktreeAdd` result** —
`grep -rn worktreePath Tests/` finds only hand-built literals in `WorktreeAddWireTests.swift` and an
assertion on the unrelated `WorktreeRemoveResult` (`PipelineContractTests.swift:314`).

**Dropping canonicalization is the realistic regression, and it is a cross-command inconsistency:**
`wt new` would report `/var/folders/…` where `wt list` and `wt where` report `/private/var/folders/…` —
the same worktree under two identities across the M1 command set, which is precisely what an agent
diffing command outputs would trip over.
