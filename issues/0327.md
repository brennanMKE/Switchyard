## Description

**Finding 4 of the M1 milestone review, fourteenth pass, 2026-08-18 — a full-suite survivor.**
`CommitLogEntry.shortOid` returns the **first** twelve hex digits, and nothing asserts that rather than
the last.

`YardKit/Sources/YardGit/CommitLog.swift:370-378`, mutated:

```diff
- return String(oid[..<endIndex])
+ return String(oid.suffix(count))
```

`Test run with 1135 tests in 80 suites passed after 53.926 seconds` — **full suite.**

**Why:** `shortOidReturnsTwelveChars` (`CommitLogTests.swift:288`) and
`shortOidPropertyReturnsTruncatedOid` (`:307`) both assert only **`.count == 12`**; the third covers the
`""` → `"<unknown>"` case. **A suffix is not a valid git abbreviation** — it resolves to nothing — and
`shortOid` reaches user-visible output through `CommitLogEntry.subject`'s empty-message fallback,
`"(commit \(shortOid))"` (`CommitLog.swift:354`).

**The contrast is instructive**: `whereAmI` has `headOIDAndRawHeadMatchRealHeadResolvedIndependently`,
which asserts `headOID == String(rawHead.prefix(7))` and kills the equivalent mutation instantly.

## Expected behavior

- [ ] The `shortOid` tests assert the value **is the oid's prefix** — `shortOid == String(oid.prefix(12))`
      — not merely its length.
- [ ] **Mutation:** `oid[..<endIndex]` → `oid.suffix(count)`. The test must redden.
- [ ] `cd YardKit && swift test` **twice, in the foreground with an explicit 900000 ms timeout**, both
      green, at or above the count in `docs/test-baseline.txt` (strengthening existing assertions may not
      move it — say so explicitly).

## The files

`YardKit/Tests/YardGitTests/CommitLogTests.swift`. **No production change** — `CommitLog.swift` is
correct.

## Notes

**Milestone M1**, criterion 5.

**This is the one that says something about the method, and it is recorded in guide §11.** Pass 13
enumerated **60 stored result fields** and found no gaps — and `shortOid` is a **computed** member, which
an enumeration over stored fields **skips by construction**. That is how a length-only assertion survived
thirteen passes. If class 4 is ever restated as a criterion, it must read *"every public member"*, not
*"every field"*.
