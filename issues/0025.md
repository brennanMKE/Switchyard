## Description

Lane assignment needs table-driven tests: a text notation for a DAG plus its expected lane
assignment, one file per case.

GitUp does this and it is the right approach — but **GitUp's fixtures are GPLv3 and must not be
copied**, not even as "just test data". Design the notation independently and write the cases from
scratch.

## Expected behavior

- [ ] New file `YardKit/Tests/YardGitTests/LaneAssignmentFixtureTests.swift`. Create it; do not restructure existing files.
- [ ] An original text notation for a commit DAG, documented in `docs/`.
- [ ] One fixture file per case, each pairing a DAG with its expected lane assignment.
- [ ] Cases cover: linear, simple branch/merge, criss-cross merge, octopus merge, multiple roots, orphan branch.
- [ ] A deliberate regression in lane assignment makes a fixture fail — verified by temporarily breaking it.
- [ ] No file in the fixture set is derived from GitUp's.

## Notes

Guide §10. Blocked by #0015.
