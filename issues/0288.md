## Description

**Finding 2 of the M1 milestone review, seventh pass, 2026-08-18.** `whereAmI`'s untracked count can
drop `--exclude-standard` undetected.

`YardKit/Sources/YardGit/WhereAmI.swift:245`:

```swift
["ls-files", "-o", "--exclude-standard"]   →   ["ls-files", "-o"]
```

Full suite green, **1092 tests in 78 suites**.

**It is behaviour-bearing, and the review proved it rather than asserting it:** in a repository whose
`.gitignore` contains `junk/` with a file inside, `untrackedCount` reports **1** under the mutation and
**0** on pristine. Without the flag, every ignored file counts as untracked — so `whereami` would tell
an agent it has untracked work when it has none, in any repository with a populated ignore list, which
is essentially all of them.

**`untrackedCount` is a field #0259 already hardened once.** That issue made the four counts
asymmetric so a transposition dies; the flag that decides what one of them *means* was left unpinned.
