## Description

Guide §11 decision 42 in the commit changes window (`CommitChangesView`, #0404/#0406).

- `loadCommitDiff(at:revision:options:)` passes `options` to the async `commitDiff` (default
  `.standard`; `ContentView`'s and `SplitCommitSheet`'s callers are unchanged).
- The window owns `@State options = DiffViewOptions()` (per window, not persisted) and `@State
  shownFiles: [FileDiff]?`, loaded by `.task(id: ShownLoad(target:options:))` only when the options
  are not standard. The file list and the scroll order stay the **standard** listing (`files`): `-w`
  leaves a whitespace-only file out entirely (#0535), and a list that shrank when an option was
  turned on would read as a different commit. Each file draws `DiffViewOptions.file(file, in:
  shownFiles)` — or `WhitespaceOnlyFileView` for `nil`.
- The bar sits over the diff scroll (`DiffOptionsBar(options:)`, no staging note — nothing here
  stages). A failed filtered load leaves the standard diff on screen; a cancelled one is ignored.

import Testing
@testable import YardGit
@testable import YardUI

@Test(arguments: FixtureRepository.RefFormat.supported())
func loadCommitDiffDrawsTheCommitWithTheOptions(format: FixtureRepository.RefFormat) async throws {
    var repo = try FixtureRepository(refFormat: format)
    defer { repo.destroy() }
    try repo.build([
        .init("base", files: ["a.txt": "a\n", "ws.txt": "y\n"]),
        .init("both", files: ["a.txt": "A\n", "ws.txt": "\ty\n"]),
    ])

    let full = try await loadCommitDiff(at: repo.url.path, revision: "HEAD")

        at: repo.url.path, revision: "HEAD", options: DiffViewOptions(ignoresWhitespace: true).diffOptions)

    #expect(full.map(\.path) == ["a.txt", "ws.txt"])
    #expect(shown.map(\.path) == ["a.txt"])
    #expect(full.map { DiffViewOptions.file($0, in: shown)?.path } == ["a.txt", nil],
            "the window draws a.txt and notes ws.txt")
