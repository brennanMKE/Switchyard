## Description

**Finding 2 of the M1 milestone review, fourteenth pass, 2026-08-18 (second half).** Under
`log.showSignature`, **`CommitLogEntry.oid` becomes an English sentence.**

`YardKit/Sources/YardGit/CommitLog.swift:195` invokes `git log` without `--no-show-signature`. The
config prepends a verification line **even with a custom `--format`**. Measured through the engine
against a real signed commit:

```
log default:        oid=[27a977e1a8ad5c5d8e1c5231d24358db9d32c21f]  sig=good
log showSignature:  oid=[Good "git" signature for t@t with ED25519 key SHA256:aqNIt…\n27a977e1…]
```

**`oid` is a wire payload field an agent feeds back to git.** An agent that reads it and passes it to
another command gets a failure it cannot diagnose.

## Expected behavior

- [ ] `CommitLog.run` passes `--no-show-signature`.
- [ ] A named test setting `log.showSignature=true` and asserting `oid` is a bare oid — assert it
      **matches an oid shape** (40 hex characters, or `count == 40` plus hex membership), not merely that
      it is non-empty, since the failure mode is prose that is also non-empty.
- [ ] **Verify the config bites first**: plain `git log --format=%H` under it must emit the prose line.
- [ ] **Mutation:** drop `--no-show-signature`. The new test must redden.
- [ ] `cd YardKit && swift test` **twice, in the foreground with an explicit 900000 ms timeout**, both
      green, above the count in `docs/test-baseline.txt`.
