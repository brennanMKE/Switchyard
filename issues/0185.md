## Description

**Filed by #0182's planning on 2026-08-08. Blocked until #0182 resolves — the file this issue
edits calls a type #0182 creates. Every edit below was applied and run by the planner in a
`git archive` copy of `main` at `910e0ec` plus #0182's two files.**

#0182 extracted #0181's source scanner into `YardKit/Tests/YardWireTests/ConformanceScan.swift`,
parameterised by protocol name, because two near-identical scanners is exactly the duplication
that rots. `DescriptionCoverageTests` already uses it; `ExitClassCoverageTests.swift` still
carries #0181's embedded copy (`private struct Scan` plus a 24-line `scanSources()`). This issue
deletes the embedded copy and points the exit-class guard at the shared scanner. #0183 should
then point the same scanner at `Equatable` rather than writing a third.

The migration also **strengthens** the guard: `ConformanceScan` classifies declaration-site
conformances and duplicate sites, which the embedded scanner reported only as unrecognized lines.
The migrated test refuses both explicitly (measured below).
