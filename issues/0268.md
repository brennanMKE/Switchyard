## Description

**Finding 1 of the M1 milestone review, fifth pass, 2026-08-18.** `whereAmI`'s `headOID` and `rawHead`
are **never compared to the repository's actual HEAD**. Both can be replaced by constants and the full
suite stays green:

```swift
// WhereAmI.swift:160
return "deadbeefdeadbeefdeadbeefdeadbeefdeadbeef"   // was: return text
// WhereAmI.swift:316
return "abc1234"                                     // was: return line
```

`✔ Test run with 1074 tests in 78 suites passed after 121.839 seconds.` — full suite, both mutations
applied together.

**Every assertion on these two fields is the zero value or a shape check:**

| where | what it asserts |
|---|---|
| `YardKit/Tests/YardGitTests/WhereAmITests.swift:19` | `r.headOID == ""` — unborn HEAD, the zero value |
| `YardKit/Tests/YardGitPublicAPITests/PipelineContractTests.swift:242` | `info.headOID.count == 7` — length only |
| `PipelineContractTests.swift:243` | `!info.rawHead.isEmpty` — non-emptiness only |
| `YardKit/Tests/YardCommandsTests/WhereAmICommandTests.swift:64-65` | `headOID.count == 7` — length only |

`WhereAmIWireTests` builds `WhereAmI` values by hand, so it pins encoding and never derivation.

**`headOID` is the identity of the commit the agent is standing on.** #0259's fix landed on the *count*
fields and left the two HEAD fields carrying exactly the assertion shape that finding was filed against.

## Expected behavior

- [ ] `YardKit/Tests/YardGitTests/WhereAmITests.swift` asserts `rawHead` **equals the repository's real
      HEAD**, resolved independently — `#expect(r.rawHead == (try repo.revParse("HEAD")))`.
- [ ] And that `headOID` is its short form: `#expect(r.headOID == String(r.rawHead.prefix(7)))`.
      Assert both; the length check that exists today survives either mutation on its own.
- [ ] **Mutation 1:** `WhereAmI.swift:160` returns a constant 40-hex string. Must redden.
- [ ] **Mutation 2:** `WhereAmI.swift:316` returns `"abc1234"`. Must redden.
      Apply them **separately** — applied together they can mask each other, and confirm each landed on
      the line you meant.
- [ ] `cd YardKit && swift test` **twice, in the foreground**, both green, above the count in
      `docs/test-baseline.txt`.
